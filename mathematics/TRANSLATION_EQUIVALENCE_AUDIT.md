## 3. 真实发现与处理

| 位置 | 发现 | 数学影响与实际处理 |
|---|---|---|
| 39.42 | 初译曾将“最大格比”写成最大格振荡 | A 核实 `BrownianFiniteStateTaylorRemainder.lean` 的 `cellRatio`、`gridRatio`、`gridRatio_tendsto`；实际量为绝对 Taylor 余项除以状态增量范数平方的格上最大值，零增量取零。C 候选已写完整定义；主代理同步澄清中文。没有更改 Lean 公式或证明。 |
| 39.58 | C 初译的有限永久个体语句可被读作一个个体 | B 分离审查要求明确为 “a finite permanent set of individuals”；主代理采用精确修订。对象是有限永久集合，不能缩为单个个体。 |

## 4. 关键语义边界的逐项保持

### 4.1 量词与概率

双语审查明确区分逐点、对正支持输入、几乎处处、期望、条件分布与完整路径律。尤其保留：可数协议族上的共同满事件与不可数选择的区别；有限时域风险与无限时间最终失败的区别；末时失效与曾经失效的区别；同一初始状态与依赖数据的条件初态的区别；占据平均与单次时点边缘的区别；同一源的联合律与将各边缘独立相乘的区别。

§39.61 的 repair 蕴含真实噪声小于一仅是实际训练律下的几乎处处结论，零质量输入词不能替代该量词。§39.70 的组织边缘来自依赖有限输入的条件初态，未被改写为整个联合律等于某一固定初态边缘。§39.83 的动作概率因子仅在正质量相容历史上可消去；数值零收据不一定是故障样本。

### 4.2 控制与评价

GOD 保持最优动作对应的集合类型。GOA 依实际模型可指长期集合、不变律、Cesàro 极限或条件结构；名字不自动提供吸引性、唯一性或最优性。最优策略族、指定返回程序、固定初态最优与全状态最优、受限安全模型与原完整动作域均分开。

第 20 章商控制明确依赖奖励闭合和所有动作下的转移闭合。第 21.7 节保留 M 与受限 R 的区别。§39.77 的有限 Bayes 最优比较类包括完整许可历史和任意实随机概率。§39.92—39.94 的最坏后悔使用运行前固定机制和独立私随机，不能让环境随私种子或逐 tick 更换机制。达到性不是从零下确界擅自推出。

### 4.3 实现、恢复、复制与维持

访问擦除与实际物理毁损没有混同。载体、恢复、修复、组织再生、严格子代与同一身份延续采用术语表的不同条目。实际程序、解释器、初始保护代码、外部资源、传感权限和评价合同仍是各自明确的来源条件。

有限零收入钱包只支付登记有限费用流；后续无限维持另有实际当前余额及外给收入。期望费用不取代逐前缀预付。单个成功样本、Price 恒等式、平均 Perron 增长与实际随机种群长期生存没有互换。

### 4.4 低维模型与数学创新归属

Π/Φ 的规范不唯一和共同低维瓶颈分别表述。第 23.4 节秩三反例只排除所列邻域上的共同光滑二维分解，不排除受限二维参数族或非光滑编码。有限指数族、KL 数据处理、Perron–Frobenius、鞅收敛、可测选择和谱理论的既有数学来源保持明确；它们没有被重命名为 UEOT 首创。

D、P、K、H、E、N、O 的既有角色保持；翻译审查状态不是另一套数学真值体系。Lean 接受某一形式陈述没有被翻译为自然界符合该模型；所有经验支持仍按实际状态保留。

## 5. 可执行结构对照

`check_bilingual_structure.py` 按对应章节检查下列实际内容：

- 章节与附录编号、层级和顺序，显式锚点；
- 每节内按顺序提取的所有显示与内联数学；
- 命题/定义等现有编号出现情况；
- 证明结束标记；
- 完整围栏代码和重要内联代码；
- Markdown 来源与内部链接目标；
- 普通文字中的章节/附录交叉引用；
- 每节文本散列、源行定位及段落数诊断。

允许的确定性归一化只有 Unicode NFC、换行、数学排版空白与显式登记的公式文本翻译。TeX 控制词后的必要分隔空格予以保留，例如 `\beta P` 不能与 `\betaP` 归一成同一 token。公式文字标签使用精确 old/new 字符串及理由白名单，符号、概率量词和公式顺序没有静默豁免。合理的中英普通并列引文可按相同编号序列比较。

调用形式：

```text
python3 check_bilingual_structure.py FINAL.zh.md FINAL.en.md \
  --whitelist FORMULA_TEXT_WHITELIST.json \
  --output BILINGUAL_STRUCTURE_REPORT.json \
  --map-output BILINGUAL_SECTION_MAP.json
```

白名单条目形如：

```json
{"formula_text_replacements":[
  {"zh":"\\text{成功}","en":"\\text{success}","reason":"translation of a text label only"}
]}
```

围栏代码保留源字节（除换行规范）；不通过翻译代码注释改变冻结代码。各段候选最初保留公式内中文，主代理以最终有限白名单统一翻译。不得将候选中保留的中文标签当作英文出版已验收；最后全书检查必须使用已经完成该步骤的正式英文。
