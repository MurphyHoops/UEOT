## 实际环境与复现

实际工具为 Pandoc 3.1.11.1、XeTeX / TeX Live 2025/dev Debian。Noto 三种字体沿用原共享构建的许可证与固定散列；DejaVu 八种字体、局部 TeX 格式与依赖散列见 `TEX_ENVIRONMENT.json`。固定 `SOURCE_DATE_EPOCH=1794355200`（2026-11-11 00:00 UTC）。

```bash
python3 mathematics/tools/prepare_tex_runtime.py \
  --output mathematics/tools/.cache/tex-runtime
python3 mathematics/tools/build_bilingual.py both \
  --runtime-dir mathematics/tools/.cache/tex-runtime
```

第一条仅用于本次缺少格式/CJK 文件的最小运行环境，完整 TeX 安装可直接用数学构建入口。运行环境修复采用固定 SHA-256 的 TeX Live 2024 xecjk/ctex 归档和局部格式；没有改动系统 TeX、其他书的构建路径或共享字体配置。最初缺少格式/CJK 依赖、英文 Babel 语言选项冲突及长译文公式溢出均已在实际迭代中消除；最终日志和两次固定输入构建才是验收依据。

每次构建每种语言均实际执行三遍 XeLaTeX；局部辅助文件可复用。本轮证实同一已记录环境中的逐字节可重复性，不承诺不同 TeX 发行版、字体版本或平台必得相同 PDF 字节。构建器会在输入发生中途修改时拒绝生成有效回执。更早的 `REPRODUCTION_FIRST_BUILD.json` / `PRE_TYPOGRAPHY_REPRODUCTION.json` 保留其历史阶段，不能代替最终回执。

这里的接触表审阅不是全页高分辨率精读；高风险长公式、证明、表格、引用、代码和目录另作放大。没有声称每个字都经视觉逐字复核。

初次版本到最终中文只有 84、86、87、220 四页发生 150 dpi 像素变化；初次英文到最终只有 111、113、114、115、139、242、244 七页变化。其余页面逐像素相同，明确复用原视觉观察。英文 C 的最终直接观察对象为中间 `8d5c4630…` 版本，后续只变 113—115 页；`PIXEL_COMPARISON_EN_HEADING.json` 证明后半 168 页与本版完全同像素，因此其后半审查可以准确继承，未冒称 C 直接重看本版所有页面。

最终真实修复包括下标、英文缩写末点、表项断词、中文附录标题孤字，以及双语端点表的孤立标题。所有已发现问题均解决；没有用编译日志“零警告”掩盖视觉发现。初始图像、每次 PDF 身份和复验页散列见三份 `PDF_VISUAL_REVIEW_*`。完整最终页面也已重新渲染。

`PDF_MECHANICAL_ZH.json` / `PDF_MECHANICAL_EN.json` 逐页检查文本边界、书签、命名目的地及链接；`PDF_FONTS_*.txt` 与提取的字体对象证实嵌入。内部导航通过实际 PDF 对象解析验证，B 另保留 14 个目的地样本；没有把解析说成 GUI 逐一点击。

版心候选列表采用宽松阈值，中文标点悬挂及字体包围盒可能触发。它不是溢出错误清单；实际是否裁切、跨列或相撞由页面观察和物理边界检查判断。源文件相对链接依赖仓库目录；独立阅读 PDF 时，内部导航完整，外部 Lean/历史材料可从 GitHub 来源矩阵进入。
