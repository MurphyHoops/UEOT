# UEOT Council Records

This directory preserves architect resolutions and cross-domain reviews.

It remains governance-relevant because the constitution's change-control process
requires written resolutions. The repository rearchitecture therefore does not
archive or remove this tree.

New exploratory proposals should normally begin under `research/rfcs/`; once
approved, the corresponding architect resolution remains recorded here unless a
future governance RFC changes that rule.

## Current interpretation of earlier records

The [2026-11-13 scope resolution](resolutions/20261113-core-claim-scope-reconciliation.md)
coordinates the constitution with the current conditional Core. It explicitly
limits inherited strong readings of Omega, Pi/Phi, GOD/GOA and lifecycle staging
in the six 2026-03-11 charters and their domain memos. Those historical records
are preserved; acceptance at their own date does not reinstate the superseded
universal admission rules or automatically reactivate their follow-up lists.
Use [current Core state](../core/status/CURRENT.md) and the
[audit closure record](../research/audits/core-closure-2026-11-13/README.md)
before deriving a present task from an old resolution.
