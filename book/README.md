# UEOT Book — Legacy Monograph Tree

The existing chapter tree is preserved as an early monograph snapshot.

Active theory development no longer flows from book prose into Core by default.
Future book releases should be assembled under `publications/book/` from a
declared Core/formalization/physics/validation state.

Existing chapters remain available for provenance and may contain valuable
conceptual material, but they should not be treated as current mathematical or
physical source specifications unless explicitly promoted.
