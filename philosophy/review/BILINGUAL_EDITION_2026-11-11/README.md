## 意见怎样改变正文

[APPLIED_EDITS.json](APPLIED_EDITS.json) 保存 60 项实际编辑决定及依据，
包括旧文、新文、修订理由或组装处理。它是有先后次序的修订日志；
较早条目的新文可能由后续条目继续精化，最终权威文本是两份正式 Markdown。

| 关键发现 | 正文中的实际处理 |
| --- | --- |
| 持续组织可能被当作全部存在者的门槛 | 第 2 章、附录 A 限定主要对象域，承认事件与形成过程；第 30 章只说部分客体具有记忆与行动 |
| 历史连续无法单独解决分叉身份 | 第 5 章增加双后继与同一性传递性检验，分开连续、继承与严格同一 |
| 付费修复容易掩盖可信底座及外部供给 | 第 7 章明确未被修复的条件；不以扩大对象边界吞并所有环境支撑 |
| 新增功能比较与旧功能定义冲突 | 第 11 章实际改掉旧引导句，允许失常；偶然有益效果不自动成为功能 |
| 新增最小能动性与旧总括句冲突 | 第 15 章将旧句限定为反思性能动性，附录 A 同步分层 |
| 整体说明可能重复计算因果 | 第 16 章加入因果排除反对，要求具体实现与可检验的干预解释收益 |
| 自然条件不能直接推出体验、自由或道德 | 第 21、23、25 章分别补入体验难题、形成史操控、一致利己者与公开规范前提 |
| 说理门槛可能排除无法表达者 | 第 24—25 章明确意义反思与生命价值的区别，补入代表与纠错责任 |
| 修订可能把理论变成无法失败的框架 | 第 28 章记录失去的范围，要求剩余主张具有独立、非空和区分性内容 |
| 技术翻译弱化或错置量词 | 全期预期后悔、严格正概率/价格、任意实随机且可相关策略、噪声参数、解码程序、有限维 Itô、增长因子等逐项修正 |
