# Original philosophical manuscript

The seven files in this directory are the unmodified contents of the historical
root [LaTeX archive](../../../UEOT_v3_top%5B1%5D.zip): `main.tex`, `sample.bib`,
`wlscirep.cls`, `jabbrv.sty`, the two `jabbrv-ltwa` data files and
`naturemag-doi.bst`. Third-party class, style and bibliography files retain their
original license notices.

The historical [43-page PDF](../../../UEOT_v3_top.pdf) remains at its original
repository path. The user-provided PDF was verified to have the same bytes.
All original file hashes are recorded in [SOURCE_PROVENANCE.json](../SOURCE_PROVENANCE.json).

The maintained philosophical work lives at
[philosophy/UEOT_PHILOSOPHY.md](../../UEOT_PHILOSOPHY.md). Its revised arguments
and collaborative authorship statement are independent of this frozen source.
