## 2. Q316-CL：同源经典纯化分离

必须采用完整概率单纯形及其凸极点定义。纯态不能定义为 Dirac 后把分类当成证明；辅助类型量词必须覆盖任意有限类型，包括空类型的否定情形。状态的普通联合扩展与纯化分开证明。

实际 Core 对象使用冻结源码中的 `survivalMicroKernel`。完整读出模型的终端等价必须由实际算法证明等价于源态相等，再证明真实 `organizationalTerminalControl` 的商映射保留二点支持。常真策略必须指明，所有时刻安全和第一时刻的商边际必须连接到实际 `stationaryTrajMeasure` 与 `Measure.map`，不能把目标作为证书字段输入。

必需的删除／正例是：删去第二位读出后，旧注册模型的真实商把二点混合压成 Dirac；删去纯性要求则有普通联合扩展；Dirac 态有由极点定义证明为纯的联合扩展；同一源核的假动作破坏安全。H1–H6 的范围及零奖励的退化性质按原合同逐项记录。

责任为 C 接口的具体实例与公开声明的经典 B 解释之间的有限分离。不得升级为全部 106 条及其全部物理解释的反模型，不得称为整个 UEOT 的不可能重构定理。

## 3. Q316-RT：全部实局域测试与联合可区分性

在明确说明的复矩阵表示中，令单量子位 Pauli 矩阵为 \(Y\)，定义

\[
H=Y\otimes Y,\qquad P_\pm=(I\pm H)/2,\qquad
\rho_\pm=P_\pm/2.
\]

分别证明矩阵实性、厄米性、半正定性、迹为 1 及两态不同。局域测试必须量化所有合法实局域效应，证明 \(\operatorname{Tr}((E\otimes F)\rho_+)=\operatorname{Tr}((E\otimes F)\rho_-)\)。联合测试 \(P_+\) 本身也必须通过效应条件，响应为 1 与 0。删除实性限制后，给出复局域效应的乘积将两态区分，说明失败依赖哪项限制。

这是标准有限实态／实效应子空间上的局域层析分离。它没有完成整个实 OPT、所有系统与通道、纯化背景或 UEOT 接口组的形式化；排除这个实模型也不等于已经唯一选出复量子理论。

## 4. Q316-QD：实际量子仪器的条件化连接

从一个实际仪器的成功分支 \(\Phi\) 出发，显式输入 \(r>0\) 以及互逆矩阵 \(S,T\)，并令 \(H=S^\dagger S\)。左特征条件是 \(\Phi^*(H)=rH\)。构造

\[
\widetilde K_j=r^{-1/2}SK_jT,
\qquad
\widetilde\Phi(X)=r^{-1}S\Phi(TXT^\dagger)S^\dagger.
\]

必须证明真实 Kraus 完备性，而非把通道归一直接输入结构。过滤态的质量严格正须由密度条件及过滤可逆性推出。有限迭代等式必须连接现有实际记录算子，进而给出过滤后的实际条件态与 Doob 演化的关系。如果另有右特征密度 \(\Phi(\rho)=r\rho\)，必须单列这一额外假设后再推出准稳态关系。

具体有理见证要求源仪器正规化、左右特征数据可检验、过滤后的态与通道作用确实计算出来。至少有非交换成功 Kraus 及源对非对角输入的非零响应，避免只有对角经典嵌入的特殊例子。所有系数由 Lean 精确计算，不以浮点输出替代证明。

本轮不宣称普遍存在正可逆左特征矩阵，不把特征值存在、主谱选择或无限时条件极限当成已证。此线是公开输入量子结构后的 P／B 定理，尚未证明由 Core 选择这些量子结构。

1. 每条线先完成数学陈述、明确假设、正例及删除见证；主智能体审查量词与实际对象的同源性。

4. 专用见证进入持久化验证入口；递归 Core 导入闭包逐项绑定实际源文件身份。旧版 13 个 Core 导入的回执不能覆盖本轮新增导入。
5. 已完成作者转为另一条线的独立审查者。审查要区分定义、数学假设、已证结论与物理解释，发现问题先修复或收缩主张。

7. 本地完成后集中形成一次可评审源码交付，只运行必要的 PR／主线 CI，并据实际回执登记最终提交、源码树与构建身份。既有研究线和冻结 Core 源码不改动。
