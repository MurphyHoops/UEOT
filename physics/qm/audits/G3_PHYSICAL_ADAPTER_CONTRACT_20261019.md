# QM 内核：三代条件选择的物理接入合同

**结果范围：** UEOTQM-G3 的整数选择定理及其物理适配义务。`UEOTQM.Selector.selects_three_without_atomicity` 已在提交 `fc6942632643369a03deba5e8d5f74e3e4f92511` 的 CI 中完成 Selector 模块构建；完整 QM 包的最终验收另记。[1] 本定理没有新增 Frozen Core 计数，也没有证明规范母结构必然存在。

## 一、已经证明什么

对自然数 \(N_c,N_f,k\)，若

\[
N_c\ge3,\quad N_f>0,\quad k\le N_f,\quad
2N_ck+N_f=N_cN_f,\quad N_f(N_c+1)<22,
\]

则 \(N_c=N_f=3,k=1\)。这里没有原子性或最小包假设。\(k\le N_f\) 仍保留为显式计数合同；在其他现有条件下它可逻辑冗余，本轮没有宣称整个输入集已经最小。

纸面短证：异常整数式给出 \(N_c\mid N_f\)。写 \(N_f=N_ct\)，则 \(t\ge1\)，预算成为 \(N_c(N_c+1)t<22\)。由 \(N_c\ge3\) 得 \(12t<22\)，故 \(t=1\)；预算再给 \(N_c\le4\)，而异常式化为 \(2k=N_c-1\)，迫使 \(N_c\) 为奇数。因此只剩 \((3,3,1)\)。Lean 实现另用已证明完整有限上界的分类证明，结论一致。[1]

## 二、P／S／B 输入不能省略

分类沿用仓库物理合同。[2]

| 层 | 本接口需要的内容 |
|---|---|
| **P：标准物理输入** | 手征 Weyl 谱的局域三次规范异常按表示与重数求和；共轭表示异常反号；色重数为 \(N_c\)；声明规范群内的一环弱耦合系数公式。它们的物理解释来自标准场论。 |
| **S：扇区选择** | 存在所需的动态规范母结构；采用 \(N_c\ge3\) 的复色基本表示、非空家族、同质轻子 \(R\) 与夸克 \(R/\bar R\) 模板，且 \(A(R)\ne0\)；在声明窗口选择 \(b_2>0\)。这些不是 generic UEOT 或整数定理的输出。 |
| **B：待完成的类型化桥** | 将完整谱映射到计数 \(N_c,N_f,k\)，证明额外同通道异常总贡献为零后得到上述整数式；从实际活跃谱与 \(b_2>0\) 推出弱预算。桥必须展示逐项求和，不能把目标方程或“三代”作为结构字段。 |

另须登记 **E：有效模型条件**，包括微扰适用、所有被计数 ordinary families 均活跃的弱 \(SU(2)_L\) 窗口及阈值处理。该窗口的 \(b_2>0\) 不等于跨全部阈值的 UV 渐近自由。额外屏蔽项、规范增强与不同表示均需重新计算。[3]

## 三、为什么仍不能作无条件现实解释

放宽同质轻子模板，令 \(\ell\) 个轻子取 \(R\)，其余取共轭，则方程改为

\[
2\ell+2N_ck=(N_c+1)N_f.
\]

\((N_c,N_f,\ell,k)=(3,2,1,1)\) 满足该式及弱预算。v31 已审计的 \(\beta=0\) 完成谱也通过六项局域异常的精确有理数检查；当前 Selector 的 Lean 反例只覆盖整数式与预算。[1,3] 因而，同质模板承担了真实选择作用。这个两代见证尚未证明全局规范一致性、标量真空、质量机制或实验可行性；它已足以阻止从较宽假设直接宣称“三代唯一”。

## 四、下一项可闭合任务与验收

下一适配器限定为**有限谱清单→异常与弱重数求和→现有 selector**，沿 v31 完成谱及对照谱推进。验收须同时满足：

1. 输入只列表示标签、重数、荷及明确的额外贡献；逐项导出三次异常因子，禁止内置最终计数方程。
2. 在非零异常系数、无额外补偿及已声明的弱窗口前提下，推导 selector 所需两个算术条件，组合调用现有定理。
3. 保留混合轻子两代见证、六代复制超预算见证，以及一般 \(\beta\) 谱遗漏 \(E^c\) 的异常残差控制；区分 Lean 证明与独立精确回归。
4. 固定工具链编译适配器与组合声明，审计公理依赖，报告所有剩余 P／S／B／E 输入。通过后仅升级该适配器；HGP 来源、完整全局异常及现实适用性继续独立验收。
