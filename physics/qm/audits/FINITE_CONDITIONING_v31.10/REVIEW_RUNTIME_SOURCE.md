## 3. 两个完整模型的独立算术核对

### 3.1 非标量 T=3 模型

原仪器完整，失败标签的两个 Kraus 始终隐藏。成功效应逐时为

\[
H_0=\frac1{4096}\begin{pmatrix}183&27\\27&51\end{pmatrix},\quad
H_1=\frac1{256}\begin{pmatrix}33&3\\3&12\end{pmatrix},\quad
H_2=\operatorname{diag}(3/8,3/16),\quad H_3=I.
\]

对冻结的初态，p=117/4096；总原可见叶为 15，接受叶为 8。精确有理下界分别为 3/512、9/256、3/16、1，证书对每个 H−ηI 核查两个对角主子式和行列式。平方根、逆根、Gram 和及逐隐藏 Kraus 运输恒等式均为独立 SymPy 精确表达式检查。

本次新增的 CP 语义检查取 P0=diag(1,0)，得到

\[
\mathcal I_0(\mathcal I_1(P_0))-\mathcal I_1(\mathcal I_0(P_0))
=\begin{pmatrix}0&-1/128\\-1/128&-3/256\end{pmatrix}\ne0.
\]

这证明实际两条成功 CP 分支不交换；仅检查 K0K1≠K1K0 不足以支持该结论。差矩阵已导出至 `exact_witnesses.json` 的 `t3.success_CP_branch_commutator_on_P0`。

访问第二、第三个动作的原概率分别为 9/32、45/512，因此

\[
\mu=1+9/32+45/512=701/512,\qquad \mu/p=5608/117.
\]

最大特征值为 c=(117+3√565)/4096，故最优尺度族滤波的成功率为 p/c=39/(39+√565)。这些数值均正确。原仪器在 I/2 上的失败概率为 23/32，且失败效应为 diag(5/8,13/16)；目标在正定节点的失败概率为零。负失败概率泛函确实将目标与只含原完整仪器的单轮凸包分开。这不排除扩充动作库、加入额外筛选或多轮电路。

### 3.2 同一模型贯通实现与成本的 Pauli 正例

源成功 Kraus 为 Z/2、X/2，失败为同一可见标签下的 I/2、I/2。每步成功率为 1/2，H_t=2^{−(3−t)}I，p=1/8，初始化不变。允许动作是确定标签 0+Z、确定标签 1+X；权重 1/2、1/2 实现真正带标签 Choi 等式。八条完整成功记录的量子块均逐块核对。

原一次仪器调用计一单位时，早停单次动作均值为 7/4，每个成功输出为 14。目标三次 Pauli 调用，另加每次随机化 r 的成本为 3+3r，比较条件 3+3r<14 正确。这里源一次调用是一个完整的随机仪器，不应被表述为已知的单个酉动作。

Z 与 X 反对易，但共轭通道 Ad_Z 与 Ad_X 交换：两种次序只差全局符号，符号在密度矩阵共轭时消失。因此该正例是带量子末态的完整实现见证，不是非交换 CP 分支的见证；非交换性由上一模型提供。

## 4. 初始化、资源及误差边界

1. **初始化分类正确。** 在全部正成功率系统输入上，确定性实现归一过滤的例外确有 H=cI 与 rank(H)=1 两类。前者保留整个联合态，后者只能保证系统边缘；保留参考的 Bell 反例距离为 1/2。非标量有两个不同正特征值时的仿射失败、等正谱但含核且秩至少二时的仿射失败，覆盖其余情况。本章正确将该全分类标为书面证明。

2. **滤波尺度正确。** 完整滤波成功率为 p/c，成功后态与 c 无关；平均尝试数 c/p 必须有独立重新准备相同输入的资源前提。`QuantumInitializationCost.filterInstrument` 使用真实 PSD 剩余 Gram 因子，实际证明概率及后验。`scaled_filter_mean_attempts` 本身是倒数代数恒等式；概率等待及无限期成本解释不能仅靠这个声明名称。

3. **早停和重试公式正确。** `retryTreeCost` 从每条原记录的成本构造有限递推，不要求同一次成本与成败独立；其闭式与极限为 μ/p。非负成本下以单调收敛识别无限总成本期望是书面概率论步骤。仅一份未知态的失败后恢复不在 iid 前提内。本次运行的完整源质量与矩阵生成的实际动作访问率相符。

4. **条件误差分母正确。** 两个接受子效应 E 与 I−E 同时使用，得到 ε/max(p,q)，不是仅用一个子效应的粗界。相同接受提取器及两个完整归一源 CQ 输出是必要前提。现有精确见证用 p=1/1000、q=11/10000、完整误差 1/10000，条件误差 1/11，精确达到该不等式。本章另写的同质量三结果例也正确，但需显式加 0≤δ≤p≤1、p>0 使概率律合法。

5. **局部 Kraus 误差常数正确。** 在标签匹配、隐藏指标零填充、两套实际完整仪器及算子范数约定下，半迹距离不超过 (1/2)Σ_j(‖L_j‖+‖M_j‖)‖L_j−M_j‖。同一有限参考的恒等延拓不改变该范数估计。前缀预算只适用于相同声明控制器；完整性残差本身不把浮点集合变成物理 CPTP 仪器。

6. **谱稳定范围正确。** 两个正定效应共同满足 H,H′≥ηI 时，根差和逆根差的常数 1/(2√η)、1/(2η^{3/2}) 正确。奇异支持必须另行认证，纯补空间输入可使两个合法 fallback 的可见 TV 达到 1，不能将泄漏删出误差账。
