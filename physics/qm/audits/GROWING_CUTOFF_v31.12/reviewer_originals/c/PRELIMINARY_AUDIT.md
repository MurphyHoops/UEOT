# C recovery audit: checks frozen before source inspection

Status: preliminary responsibilities only; no candidate source has yet been recovered or accepted.

## Required equalities and domains

1. Freeze one parameter vector theta for source events, backward effect, target, action library, preparation, and readout. The deployed policy is chosen from calibration and visible history only: exists w(D_cal), for all theta in C(D_cal). A per-theta optimizer is not a deployment certificate.
2. Preserve every visible source/compiled record, failure/leak/stop record, and a common final-state embedding. A Choi equality without its normalization and input domain is not a complete record bound.
3. For a spectral filter P and Q=I-P, failure-reset output on SR must be |reset><reset|_S tensor Tr_S[(Q tensor I) rho_SR (Q tensor I)], an unnormalized conditional reference block. It is not generally the unconditional rho_R.
4. If the original two-step successful source has H=s^2 I, H is computed from its actual same-parameter events. For physical filter plus source, total success is s_N s^2. This scalar identity permits target contraction only on its correctly normalized contract.
5. Infinite independent retry cost mu/p requires a fresh/resettable source. An unknown quantum input cannot be regenerated for free. One-time calibration is amortized separately from per-attempt resources.
6. A blue-pulse call count inferred from label 1 is valid only for a flag-first implementation scheduling the pulse conditionally. Coherent-control scheduling may consume a pulse slot on every trial.

## Quantitative checks to execute

- Recompute exact/fractional minimax and deployment witnesses independently of the proposal solver.
- Verify the design interval certificate separately from a narrower data-dependent interval.
- For each beta omission hybrid, use the actual input support at that slot and a branch mass from one valid comparison-side process. Do not mix unnormalized masses from incompatible trajectories.
- Confirm that beta has an independent constraint if label probabilities are beta independent; observed label counts cannot supply beta coverage.
- Freeze the target precision before evaluating the bound; report both the numerical slack and which physical uncertainties remain unbounded by data.
- Check the inclusion of real filter failure in the full output metric, not only the normalized projected-state comparison.

## Evidence check

Only source-byte-matched historical evidence may be reused. New commands must have truthful runner, checkout, input/output/log identity. Paper, Lean, exact arithmetic, floating point, synthetic coverage, external data, and project data remain separate. No empirical claim follows from a simulated PASS.
