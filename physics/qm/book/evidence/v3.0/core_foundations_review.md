## 2. 理论核心的准确理解

UEOT Core 的可持续核心是相对声明协议的识别、实现、运输和评价架构。它使“在变化中仍是同一个对象”可以具体化为未来响应因子、递归/动态闭合、物理实现、机制干预和历史延续。Core 的规范预测状态不要求单个对象保存整个世界的未来；最小性相对目标、协议、参考律和支撑成立。

四生成器是 M-QD 商/下降、M-TC 有限定量运输、M-PE 正特征结构、M-OI 占据极限/不变闭合。S4 §6.2的准确账本为11 generated、89 retained_adapter、6 retained_boundary，共106项；四者只在声明推导系统内非冗余。95项适配或边界仍保留，不能把“4”解释为四条物理定律，更不能宣称106项在无额外数学条件下均由四项生成。

正文§1.4没有只重复四个名称，而是给出了四种可直接检查的推导：纤维常数产生下降；Lipschitz误差递推及乘积展开；Perron归一化、Doob变换与不变权重；有限量子CPTP通道的Cesàro平均及不变极限。最后一个有限量子版本是正文中的直接数学推导，不冒充新增 Lean 声明，也不意味着量子本原谱论全部已实现。

GOD/GOA需要评价桥。相同对象/动力学上的两个相反奖励直接排除“存在唯一生成目标”。最优动作通常集合值；不变律、Cesàro极限、QSD、轨道吸引性各有不同假设。Π/Φ存在目标 gauge，同一行为不唯一识别两个机制。共同二维响应给同一点跨环境秩≤2的必要条件，有限统计中未拒绝零不等于精确秩已证。

七科学端口是把这些数学边界变成具体研究问题。量子内核能够给指定有限模型的可靠全词/自适应结论；真实设备模型、协议可实施性、相关数据与机制可识别性继续由相应C端口承担。阶段合同关闭、Core表面覆盖、有限实例通过、现实应用支持和整个科学端口关闭不能互换。

## 5. 两个实质修正为什么不能省略

### 5.1 总通道与相同POVM仍不足以保证记录律

旧§5.3写 `T_a E=E T̄_a`，而T为CPTP。若后面的“全部输出效应”只指各次测量POVM，就无法由该式决定測后态。反例中两仪器所有单支概率都为1/2，总通道都制备I/2；第一标签相同的情况下，后续Z结果却相反。正确替换逐个CP分支后，所有未归一历史算子由编码对应，保迹和效应配对才完成路径证明。

这同时解释为何现代内核要使用实际Kraus枝、词效应与拉回闭合，而不能仅在摘要表中存总通道或相同单次效应。旧编号被保留，前提增强和证明修正有据可查；没有通过换一个名字隐藏原语义缺口。

### 5.2 相干反演的算子必须类型正确

旧W被同时称作等距写入和完整空间酉操作，原公式中 `W(X⊗|0><0|)W†` 和右端的张量态因此有类型歧义。修订将 `W:H→H⊗R` 与 `U_W:H⊗R→H⊗R` 明确分开。在写入像上，SRN确实保持所有块并乘以K；完整逆酉才把记录寄存器恢复为空白。这个数学完成不代表装置能访问所有泄漏到环境的记录。
