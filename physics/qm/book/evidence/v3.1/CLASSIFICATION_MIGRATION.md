## 两个字段保持独立

| dependency_class | 冻结合同原义 | 本迁移采用的判据 |
|---|---|---|
| C | Core-derived | 明确Core结果；声称已证时须有真实源命题/形式定理依赖，提及Core或研究类比不够。 |
| B | Bridge | Core与物理对象、状态、操作/响应的有类型映射，前提与形式状态另明。 |
| S | Sector-selection principle | 从通用结构选择理论类别的额外原则，不倒填成Core结论。 |
| P | Standard physical input | 标准物理结构、常数、场内容、边界或实验标定输入。 |
| E | Effective/modeling assumption | 实际的Markov、弱耦合、有限截断、微扰/EFT或声明模型适用窗口；不是经验一词的同义字母。 |
| O | Observable consequence | 声明输入链下可测或可数值核查的响应/约束；不表示已有真实实验。 |
| X | Open conjecture | 尚未通过证明/实证门的UEOT专属正向关系；不包括已反驳主张或仅待形式化的标准数学。 |

argument_status 保持原有 D/P/K/H/S/E/N/O 字母、字段名和含义：定义/协议、正文推导、外部标准定理、附加假设、组织解释、实验/数值或经验输入、反例/不可能性、开放问题。没有引入改名字段或新论证字母。两字段重复使用同一字母时，必须带字段名理解。

章级数组是所含角色集合，不表示全章每一句都同时依赖全部类别，也不会使所有H前提都成为X。每条JSON reason给出具体章节定位与X范围；精确命题仍以其正文前提及实际源码类型为准。
