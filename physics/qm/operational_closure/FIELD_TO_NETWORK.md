# 类空共同场如何改变双源独立性与网络计分

主审从同一批物理输入独立推导，再与量子组和反例组的实现交审。这里比较三个问题：能否发送信号、两个实验源能否按乘积处理、指定操作菜单能否排除一个物理候选。它们在这个具体模型中有不同的答案。

## 制备合同和局域操作

取已冻结的单位质量 KG 圆场、同一涂抹、制备时钟、初始高斯态和严格类空设置。左右 A、B 两段宽 0.2，间隙 0.1，中心对径，最大时间差 0.5 小于两支撑的最短空间距离。在每个源制备一对 Φ⁺，次序为 (A,B₁) 与 (B₂,C)。用每对的中间站半边 B₁、B₂ 控制当地纵向场位移，其余两比特不动。随后场退出可访问的线路；三个站按 E3 作局域测量。换上 Bell 输入是本合同新增的物理制备；仍使用旧场及源核。该线路可在共同未来汇合两个中间站半边；空间支持不意味着三个最终读出同时发生。[原场合同](../cross_domain/field/design.json) · [E1–E3 原定义](https://arxiv.org/pdf/2101.10873#page=11)

设含耦合 λ 的模式位移为 u、v。高斯高模真空，低两模的占据矩阵为 N，N₀₀=N₁₁=1/2、N₀₁=N₁₀=1/4。写 G=I+2N，得到 Qₗ=2u†Gu、Qᵣ=2v†Gv、C=4Re(u†Gv)。推迟对易响应在这两个支撑间严格为零。对称二点函数的 C 可以非零。对角两比特编码 |i⟩→|ii⟩，丢弃场后显式密度矩阵为

    ρ(ii jj, kk ll) = exp[−Qₗ(i−k)²−Qᵣ(j−l)²−C(i−k)(j−l)]/4.

这是零均值相关相位角的经典特征函数，协方差矩阵两对角为 2Qₗ、2Qᵣ，非对角为 C。每个角仅旋转当地的半个 Bell 对；在复张量积中两源之间可分。由原谱尾界 H_M（M=320），两条噪声的截壳修正分别位于 [0,8λ²H_M]，C 的余项绝对值≤16λ²H_M。名义 λ=0.3 时 Qₗ≈0.033435349875，Qᵣ≈0.024933068940，C≈0.016862931440。用全部归一化概率及16维矩阵独立检查。[程序](source_bridge.py) · [向外数值区间](source_result.json)

## 同一个源，三个不同的可区分性结论

记 m=exp(−Qₗ−Qᵣ)，kₓ=m(cosh C−1)，kᵧ=m sinh C。把 ρ 写成两个逻辑比特的 Pauli 展开，相对两源边缘乘积的偏差正好是 (kₓ X⊗X+kᵧ Y⊗Y)/4。这里 X、Y 作用在各源的逻辑二维空间。名义点 kₓ≈0.000134121179，kᵧ≈0.015907596792。

1. **允许任意联合量子测量。** XX、YY 对易，四个 Bell 向量上取得四组符号。到边缘乘积的半迹距离为 max(|kₓ|,|kᵧ|)/2=**0.007953798396**。类空无信号和非乘积在同一个态上同时成立。
2. **固定实基底，改变所问的距离。** 对实可分的任一态 σ，每个实对称局部因子对逻辑 Y 的期望为零，所以 Tr[σ(Y⊗Y)]=0。该联合算符本身实对称，算符范数为 1，从而 D(ρ,σ)≥|kᵧ|/2。在两个逻辑 X 基底各自去相干得到 σₓ；这只删除 ρ 的 YY 项。σₓ 是实乘积 X 本征态的概率混合，恰达到下界。故此四线**固定实现**到实可分集的精确距离与上一数值相同，到复可分集的距离则为零。原空间中的实可分竞争态即使跑出逻辑支撑，也服从将 YY 在正交补置零后的同一下界。Y⊗Y 对两实比特的作用可与早期实比特纠缠工作对读。[Caves、Fuchs 与 Rungta](https://arxiv.org/abs/quant-ph/0009063)
3. **权限只有各源分别进行实测量。** 对单份、局域实对称效应及其经典粗化，ρ 和 σₓ 的全部联合统计完全一致。相对指定边缘乘积，单份菜单可见的最优总变差仅有 |kₓ|/2≈**0.000067060589**，由测当地 X 并比较两比特乘积达到。若确实能独立重制两份同一 ρ，每个实验室新获准在自己的两份上测 Y⊗Y，这是一个实对称的二元测量。在两实验室比较结果，ρ⊗ρ 与 σₓ⊗σₓ 的乘积期望差为 kᵧ²≈**0.000253051636**。这给出一个实际拆开原有不可区分类的测试。它依赖独立张量幂和跨两份的局部联合门；跨次持久参考有自己的联合态。

因此，从一个已指定实密度矩阵算出的距离，不能替代对未知实模型、所有附属设备和共享参考的距离上界。允许源间共享经典随机数的实可分模型仍受 Renou 界；把独立性仅定义为某个源端菜单下的因子化，容许更大的实模型类。Hoffreumon 与 Woods 的预印本在相应操作独立性下给出有限网络与序列协议的实模拟；另有改变复合规则的实表示。本轮使用以上具体矩阵和操作权限裁决这条差别。[操作独立性原文](https://arxiv.org/abs/2603.19208) · [改变复合规则的实表示](https://doi.org/10.1103/4k13-sdjh)

## 在同一源上计算实际网络分数

E3 有 3×6 个输入组合，每个有 2×4×2 个可能输出。中间站的四个 Bell 标签合计为1，每个概率都是1/4。对 b=b₁b₂，后选择对应的末端相干因子为 exp[−Qₗ−Qᵣ−(−1)^b₂ C]。按标签改正符号，三个轴的相关量为 1 以及两个相同的相干因子。故 4T_b=2√2{1+2exp[−Qₗ−Qᵣ−(−1)^b₂ C]}，总分 T=2√2(1+2m cosh C)。直接用 Born 规则算18组、288个概率验证每一标签。名义点四个 T_b 依次约为 2.018831、2.063824、2.018831、2.063824，总分 **8.165309753260**。强行将两源边缘取乘积会得到 **8.164551049300**，共同噪声对总分的改动小于它对单个条件分数的改动。

这一模型分数超过 Renou 附录 E 定理 3 的实可分网络界 7.6605，差约 0.50481。该界采用原作者的 SDP 计算机辅助结果。另有一条完全避开这项 SDP 数值的检查。保留同一剖面、时钟、场态、实可分竞争类和测量，仅把两源耦合都改为 **0.003**，所有 Q 和 C 乘 0.0001。小剂量按 1−exp(−u)≤u 选取，使最差分支离极值小于 0.000060；这是一个另行声明的物理点。实际两种分支的 6√2−4T_b 分别约为 **0.0000425571183、0.0000234790005**，四个概率仍严格为1/4。该点满足原文定理 2 的四项解析鲁棒条件（ε_c≈0.0000718）。因此可直接排除任意维数的 E1 实可分源加实局域操作。这里的物理输入是构造的复量子实验模型，结论是条件预测。

还可将该判据送回记录空间。若另一个合法网络每一设置的完整输出总变差≤d，则每个 P(b) 最多改变 d，每个 T_b 最多改变 24d（12 个有符号期望，各不超过 2d）。令 ε=0.000060。取 d=10⁻⁷，四项均满足

    [ε−(6√2−4T_b)]/4 > (24+6√2−ε)d，且 d < ε。

于是这整个响应邻域仍满足解析排除条件。此邻域是模型预测的充分误差余量。将它用于设备，需要包含损耗、设置独立性和抽样的同一完整记录误差证书；普通点估计不能给出这项保证。[Renou 等，附录 E、G、H](https://arxiv.org/pdf/2101.10873#page=11)

## 同一个源矩阵若允许重选全部实读出，能否复制这些分数

在名义 λ=0.3 的点，对该矩阵选任意局域实 POVM，再把输入替换为上面显式的实可分 σₓ，得到同样 POVM 作用的 E1 表。每设置总变差至多 D=0.007953798396，故原矩阵在任意这类读出下 T≤7.6605+24D<7.852，低于复读出 8.16530。这个推论依赖文献的数值 SDP 界。任一全实模拟若要重现该值，包含所有共享参考后，到同一切分的实可分源集的距离至少 (8.16530−7.6605)/24>0.02103。所选实嵌入以外的额外资源需要另计。

还可由解析定理给出**整段非零耦合范围**的结论。令 r=(λ/0.3)²。当 |λ|≤0.0015，即 r≤1/40000，已知源矩阵到 σₓ 的距离至多 r|C|exp(r|C|)/2<2.11×10⁻⁷，此处 Q 和 C 为名义点的值。每一分支的极值缺口至多 4√2 r(Qₗ+Qᵣ+|C|)。代入上一节的不等式，整个窗口中理想复输出表的 **3.70×10⁻⁷** 每设置总变差邻域都排除 E1 表。若某组实局域 POVM 在同一个源矩阵上离复预测至多 **1.59×10⁻⁷**，用同一读出测 σₓ，所得 E1 表便在前一邻域内，矛盾。这说明即使在一定误差内重选所有实测量，该固定矩阵也不够；证明只用定理2。局部私有辅助态可吸收到 POVM，未建模的跨源量子参考则改变前提。数值量词覆盖模型，不代表实验可达相应统计精度。

## 哪一部分由 Core 承担

C：P-MET-01 提供概率测度在可测读出下的总变差收缩；QM 的标量运输定理复用 Core 的加权链界。B：把每一合法设置看作协议，把 a,b,c 作为完整记录。量子测量将半迹距离上界送到输出总变差，此后事件粗化和 E3 分数运输分别使用上述收缩和有界函数期望不等式。不同操作菜单由可用未来测试定义不同响应商，第三个算例给出了严格见证。S：跨源的实可分假设与准许的局部／跨份操作。P：KG、Weyl、Gaussian、Bell 制备、量子读出规则；E：谱尾包围；O：四类概率、分数、能区分两份制备的本地统计；X：从 Core 选出自然界的复合规则。这条依赖中，Core 没有独立给出 E1。[Core 总变差定理](../../../formalization/ueot-core/UEOT/V3/TotalVariation.lean) · [QM 对 Core 链界的调用](../../../formalization/ueot-qm/UEOTQM/Transport.lean)

仓库中可逐行定位这一接法。Operational.lean 中的 `UEOTQM.existsUnique_responseDecoder` 调用 Core 的 `QuotientDescent.existsUnique_descend`：取协议标签为设置，在每个等价类上读取联合响应表；E3 是该表的线性函数，故在该商上良定义。对源端单份实菜单，ρ 与 σₓ 投影到同一响应类，二者的实可分距离却不同。因此不存在一个定义在该单份响应商上的解码函数，能为每个制备返回其真实可分距离。加入两份局部门并允许独立重制后出现非零反例统计，原等价类必须细分。这里实际得到了一项关于可识别性的非蕴含；有限网络原理仍由单独的物理输入提供。[量子响应解码及所调用的 Core 定理](../../../formalization/ueot-qm/UEOTQM/Operational.lean) · [Core 结果来源矩阵](../../../mathematics/THEOREM_SOURCE_MATRIX.md)
