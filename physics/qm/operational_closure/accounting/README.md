在基线 `940541cd464d8bccb9f7c553dbd3ebfefde596b7` 的四个设置中，**旧同地**在本预算下能排除脉间复位。严格类时的信号小近两个数量级；本轮没有分辨它，也没有凭类空组的近零结果认证微因果。后续局域门独立重算了两符号共八个联合概率，以及场能、探针能和开关功。以下观测都是固定生成器实际运行的合成数据。硬件部署、系统转移界、泵效率和复位均未认证。

## 冻结、留出与实存记录

在取样前将设置、主终点、整数分配、噪声、三条 RNG 种子、失败出口及 α 写入 [合同](CONTRACT.md)。原四个名义量早在基线中可见，按预期信号选旧同地作主组。没有从四组实测差值中择大，也没有因新增 C 读数而重定主终点。第三门参数来自 [Noether 合同](../local/CONTRACT.md)，在首次合成揭示前补入。合成随机种子公开，可以重放。预测函数无观测文件入口，实际评分也可只从存档记录解码。人员私盲及真实硬件未实施；现场实施需独立保管随机码，先锁定两模型及规则，再打开留出标签。每次重新制备，不设“取满成功次数”停则。

## 统计界、漂移与失败出口

每个二元读数保留未知漏读。潜在正率的下端用已报正数/全部开始，上端用（正数＋漏数）/全部开始。对两个端点各向外加 rₙ=√[log(64/0.05)/(2n)]，截至 [0,1]。在独立开始、稳定的条件概率或固定组平均的独立有界模型下，至多 64 个单侧端点的总失败概率≤0.05。用掉的端点包括前/后/合并参考、四组两符号和新增 C 的边缘。漏读可依赖结果；若源根本没发出，区间只具“任意二值填充”的含义。失败本身已是可观测输出。

对每个 s，参考给 a=P(读+|真−)、b=P(读+|真+) 的箱。对留出理想率 p 拟合转移式 q=a(1−p)+bp+ε，|ε|≤0.005；用箱端点单调反演，再用两符号作差。若 b 的下端≤a 的上端，或任一真值/符号两期误差率区间的最小距离>0.05，则不出物理判定。原合成资料的四个最小距离都是 0，只验证前后数据相容；设备在试验中途稳定仍是前提。

* **效能。** 在冻结的稳定错标、独立 0.002 漏读、完整场和固定分配下，主组检出正 Δ 的功效下界为 **0.98247**。证明令合并参考及主留出各相关端点偏离均值至多 t=0.015，在最坏端点反演后 Δ 下界仍为 0.02664。对此事件取并集界，另计两期漂移误报，损失上界为 8exp(−2·16384t²)+4exp(−2·32768t²)+16α/64。该设计功效有明确噪声前提。
* **漂移。** 合成后期给指定参考误标加 0.18，整批实际触发不合格。若把真物理差置零、只对旧同地真实脉冲读出加符号相关偏置 ±0.96Δ/2，参考仍正常，评分却返回 [0.07515,0.21044]。监测不能自行证明参考到部署的 0.005 转移界。
* **时序。** 原四组在其他量不变时，|∂p/∂τ|≤2Σω|AⱼBⱼ|+|ω₁−ω₀||B₀B₁|，余壳也取界。若将每符号 0.005 中的 0.0025 专留给相对时延，则旧同地须 |δτ|≤0.00817，其余三组≤0.03434（场质量倒数为单位）。余下 0.0025 需覆盖 SPAM 转移等误差。脉宽、剖面、锁相、探测效率与泵波形须各自校准。矩形开关有高频尾，有限带宽硬件的实际包络需重新代入，以上时延界不能覆盖任意波形畸变。
* **复位与选择。** A/B 中间整场复位的合成对照给旧同地 [−0.06858,0.06655]，排除完整场名义值。另在零物理差下选择性删去 30% 的不利类别，只报存活得到伪差 **0.172586**，两臂每存活需 1.17955、1.17769 次开始；按全部开始给 [−0.06858,0.37886]，保留零。这些对照是同预算反事实重放，未增加名义实验的启动数。

## 跨符号复位、全局读出与可部署边界

可对两符号使用同一种复位载体。对理想两位记录 M 和四态简并空白寄存器 R，用同一 SWAP 将 M 置空并把记录及其相关转交 R，不用知道 s。真实三值两路需至少九种输出标签，或两只三态寄存器。每次都需干净接收空间；若复用同一块芯片，要先排空、再冷却/擦除或输出记录。输出 B,C 与其余场有相关；局部擦除不复原场。若要真正全装置独立重启，须重供与 s 无关的同一初始锁相场（例如与同谱服务场作理想全场交换），并为 C 供应同一纯相干制备。理想能量匹配交换可用同一个门覆盖两符号；接收载体末态、搬走的能量和相关随符号变化。全场访问、干净载体的生产、时钟分发、复位热浴和运输都是新增权限。若有记录控制脉冲将能量本征态的 C 恢复到同一初态，理想条件平均驱动功为 −ΔE_C；同时消耗相位参考并需结算记录。测量 Y_B 在简并假设下无裸能变；读出基础设施仍有成本。

以 kBT=0.25，限定简并经典记忆、无剩余量子旁信息、渐近可逆擦除。理想记录若计入已知符号，H(B,C|s)=1.671747 bit/开始；不知道 s 而用同一复位策略则 H(B,C)=1.687310。含错标/漏读的实际生成器对应 1.711169 与 1.725491 bit，忽略符号额外支付的最低平均功为 0.002482/新增门启动。这是同一空白服务规格下是否利用旁信息的区别。若设置、符号序列已知，**全部 262144 次**已登记输出的模型熵为 255295.9882 bit；若要把唯一档案也擦掉，相应最低功为 **44239.4236**。这是给定分布的期望和理想下界。保留档案就须给存储、传输和以后复位付费；未归档的时钟、随机设置或标号若也擦除须另计。只保留 C 激发的理想成本已是每个接受 5.30093/5.61743 次源准备，不能只报成功支路功。

空间上每个耦合剖面有半径 R=23L/120。在支撑区用一个展宽探针表示同一量子控制自由度，是额外的局域装置假设。物理实现须在支撑内提供所需相干耦合，或部署有共同参考和校准的分布式辅助器、延迟汇聚读出。比较记录只能在相关支撑的共同因果未来进行。取 c=1，同地在中心汇聚的充分最早保证时刻为 T+h+R；对径的全圆记录可保守等到最后脉冲结束后 L/2 再在固定点归档。不能在某一端立即获得全支撑联合记录，更不能以支撑几何替代对控制总线、信号速度及汇聚时钟的验证。
