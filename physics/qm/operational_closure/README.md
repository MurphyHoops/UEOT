## 主审增加的跨组结果

给原严格类空的两个耦合分别配一对 Bell 源。各源一半与场局域相互作用，共享场随后不可访问。在固定低模噪声及原剖面下，场的推迟响应为零，两个源的制备却有非零相关。名义耦合 λ=0.3 时，与两侧边缘乘积的半迹距离为 **0.007953798396**。给源端单份的实局域测量，能见的最大总变差只有 **0.000067060589**；两份独立重制并在各侧联合测量，则可见单份测试遗漏的一项相关。可访问的操作决定响应商，这里有一组具体数值可检查。

将该态继续送到三站网络，名义点给 **8.165309753260**。主审矩阵法与两组独立高斯求积在两种剂量下逐格比较，每种剂量有 18 个设置、288 个概率。λ=0.003 时，四项同时满足 Renou 的解析鲁棒条件；进一步在整段 |λ|≤0.0015 上，即使允许对**同一已知源矩阵**重选全部局域实测量，距目标表每设置总变差不超过 **1.59×10⁻⁷** 的模拟仍可排除。Popper 独立核验了这条三角不等式及量词。

这项结论选择的是“给定复合规则、源资源和实施权限的模型类”。在更大模型类中，实共享参考能重现理想复网络的全部 288 个概率，单份局域源检验也可对它完全失明。将复合规则改为另一个实表示，或将独立性仅定义为可见相关的消失，会改变命题。[主审完整证明与数据](FIELD_TO_NETWORK.md) · [Renou 原始定理](https://arxiv.org/abs/2101.10873) · [操作独立性的竞争模型](https://arxiv.org/abs/2603.19208)

## 能量能否追溯到同一个源

原同地、正号制备的 A、B 作用之后，保留 B 与整个场的相关，不做模式选择。第三段若采用实验室固定轴、能隙 1/64，场能变化在 **[−0.0113640,−0.0087546]**，C 能变化在 **[+0.00008626,+0.00018393]**，净开关功为负，单位都是 ℏω₀。改为只在原点世界线上耦合、能隙 1/128，另取已声明的时窗，场与探针能量仍严格反向。初始场已受驱动；此结果涉及这一轮制备与干预，不能由它计算循环热机效率。

阶段性纠正有两项。第一，末态相近只能控制有界读出，场能没有上界；固定轴的能量证书另用 Heisenberg 方程控制能量加权的模式差。第二，分辨 C 的激发率与实测场失能是两个实验问题。随机开关能检验前者；后者还需独立的开、关边缘功估计和守恒合同。[局域操作、负控与能量收支](local/README.md)

主审还审出了一个会影响统计判决的问题：某一符号臂超出读出动态范围时，原评分可能用一个空的参数区间与另一臂做差。Bacon 已修正。负控中，观测下界 0.709553 高于校准上限 0.669801，程序现拒绝该设置并保留原因。原 262,144 条合成记录重放后，旧同地签号差区间为 [0.074641,0.209922]，弱门的未分辨裁决也保持。Gibbs 跨组用 512 壳独立复核固定轴能量界，能量加权余项给出场能误差小于 0.001304670。两项检查分别针对统计可行性和无界观测量。

## 下一轮的决策顺序

1. **先验证访问权限。** 网络组优先检查两份是否真能独立重制、源端是否有跨份实联合门、跨次是否共用量子参考。声称排除一个全实候选之前，先说明如何界定共享参考及漏检；若只有单份产品统计，保留明确的等价反模型。
2. **再决定是否采集设备数据。** 在相同源、准备、时间和读出下随机切换固定轴门的开／关。设计冻结的最小物理差为 0.0055212；在给定的校准跨度、差分系统误差和漏读合同下，示例分配为校准 2,097,152 次，开、关各 3,200,000 次，全数 8,497,152 次。该数是可复算的前瞻设计。任意未受约束的差分漂移均能伪造这个信号，遇到这种情况应先改善对照，再投入采样。
3. **能量证书单独验收。** 固定探针能变化、驱动功的正号、初始场能范围和测量侵扰。只有同源开关功、探针能及其联合误差都足以确定符号，才能从第一定律判定原场能变化。独立的示例按开、关边缘表、能量上限核验、探针占据及其参考分配 **16,900,000 次启动**，在仪表转移和二阶矩前提下原场增能的上界可取估计值加 0.0042359375（ℏω₀）。这是另一个目标和资源方案，不能把与随机开关实验重叠的准备简单当成免费。点状场的瞬时真空方差发散，仪表预算限于展宽涂抹。记录复位的熵下界、指定载体的净能量、实机耗散分别记账。[开、关边缘见证与计量条件](local/ENERGY_WITNESS.md)
4. **用结果约束后续跨领域工作。** 将本轮验证过的“同一源、合法菜单、完整记录、误差预算”用于味相位及引力扰动的下一次提案；后两者另需强子/长程矩阵元及应力扰动输入，保持[原责任和停止条件](../cross_domain/README.md)。基础选择优先研究哪些可独立检查的组合/制备原则能排除当前的实模拟，或证明给定菜单上的等价。
