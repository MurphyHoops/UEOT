# Bacon 复核用参数与事件合同

基线 `940541cd464d8bccb9f7c553dbd3ebfefde596b7`。采用旧同地源的原剖面、同一制备时钟和整个 B＋场态。三段都以圆上原点为中心，空间支撑半径均为 \(R=L/6+L/40\)。保留所有余弦模。原 A、B 为 \(a=2/3,b=3/4,\lambda=3/10,g_{AB}=0,n=1/2,c=1/4\)，A 符号 \(s=\pm1\)，B 初态 \(+X\)。C 与旧源独立，B＋场的相关原样带入。

第三段起点 \(T=a+b+4=65/12\)，宽 \(h=2/5\)，有符号耦合 \(k=-1/10\)，无条件施加。C 在开脉冲时的 Bloch 向量为 \((16/25,-12/25,3/5)\)，能量投影 \(P_e=(1-X_C)/2\)。主合同取常开能隙 \(\Omega=1/2\)，在 C 自由绘景施加固定 \(Z_C\)，因此实验室的局域控制轴是 \(e^{-i\Omega P_e(t-T)}Z_C e^{i\Omega P_e(t-T)}\)。最终同测常规 \(Y_B\) 与 \(P_e\)，保留四种结果及每一个 s；读取 B 前不测 Z。第三段无需访问单个场模、原场数或场奇偶。

定义 \(d(k,t,h)_j=k(g_j/\omega_j)e^{i\omega_jt}(1-e^{i\omega_jh})\)，\(A=d(3/10,0,a), B=d(3/10,a,b), C=d(k,T,h)\)。场历史按时间从右至左为 \(D(vC)D(uB)D(sA)\)，\(u,v=\pm1\)。第三段的场能变为 \(\sum_j\omega_j[|C_j|^2+2s(3/5)\mathrm{Re}(\bar A_jC_j)]\)。令 \(\phi_{DC}=4\mathrm{Im}\sum_j\bar D_j C_j\)，则末态 C 的 \(2\rho_{01}\) 为 \((16/25+12i/25)e^{-Q_C+is\phi_{AC}}\cos\phi_{BC}\)，其中 \(Q_C=2\|C\|^2+4C^\dagger N C\)。C 能变为 \(\Omega[16/25-\mathrm{Re}(2\rho_{01})]/2\)。净驱动功是场与探针能变之和。相位在制备时钟求和；\(\Delta E_C\) 与末态读数均不受回到薛定谔绘景的 C 自由转动影响。
