# 同一场上的相位、能量交换与测量反馈

在第 71 章的原场上可以把探针相位读成能量记录。先把 B 的指定轴映到能级，再让 B 与**原圆柱场零模**交换一份能隙。原同地算例给出 \(p(+Y|s=+)=0.427005743276\)，第一次交换给原场净增能 **0.156704841066**。随后读取零模、按结果反馈，外驱对系统做功 **−0.427005743276**。下述确定的复位协议另付正功 **0.640508614914**。这些是模型内的期望值，单位为 \(\hbar\omega_0=1\)。工作介质、外驱、记忆和出射载体的账分别可查。

## 起点与权限

科学源为提交 **67aa5c4d9a7e77da3f2a74dfb717a711f885cca9**。取质量为 1 的自由实 KG 场，空间为周长 \(L=4\pi/\sqrt5\) 的圆。归一化低偶模 \((\omega_0,g_0)=(1,1)\)、\((\omega_1,g_1)=(3/2,3/5)\)，其余耦合来自原四盒卷积与平移侧瓣剖面。高模真空，两个低模为中心、无反常矩的 Gaussian 态，\(\langle a_k^\dagger a_l\rangle=N_{kl}\)，低模块对角 n、非对角实数 c。取 \(0\le |c|\le n\le0.6\)，数值点 \((\lambda,n,c)=(.3,.5,.25)\)。制备原点锁相。A 在第一段固定为 \(Z=s=\pm1\)，B 在第二段从 \(+X\) 开始。每一类 s 单独计数。原模型两探针裸 Hamiltonian 为零。[原场合同与归一化](../../correlated_bath/field/FIELD.md)

设 \(g\) 在时序中表示两段之间的**间隙**，模耦合写 \(g_j\)。在制备时钟的相互作用绘景定义
\[
 A_j=s\lambda(g_j/\omega_j)(1-e^{i\omega_j a}),\qquad
 B_j=\epsilon_j\lambda(g_j/\omega_j)e^{i\omega_j(a+g)}(1-e^{i\omega_j b}).
\]
同地 \(\epsilon_j=1\)，对径 \(\epsilon_j=(-1)^j\)。本文在公式中用 \(B_j\) 表示第二脉冲位移，用 B 表示探针。略去两条路径共有的标量相位，令 \(U_z=D(zB)D(A)\)。两个局域脉冲结束后的完整起点为
\[
 \rho_{BF}=\tfrac12\sum_{z,z'=\pm1}|z\rangle\langle z'|
                \otimes U_z\sigma_F U_{z'}^\dagger .
\]
A 保持同一 Z 本征态而可迹去。此式保留 B 与整个场的相干和相关。薛定谔绘景需同时恢复场的自由转动。后续的数、奇偶及能量都与该转动对易。

记 \(\Phi_s=4\operatorname{Im}\sum_j\bar A_j B_j\)、\(B_\pm=(B_0\pm B_1)/\sqrt2\)。原探针相干和原场裸能增量为
\[
 z_s=2\rho^B_{01}=e^{-Q+i\Phi_s},\quad
 Q=2\|B\|^2+4(n+c)|B_+|^2+4(n-c)|B_-|^2,\quad
 W_{\rm src}=\sum_j\omega_j(|A_j|^2+|B_j|^2).
\]
两段首末关闭；场均值初为零，两种第二段力等权，故裸场能变化由外部开关供给。原场初始正规序能量为 \(n(\omega_0+\omega_1)=1.25\)。一般 \(c\ne0\) 时场态随自由时钟进动。

## 原零模上的共振交换

零模数基可严格重标为 \(|2l+j\rangle\leftrightarrow|l\rangle|j\rangle,\ j=0,1\)。令 \(J=N_0\bmod2,\ \Pi=(-1)^{N_0}=1-2J\)。能量 \(N_0=2l+J\)，所有 \(l\) 扇区都有单位间隙。在 B 简并时施加 \(V_O\)，使 \(V_O^\dagger|1\rangle\langle1|V_O=(1+O)/2\)，其中 \(O=X\) 或通常的 \(Y\)，两种轴用不同 shot。随后突开 \(H_B=|1\rangle\langle1|\)，支付 \(p=P(+O)=(1+\mu)/2\)，其中 \(\mu=\operatorname{Re}z_s\) 或 \(-\operatorname{Im}z_s\)。

定义 \(S|i\rangle_B|2l+j\rangle_0=|j\rangle_B|2l+i\rangle_0\)，其余原场模恒等。取 \(H_{\rm ex}(t)=f(t)(1-S)\)，首末关断，面积 \(\int f(t)\,dt=\pi/2\)，即可在相互作用绘景精确实现 S。它与 \(H_B+H_F\) 对易，\(\langle1-S\rangle\) 在脉冲中恒定，故净开关功为零。写 \(q_o=P(J=1)\)，则
\[
 \Delta E_F^{(1)}=p-q_o,\qquad \Delta E_B^{(1)}=q_o-p,\qquad
 P_{\rm after}(N_0\text{ 奇})=p.
\]
这在任意相关输入上成立。用两套轴重做实验，取新奇占据概率 \(p_X,p_Y\)，由 \(\arg[(2p_X-1)-i(2p_Y-1)]\) 恢复旧相位；单轴只给相应投影。

**新增物理权限**为 B 的选轴、开合可控能隙、整圈零模的数分辨选通，以及配对奇偶翻转和读出。交换的带能量自由度属于原场。按每对偶奇态等强耦合需要非线性数选择。原有局域线性涂抹同时耦合多个模；全局均匀零模的选择不具备原两探针的局域支撑。后续全局交换和奇偶读出不能用于证明类空通信。有限精度选模、寄生第一余弦模、非均匀脉冲面积或失谐会改变上述单位能隙传递。

## 完整记录为什么需要联合态

取旧探针正结果位 \(i=1\) 和旧场奇偶位 \(j\)。交换后它们分别储于场和 B。下式也给只读场位时对 B 的条件预测；作交叉检查时可以再读 B 能量。设
\[
 h(v)=\frac{e^{-2|v|^2/(1+2n)}}{1+2n},\quad
 H=\langle\Pi\rangle=[h(A_0+B_0)+h(A_0-B_0)]/2,\quad q_o=(1-H)/2.
\]
为计算联合量，用 \(r=\mathrm{Tr}(U_-^\dagger\Pi U_+\sigma_F)\)。零模利用
\(D(-A_0)D(B_0)\Pi D(B_0)D(A_0)=D(-2A_0)\Pi\)；其余各模产生 \(D(2B_j)\) 和各自交换相位。得到
\[
 r=h(A_0)\exp\!\left[
 -2\sum_{j>0}|B_j|^2-4\!\left(n-\frac{2c^2}{1+2n}\right)|B_1|^2
 +4i\,\operatorname{Im}\!\sum_{j>0}\bar A_jB_j
 -\frac{8ic}{1+2n}\operatorname{Im}(\bar A_0B_1)\right].
\]
推导最后一步可把初态写成相干态振幅的中心 proper 复 Gaussian 混合，协方差 N 半正定。零模插入奇偶给振幅权 \(e^{-2|u_0+A_0|^2}\)。配方后总质量为 \(h(A_0)\)，振幅 \(u_1\) 的均值变成 \(-2c A_0/(1+2n)\)，方差变成 \(n-2c^2/(1+2n)\)。对剩余位移取特征函数即得 r。奇异热边界可直接在支撑子空间积分，或由连续性取极限。

置 \(C_O=\operatorname{Re}r\) 或 \(-\operatorname{Im}r\)，保留四个未条件化概率
\[
 P_{ij}=\tfrac14[1+(2i-1)\mu+(-1)^j H+(2i-1)(-1)^j C_O].
\]
旧同地、\(s=+,O=Y\) 时 \(q_o=0.270300902210\)，而 \(P(j=1|i=0)=0.28575495602,\ P(j=1|i=1)=0.24956327932\)。把源替换为两个原边缘的乘积，会使 \(P_{11}\) 增大 **0.008855084077**；两边缘和第一次平均交换能量却完全相同。这样可以区分“平均热账正确”和“联合源正确”。给定停止读数 \(i\)，交换的条件平均场增能为 \(i-P(j=1|i)\)，用原 \(P(i)\) 加权恢复 \(p-q_o\)。此处是可同时读出的两能量位的记录分解；没有对初始完整场做破坏相干的能量预测量。

## 测量、反馈与复位的物理循环

以下功取“外驱对系统做功为正”。测量记忆 M 首末能隙为零，初态 \(|0\rangle\)。一次读出在第一次交换后可立即停止并输出 B＋场的次归一条件态 \(P_i^J S\rho' S^\dagger P_i^J\)，其中 \(\rho'\) 为装载能隙后的联合态。完整反馈实验继续两种结果；表内均值按所有开始的 shot 计。

| 步骤 | 探针裸能变 | 原场裸能变 | 外驱功 | 记忆与输出 |
|---|---:|---:|---:|---|
| 原 A、B 局域脉冲 | 0 | \(+W_{\rm src}\) | \(+W_{\rm src}\) | 起始时钟固定 |
| B 简并选轴，装载单位能隙 | \(+p\) | 0 | \(+p\) | 尚未测量 |
| 第一次共振交换 S | \(q_o-p\) | \(p-q_o\) | 0 | 场奇偶储存旧轴结果 |
| 用场奇偶控制 CNOT 到 M | 0 | 0 | 0 | \(P(M=1)=p\)，与裸能量对易 |
| \(M=1\) 时外驱零模奇偶翻转，\(M=0\) 恒等 | 0 | \(-p\) | **\(-p\)** | 每个触发分支向驱动输出 1 |
| 再施加 S | \(-q_o\) | \(+q_o\) | 0 | B 进入基态，原场恢复到局域脉冲后的非选择边缘 |
| B 关隙并在简并点重备 \(+X\) | 0 | 0 | 0 | B 可开始下次实验 |
| M 突开能隙 \(\epsilon=3/2\) | 0 | 0 | **\(+\epsilon p\)** | M 增能 \(\epsilon p\) |
| M 与等隙真空端口共振 SWAP，M 回基态后关隙 | 0 | 0 | 0 | 端口获能 \(\epsilon p\)，M 精确复位 |

反馈是校准外驱的条件 \(\pi\) 脉冲。这里的负功是平均驱动功；随机充入低熵电池后可独立提取的功还依赖电池与记录的定义。记录可相干复制到 M、以 M 作控制，最后在出射端口读能量，给出同一测量仪器；按测得结果当场触发也给出上述分支统计。没有额外永久保存一份免费经典记录。若另行归档或擦除外部控制器日志，要另计其资源。

第二次交换后，非选择原场回到脉冲后的**整个边缘态**（略去自由转动）。把第一次交换和返回交换共轭起来，等效通道是在原 B 的所选基测量、重置 B，且不选择结果；局域迹保持操作保持场边缘。条件场态仍依赖记录。M 与场的相关在 SWAP 复位中转移到出射端口。M＋B 的工作循环闭合时
\[
 W_{\rm total}=W_{\rm src}+p-p+\epsilon p
              =\Delta E_F+E_{\rm out}=W_{\rm src}+\epsilon p .
\]
该端口每次使用一个新的纯基态自由度。可用冷的吸收端取走其能量；未经热化的出射记录具有能量与信息，不能一概当作平衡热。复位功由实际指定的开隙与共振门计算。有限温端口初含激发则 SWAP 后 M 有同样的残余激发；继续使用上表的完美读出会失败。这里没有用 \(T H_2(p)\) 估算实耗。[Landauer 原理的储库和有限尺寸条件](https://arxiv.org/abs/1306.4352)

**再次使用同一场**须区分两种合同。持续源直接从改变后的场边缘及相关开始；下一次试验一般不独立。若要求整台装置含原场都回到初始态，可引入同谱的服务场，预置为本次制备时钟的 \(\sigma_F\)，在末端把两整个场交换。交换与二者裸能量之和对易，理想净开关功为零。原场回到 \(\sigma_F\)，服务场带走 \(W_{\rm src}\) 净能及与出射记录的相关；上式右侧改记为服务场增能与端口增能。每个闭合 shot 消耗一份锁相相关场态和一个清洁端口。生产、输运、重新净化这些资源的工程代价未测，不能据此给出自维持热机效率。仅接受 \(i=1\) 时，独立重供合同下每个接受结果平均消耗 \(1/p\) 次开始、源准备和端口；停止在读出处的分支只计已执行操作，复用前仍需结算其复位。

**一次截模与长时间。** 谱和保留余弦模 \(j=0,\ldots,M=320\)；两处涂抹与正弦模的重叠均为零。令 \(H_M=2(80/\pi)^8/(10\kappa^3 M^{10})\)，\(\kappa=\sqrt5/2\)。任意间隙有 \(|A_j|,|B_j|\le2\lambda|g_j|/\omega_j\)，故所有高模相位余项不超过 \(16\lambda^2 H_M\)，真空衰减余项在 \([0,8\lambda^2H_M]\)；能量余项在 \([0,16\lambda^2(80/\pi)^8/(9\kappa^2M^9)]\)。r 的高模因子用同样的相位、衰减余项，H 只需零模。高模有热占据或与低模相关时须重新控制特征函数及能量尾。对于重复脉冲，同模位移可相干相加，单次尾界不能直接给无界时间的一致界；需要累积暴露控制或混合、耗散和储库补给的独立假设。

甚至在**精确原场**上，弱交换与长时平均的极限也可严格不交换。沿同一装载后的 \(\rho'_{BF}\) 单独重复 \(U_\theta=e^{-i\theta(1-S)}\)，中间无测量、反馈或复位。去掉共同自由演化后，第 m 次的 B 激发为
\[
 p_m=p\cos^2(m\theta)+q_o\sin^2(m\theta)+C\sin(2m\theta)
\]
其中有限实数 C 来自初始联合相干。对固定 \(0<\theta<\pi\)，几何级数给 Cesàro 平均 \((p+q_o)/2\)；固定脉冲数先取 \(\theta\to0\) 得 \(p\)。旧同地 Y 实验两种次序分别为 **0.348653322743** 与 **0.427005743276**。这是同源可逆交换的长期反例；不假定系统趋于 Gibbs 态。独立数值门检查也对 \(\theta=\pi/14\) 的完整 14 次周期核对该平均值。
