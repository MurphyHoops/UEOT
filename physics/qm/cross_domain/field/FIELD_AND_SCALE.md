# 同一局域探针的相位、因果性和两种有效展开

第71章用同地相继脉冲得到干预相位，用对径脉冲显示截模的类空伪信号。这次沿用同一个场、态、涂抹与探针读出，加入支撑逐点类时的实验、独立位置空间复算，以及有时间窗和频率阈值的高模消去。实验设计和数值目标在本轮首次运行前写入本地合同，全部时长均用场质量的倒数作单位。[合同](design.json) · [精确有理外包](result.json) · [原始场定义](../../correlated_bath/field/FIELD.md)

## 操作及同源观测

取质量为1的自由实 Klein–Gordon 场、周长 $L=4π/√5$ 的静态空间圆周、正能 Fock 表示。$κ=2π/L$，$ω_j=√{1+κ²j²}$。沿用原四个盒函数卷积及其卫星平移得到的偶剖面 $f$，支撑半径 $R=23L/120$；其傅里叶系数固定，$g_0=1, g_1=3/5, ω_1=3/2$。奇模在原点和对径两中心不参与这两次耦合。初态零均值、无反常矩，低两模的占据矩阵对角为 $n$、实非对角为 $c$，$|c|≤n≤3/5$；所有高模为与低模成积的真空。有限秩光滑修正保持 Hadamard 奇性。场、背景、制备时钟、涂抹与量子概率规则均有独立物理输入。

A 的探针以给定 $Z$ 符号 $s=±1$ 与场在 $[0,a]$ 局域耦合；B 在同地或对径以独立 $+X$ 准备，在 $[a+τ,a+τ+b]$ 与同一场耦合，并测 $X$ 或 $Y$。每个符号使用一组新试验。令 $A_j=g_j(1-e^{iω_ja})/ω_j$，$B_j=ε_jg_je^{iω_j(a+τ)}(1-e^{iω_j b})/ω_j$，同地 $ε_j=1$，对径 $ε_j=(-1)^j$。对初始浴一次取迹给出
```
Φ = 4λ² Im Σ conjugate(A_j) B_j
Q = 2λ² Σ |B_j|² + 4λ² n (|B₀|²+|B₁|²) + 8λ² c Re(conjugate(B₀) B₁)
z_s = 2ρ(+,-) = exp(-Q+i s Φ)
p(+Y|s) = (1−Im z_s)/2
```
这里 $Φ$ 来自已排好时间顺序的推迟对易响应，$Q$ 是路径差在对称二点函数下的二次型。自由演化引起的准备相位旋转保留在 $B_0^*B_1$ 内。B 的二元 $Y$ 读出在场上诱导 Kraus 算符 $K_y=(W_B^+−iyW_B^-)/2$；$W_B^±$ 是同一涂抹源决定的两种条件 Weyl 酉，共同相位不影响仪器。由 $Σ_y K_y^†K_y=I$ 得标签概率及合法非选择操作。对类空分离的 A 局域完备操作 $Σ_r L_r^†L_r=I$，微因果给 $[L_r,K_y^†K_y]=0$，故 B 的效应在 A 的非选择伴随映射下不变。条件选择 A 的标签要另计经典信息。紧支撑 C² 空间剖面和矩形开关用同一支撑外邻域的光滑源作一粒子范数近似，Weyl 强极限保持上述概率和交换关系。采用局域耦合、诱导效应和因果组合的操作背景。[Fewster–Verch](https://arxiv.org/abs/1810.06512)

## 四种时空设置及直接复算

下表取 $λ=0.3,n=0.5,c=0.25,s=+1$。相位以 rad 计，零值由因果支撑解析给出。

| 设置 | $a,b,τ$ | 两模相位 | 完整场相位 | 完整场 $p(+Y)$ |
|---|---|---:|---:|---:|
| 第71章同地，可有因果接触 | 2/3, 3/4, 0 | 0.163731618 | 0.209161320 | 0.427005743 |
| 第71章对径，逐点类空 | 0.2, 0.2, 0 | 0.001330794 | 0 | 0.5 |
| 同地，逐点类时 | 0.2, 0.2, 2.5 | 0.002076634 | 0.001975457 | 0.499041343 |
| 对径，逐点类空 | 0.2, 0.2, 0.1 | 0.002003324 | 0 | 0.5 |

后两组只改变源的位置或起始时刻，沿用同样的脉冲形状、时长和制备。对 $|δτ|≤0.05$，类时组有 $τ+δτ>2R$ 且最大总历时小于 $L−2R$，每个源点都能向每个读出耦合点发送类时信号，并且没有绕圈像进入光锥。对径组有 $L/2−2R−(a+b+τ)>0.15564$，加上同样大小的时序扰动仍逐点类空。后者在标称时刻用两模比较正负 A 符号，B 的两态迹距离为 $e^{-Q_1}|\sin Φ_1|=0.001972933$；这量化了近似模型的伪信号。完整场对此符号的判别优势为零，即使场噪声导致 $Q>0$。

独立位置空间计算采用一维空间的质量1延迟核，对空间圆周作像求和：
```
G_R(T,X) = (1/2) Θ(T) Σ_l Θ(T²−(X+lL)²) J₀(√(T²−(X+lL)²)).
```
在锥内，Bessel 方程给出齐次 KG 解，锥面处 $J_0(0)=1$ 给出波动方程的推迟跳跃归一化；正时支撑及周期化确定解。令 $T=τ+U_a+U_b$，$U_w$ 在 $[0,w]$ 均匀；$X$ 是两个独立 $f$ 分布的点的差。同地严格类时窗口内只余一个像，原 $g_0=1$ 的场重标定使相位为 $2Lλ²ab\,E[J_0(√{T²−X²})]$。用八个对称均匀盒加两项离散平移的卷积求 $X$ 的矩，按独立性展开 $E[(T²-X²)^m]$。截到 $m=18$，绝对余项受 $[(τ+a+b)^2/4]^{19}/(19!)²$ 控制。三个未用于匹配的时移均以独立位置空间区间与320壳的谱区间重叠并排除零。对径窗口内，位置空间核的每个像都严格在支撑外。

## 在哪个时间窗可以消去高模

取 $M=160$，动态自由度仅保留零模和第一余弦模。对同一对固定形状的源，令 $K_j=\overline A_j B_j$ 取中心间隔 $τ_0$ 的值。从微观源计算四个实系数和一个噪声标量
```
h_k = (4/k!) Σ_{2≤j≤M} Im[K_j(iω_j)^k],   k=0,1,2,3
q_h = 2 Σ_{2≤j≤M} |B_j|²
Φ_eff(τ₀+d) = Φ_low(τ₀+d) + λ² Σ h_k d^k
Q_eff(τ₀+d) = Q_low(τ₀+d) + λ² q_h.
```
高模真空无反常或跨模相关，因而 $q_h$ 与 B 的起始时刻无关。每个设置使用自己的中心，系数均由场谱匹配，无留出观测参与。高模对相位的交换响应及真空噪声各存一项；把浴在 A、B 之间重置会消掉整个有符号响应。

由原剖面 $|f_j|≤(80/πj)^4$，
```
H_M = Σ_{j>M} g_j²/ω_j² ≤ 2(80/π)^8/(10κ³ M^10).
|Φ−Φ_eff| ≤ λ² [4 Σ_{j=2}^M |K_j| ω_j^4 |d|⁴/24 + 16 H_M].
0 ≤ Q−Q_eff ≤ 8λ² H_M.
```
第一项是沿实时间 Taylor 展开的积分余项，使用 $|e^{iωd}|=1$。用 $λ≤0.4$，$|d|≤0.05$，两组的相位误差统一至多 **0.000090173902360 rad**，B 的任意固定二元测量概率误差至多 **0.000045086952653**。后式用等布居量子比特的半迹距离为 $|z-z_{eff}|/2$ 及 $Q,Q_{eff}≥0$。这项界覆盖声明的 $n,c$ 范围。$d=-0.05,0.02,0.05$ 三点的相位误差均小于 $2×10^{-9}$ rad（标称参数），点值只检验该点的算法。若将同一系数外推到 $d=4$，两组相位误差分别超过 **0.0486** 和 **0.0498 rad**。窗口外的对径装置此时允许因果接触。更换剖面、脉宽、高模态、探针策略或观察时间均需重新匹配。由这些有限时窗的界推至任意时间的混合、热化或马尔可夫极限仍需另证。

## 频率阈值

连续波线性响应提供另一种尺度检验。仅把高壳的推迟易感率作低频展开，正弦开关取推迟边界值。$χ_h(ν)=Σ_{j≥2}2ε_j g_j²/[ω_j(1-(ν+i0)^2/ω_j²)]$，前两模仍显式演化。匹配常数、二次、四次项时，各项系数由截至 $M$ 的谱负矩给出。记 $S_M=Σ_{j=2}^M2g_j²/ω_j$，$D_M=4(80/π)^8/(9κ²M^9)$，对 $|ν|≤1$ 取 $r=1/6$，误差至多 $(S_M r^3+D_M)/(1-r)<0.003650$（单位源）。第一被消去、实际耦合非零的壳在 $ω_2=√6$ 有极点，这个围绕零频的幂级数不能无条件越过阈值。全系统的低模极点仍在显式部分。矩形时间脉冲不带限，所以前一节的完整测量误差采用时间核余项；这个低频界单独用于带限线性响应。

从仓库根运行 `python -B physics/qm/cross_domain/field/match.py --check`，需要 mpmath。程序检查物理源哈希、支撑不等式、旧结果回读、正负时序偏移、独立坐标表示、全窗口充分界及越窗失败；所有输出端点向外取整为有理数。
