# 味物理留出合同与候选划分

基线 `67aa5c4d9a7e77da3f2a74dfb717a711f885cca9`。本合同先于本次外部数字查取和计算落盘。基线旧脚本已经印有两条混合频率；这是回顾性的跨通道留出，作者知道历史数据。不得称为前瞻盲测。冻结后不按留出结果更换 CKM 方案、模型、误差窗或终点。

1. 对两个既定父谱施加同一条独立必要条件：保留下来的手征 SU(2) 弱双重态满足 Witten 模二规范一致性。明确色重数、标量和重态的角色。交叉核对原异常与电荷测试。此步不把测到的三色或三代作为选择规则。
2. 在通常三色、三轻代的低能 EFT 中，额外假设一个重的实中性无色矢量、纯左手流；扣除普适项后，味矩阵正比于上型 Yukawa 的顶本征投影。轻夸克 CKM 是三阶酉矩阵。单一 VLL 算符，匹配与 QCD 演化对 d,s 共用。SM 顶盒与新振幅相干相加。在相同的短程近似下用一条频率固定共同模长，另一条频率是唯一主留出量。另给未对齐秩一系数的复循环相位投影以及何时能实测它。
3. 输入分割：树过程的四个 CKM 坐标来自轻介子 Kμ2/πμ2 的 |Vus/Vud|、Λb 半轻子 |Vub/Vcb|、独占 B→D(*)ℓν 的 |Vcb|、带电 B→DK 类时间积分干涉的 γ。只用原作者公布的树通道结果及其必要的强作用输入；禁用含 Δmd、Δms、εK、sin2β 的 CKM 全局拟合以及用混合比反推的 |Vtd/Vts|。格点 ξ 选 Fermilab/MILC 的三海味 B 混合矩阵元分析，保留其相关比值的误差。中性 B 实测质量用 LHCb 的独立质量谱。用 LHCb 精密 Bs→Dsπ 振荡的 Δms 定标。留出是 LHCb 半轻子 Bd 振荡的 Δmd，只在输入与预测已固定后查阅原文并对照。
4. 主预测是 Δmd = Δms (Md/Ms) |Vtd/Vts|² / ξ²。联合相关性缺失时，根据公布的误差分量形成确定的边际输入箱，对整个箱包围非线性映射，不把缺失的相关系数设为零。公开一倍及二倍公布误差的敏感性窗口；各分量线性相加（已发布的单一合并误差保留），不将该窗口冒称为已测联合置信度。标准误差以外的系统余项另列。
5. 预设两个明确的判据：先报告单算符、顶盒主项合同下的区间是否与相同倍数的留出误差区间相交；再允许每个混合振幅有相对主项不超过 2% 的复余项，报告最坏界。2% 是额外的有效模型包络，须区分它与有独立误差证书的 SM 计算。主裁决用二倍窗口；一倍只作敏感性诊断。若缺必需数据或树输入被混合观测污染，就缩限裁决并记录原因。任意额外味方向、右手算符、显著重轻混合或不受限的破坏对齐项均解除该预测责任。两窗重叠只能报告本次未否决。
