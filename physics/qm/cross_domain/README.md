## 哪些描述确实计算了同一件事

1. **场、有效理论、记录。** A 在紧支撑区域按符号制备，B 以固定 X 或 Y 读出；初始低两模态、空间剖面及制备时钟固定。推迟对易子给相位 Φ，对称二点函数给衰减 Q。严格类时的同地设置，全场 Φ=0.001975457087 rad，p(+Y|+)=0.499041343432。换到严格类空对径设置，完整场 p(+Y|±)=1/2，由局域完备操作及微因果推出；裸两模却给约 0.002003324384 rad。这个反例指出了删模破坏因果抵消的具体位置。加入从原场计算的四个时间核系数和一个噪声常数后，在两处中心各自的 绝对时移≤0.05 窗口，任一固定 B 二元读出误差≤0.000045086952653。独立的坐标空间推迟核与频谱核一致。该界的输出类型是 B 的边缘读出；改变 tester、联合末态或动作历史需要更强的误差界。[场、尺度及频率阈值](field/FIELD_AND_SCALE.md)
2. **同一场的能量。** Noether 保留脉冲后的 B–场联合态，增加带明示资源的原场零模偶奇交换。在旧同地 Y 设置，读出 0.427005743276 对应第一次场增能 0.156704841066；原始驱动功 0.296125651337，记忆复位和出射能量均为 0.640508614914，总驱动功 0.936634266251（单位 ℏω₀）。完整重启每次消耗一份锁相制备和清洁端口。零模是全局模式，此交换须取得选模权限。前两次局域探针的因果证明在其原时序内成立。同源弱交换与长时平均依次取极限，给出 0.348653322743 和 0.427005743276，展示了有限时精度对长期外推的限制。[操作、条件能量与复位](heat/README.md)
3. **高能谱与低能味。** Gibbs 对两个候选施加同一条弱 SU(2) 全局异常条件。双重态数是 12 和 30，且既定局域立方异常式模二已经保证其偶性；本规则筛去零个候选。在三色、三轻代、单一左手算符和新增的顶 Yukawa 对齐条件下，匹配、越顶阈值的 QCD 演化、格点矩阵元与标准模型顶盒干涉都进入 Bd/Bs 频率比。树级 CKM 与 Bs 定标给出 Bd 中心 0.55525 ps⁻¹，双倍输入误差箱 [0.40941,0.73379]；另加每道相对主振幅 2% 的假定余项，扩大至 [0.39336,0.76374]。留出实测 0.5050±0.0021±0.0010 ps⁻¹ 落在两箱内。误差箱的联合覆盖率未知。标准模型也给出相同名义比值，现有检验能质疑对齐合同，不能辨识新矢量的强度。[系数、矩阵元及数据来源](matter/MATTER.md)
4. **因果结构、几何与源。** Popper 在有向时钟、有限共同信号前沿及独立可校准的方向对称下推出 Lorentzian 共形类；尺度、局部光锥可及性及对称群是外部责任。非二次锥的18个构造方向在到达时误差 0.001 内仍排除所有非零二次型。有足够独立动量交换时，软无质量自旋2的 Ward 条件要求相关物种首阶荷相等；额外标量力和断开的扇区仍可区分物质。EH 与 R+αR² 可以用同一种物质耦合，后一作用量多出质量平方 1/(6α) 的标量。取共形自由场、不变态及固定重整化 G、Λ，在 de Sitter 得 ρ=NH⁴/(960π²)，代回引力方程求得自洽低曲率支。换态留下的 C/a⁴ 足以改变反馈。[假设、否决算例与精确代数](gravity/GRAVITY.md)
5. **真实背景与扰动。** Bacon 固定平直 Ωₘ=0.30、平滑 Λ 和 GR 尘埃增长模，用 WiggleZ 定距离尺度、6dFGS 定增长幅度，以 eBOSS 类星体三量和完整协方差做回顾性留出。z=1.48 的预测 (31.0811,13.3939,0.36973)，实测 (30.21,13.23,0.462)，依次为 D_M/r_d、D_H/r_d、fσ₈。允许未知跨巡天统计相关的联合 Q=1.2192，5% 阈值 7.8147；增长方向残差 +0.09227，任意允许两类示踪体有独立速度偏差即可吸收它。注入对照超过阈值。这里检验的是发表的压缩观测和指定示踪体模型。[观测资格、协方差和测量原文](cosmology/COSMOLOGY.md)

## 半经典背景能否在这次宇宙学留出中看见

几何线给出规定重整化处方下的均匀源 ρ=NH⁴/(960π²)+C/a⁴；宇宙学线使用其平直、尘埃加 Λ 的经典低曲率极限。为定量检验交接，再取 C=0、N=1、单独指定 H₀=67.6 km/s/Mpc，并固定今天的 H₀ 与 Ωₘ（相应确定一次 Λ）。令 e=1+Ωₘ[(1+z)³−1]，u=H²/H₀²，η=(t_P H₀)²/(360π)。守恒尘埃时低支满足 u=e+η(u²−1)，u(0)=1。实验窗口内 1≤u≤2e，故相对经典候选的径向距离减小比例 ≤2ηe，积分得到的横向距离也服从同一全窗上界。在 0≤z≤1.48 上该界为 **1.31×10⁻¹²⁴ 以下**。这解释了上述距离数据为什么无法分辨此单场反馈。归一化及 N 是此比较所加的物理输入。扰动响应还需要 δ⟨Tμν⟩、状态扰动及其反项；经典增长检验只能检验其所用经典极限。[同一红移窗的计算](background_limit.py) · [Planck 时间来源](https://physics.nist.gov/cuu/pdf/JPCRD2022CODATA.pdf)
