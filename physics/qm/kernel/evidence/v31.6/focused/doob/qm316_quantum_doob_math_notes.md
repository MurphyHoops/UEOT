# C：有限非交换量子存活与可逆过滤 Doob 变换——数学说明

这份说明供 root 整合总著。当前源仍在 focused Lean 编译；正式结果、最终 SHA、目标清单与退出码以 `qm316_quantum_doob_report.md/json` 为准。

## 精确对象和依赖

源对象是已有 `Instrument ι O κ` 的实际选定结果 `o`。其成功映射是 `I.branch o X = Σk Kk X Kk†`。重复成功算符并非另造迭代，而是现有 `recordOperator` 对真实重复词 `List.replicate n ((),o)` 的值。

本模块从已有有限复矩阵量子层出发，使用其 PSD、密度、Kraus 完备性、实际记录和 Heisenberg 对偶。它没有直接调用 UEOT Core 的 QSD/Perron 定理，因此标签应是“既有 QM 量子层内的严格推进”，不能写为“直接从 Core 推出量子 Doob 或量子力学”。

## 右特征态与有限 QSD

对实际密度 ρ、实数 r，给定实际矩阵等式 Φ(ρ)=rρ，归纳得到 Φⁿ(ρ)=rⁿρ。因此实际重复成功词的概率是 rⁿ。r>0 时每个有限 n 的该概率严格正，现有 normalize 构造出的条件密度严格等于原 ρ。由源仪器的概率界进一步得到 0≤r≤1。

这里没有把“条件态不变”预先放入输入结构；它由实际记录算符、迹以及正质量归一化推出。

## 左特征度量与完整 Doob 仪器

给定矩阵 S,T 以及 ST=TS=I，定义 G(X)=SXS†、G⁻¹(X)=TXT†、H=S†S。左谱条件是实际 Heisenberg 等式 Φ*(H)=rH，r>0。

令 Mk=SKkT。逐项矩阵结合律和共轭转置证明

    Σk Mk†Mk = T† Φ*(H) T = r T† H T = rI.

因此权重恒为 r⁻¹ 的 WeightedInstrument 完整。再调用已有 sqrtWeightedKraus/toInstrument，得到真正普通 Kraus 仪器，Lk=√(r⁻¹)SKkT。目标完备性由左谱式推导，没有作为前提提供。

其单出口实际通道 D 满足对所有复矩阵 X

    D(X) = r⁻¹ G(Φ(G⁻¹(X))),
    Dⁿ(G(X)) = r⁻ⁿ G(Φⁿ(X)).

不要求 X 对角、Hermitian、PSD，不要求 Kraus 两两交换。

## 过滤归一化和任意初态有限条件化

对每个已有 Density ρ，G(ρ) 为 PSD。若它迹零，则 PSD 迹零定理令 G(ρ)=0；施加 G⁻¹ 得 ρ=0，与 trace ρ=1 矛盾。因此 cρ=tr G(ρ)>0 是由可逆性证明的结论。

定义 F(ρ)=G(ρ)/cρ。F 是归一化数学过滤，通常非线性；S 未被假设为收缩，故 cρ 不是自动具有物理概率解释的量。实际源成功概率使用的始终是 successMass。

仅凭左谱式，对任意复算符 X 的命名 Lean 结论是实迹关系

    Re tr G(Φⁿ(X)) = rⁿ Re tr G(X).

这与源码的 mass 定义完全一致。在下述 PSD 输入上迹本身为实数，可直接写 tr。完整复迹关系在数学上同样可由 trace_heisenberg 推出，但本轮没有另设该复迹类型的命名定理。

对任意初始密度 τ，这一等式和 cτ>0 使每个有限成功概率 pn=tr Φⁿ(τ) 严格正。再把上述矩阵 intertwining 与归一化因子消去，得到

    F( Φⁿ(τ) / pn ) = Dⁿ(F(τ)).

这条式子并不假设 τ 是右特征态，也不是无限条件极限。若另有右特征密度 ρ，则 σ=F(ρ) 是新实际 channelState 的不变态。

## 有理二维见证

成功 Kraus 为

- K0=(1/4)I；
- K1=[[1/4,0],[1/2,0]]；
- K2=[[0,1/8],[0,1/4]]；
- K3=0。

失败 Kraus 为 diag(3/4,7/8)、diag(1/4,1/4)、diag(0,1/8)、diag(0,1/8)。成功 Gram=diag(3/8,9/64)，失败 Gram=diag(5/8,55/64)，两者相加为 I。

采用 ρ=(1/5)[[1,2],[2,4]]、r=3/16、S=diag(2,1)、T=diag(1/2,1)。实际左右特征式均成立，H=diag(4,1)，cρ=8/5，σ=(1/2)[[1,1],[1,1]]=|+⟩⟨+|。这里 8/5 是数学过滤的归一因子，源的每步 QSD 成功率是 3/16。

实际 Doob 通道对全部复矩阵的公式为

    D(X)=(1/3)X+(tr X/3)[[1,1],[1,1]].

密度上等价于三分之一恒等通道加三分之二 reset-to-plus。公式使用复迹，因而覆盖非 Hermitian 算符。见证并非上一轮对角输出的 measure-prepare 嵌入：K1K2≠K2K1，且 Φ(E01)=(1/16)E01。

## 控制与边界

- 删除失败族后成功族 Gram 不等于 I，故不能把原成功支直接称为完整通道。
- 均匀密度 I/2 的一步成功概率是 33/128，不等于 QSD 率 3/16；rⁿ 概率式需要右特征态前提。
- ρ 与其过滤态 σ 不同。
- 新仪器的可见出口是 Unit，Kraus 指标在通道内求和。因此新重复成功词质量为 1 是迹保持单出口通道的性质。非平凡的动态结果是全算符迭代 intertwining、任意初态实际有限条件化连接和右特征密度的实际平稳态。
- 本轮没有证明把 Kraus 指标拆成可见结果后的任意细粒度监测字串关系，也没有证明跨多个操作的任意记录字串关系。
- 未证明一般 CP 支的左右谱数据存在性、严格正左谱数据的普遍可得性、主谱性、不可约/混合条件、QSD 唯一性、无限条件极限或一般收敛率。有限例中的右特征密度和 σ 都是秩一，不能误称忠实满秩平稳态。
- 上述所有结果预设现有有限复矩阵量子状态与 Kraus 层，未完成从 UEOT 选择复数场、量子正锥、张量复合或 Born 规则的重建。
