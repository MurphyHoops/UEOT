# 钨环源与原子相位的实测复算

Chris Overstreet 等的实验把钨环安装、移除，再比较铷原子干涉仪的相位。52ℏk 干涉仪的两条轨迹相距约 25 cm，另两台 4ℏk 测量的中点轨迹分别匹配这两条臂。三个配置在分开的启动上测量。论文第 2 页图 2 及第 3 页正文定义了超过中点近似的相位；数据以各配置有环减无环报告。[原论文](https://doi.org/10.1126/science.abl7152) · [作者稿](https://par.nsf.gov/servlets/purl/10340035)

最后一列按相同名义权重，对所有分量及重复运行的协方差取最坏情形，由标准差的三角不等式得到；它是条件于已给边缘标准差的界。表内没有逐次探测记录、整张协方差矩阵或可独立重做所有系统误差的校准资料。由这里重算的两点不能重新宣告全文的 7σ 似然检验。作者对理论曲线的无自由参数计算亦未作为本次独立重建。

再对夹住约 6 cm 中点响应零点的上述两个高度各取一半权重，同高度内各次运行等权，得单一回顾性对比 −155.8173 mrad。允许任意相关时，其边缘标准差给出可达的最坏标准差 66.6611 mrad；条件于高斯近似时的 95% 区间约 [−286.47,−25.16] mrad，若只假定方差有限，Chebyshev 95% 区间约 [−453.94,142.30] mrad。这项敏感性检查保留是否排零对误差分布和未计系统偏差的依赖。两个高度都不是 6 cm 处的实测。

这一基准真实连接“已知外部源的有/无—不同空间采样的原子读数—单一差分相位”。它为本轮推断提供可实跑的引力与量子探针交点；对同一量子标量的绝对重整化应力、自引力及本轮热谱候选，还需要相应制备和联合记录。[代码](replay.py) · [全表复算](result.json)
