# 本轮反思：源的可区别性、实际总源与约束历史必须分别验收

## 1. 改变了什么关键判断

前轮已把原实际局域态、同态运输、法向数据和共同正窗接到可复算的投影残差；
也已排除旧角向制备在共同内部对称合同下产生新的不变引力记录。
本轮因此没有继续压低那一个 RMS，而是直接检查总源及约束。

最强排除结果是完整 AE 密度方程的几何一阶变化与 Einstein 侧精确相消。
原实际态的全空间密度方差仍严格为正，所以其“独立噪声加零初值逆”的齐性
线性扩张没有绝对约束 baseline。相同密度噪声差不能修复这一点。
这不否定已经存在的确定性 mean-SCE 解。

## 2. 排除以后实际推进的正向路线

在同一两场模型的 k=2 简并热能量块中构造 rho_plus/minus。
它们正、正常、Hadamard，保持完整 W2、各场热边缘及全 Hamiltonian 谱，
所以同一精确静态平均几何成立；完整局域应力噪声却有一个非零纯压力差。
这个方向改变的是内部不变扇区权重，超出了旧角向旋转等价类。

随后不是停在噪声核：全阶有限壳层影响已闭合，并给出一对明确平滑的平衡
几何脉冲。零模相位差严格为零，beta2 有严格非零下界，全部高模的
Hilbert-Schmidt 和真空重叠受控，故全自由场影响幅度差严格非零。
这些几何是 prescribed histories，不是已证明的自洽引力解。

## 3. 由源转向器件又完成了什么

原热态不能通过目标自身幺正得到该新谱。一个明确纯记忆 dilation 完成
全部结果且保持自由能量，熵减少和互信息均已计入；实际输出仍保留关联。
c=w 的 signed difference 给制备后完整记忆模型的总源相对定理。

进一步用真实 U(2) 简并自由场载体承载内部记忆，在包含所有对产生的完整
表示扇区上证明未来引力不变代数的严格因子化。载体自身的非零 mean、
noise 与 response 全部保留。这里能闭合未来相对问题，却不能把载体删去，
也不能把旧 bare 背景与响应搬到新总模型。

另一个独立自主 chi benchmark 确有正动能、非平坦场空间、守恒全源、
同一经典 GR 历史及有限读出增益。其总 stiff 能量保持不变，内部信息转移
本身不制造总引力变化。它证明一种自主经典机制存在，不能替代上述量子门。

## 4. 再次反思后已关闭的误用

- 同源核、同几何初始边缘仍不固定曲率方差：交叉块可以改变乃至取消一个
  预定线性测试。合法齐次切向必须携带同步量子态数据。
- Gaussian 辅助增量的取消不等于取消实际量子压力象限；明确的 Robertson
  不等式阻止有限资源正常联合态作后一种取消。
- 完整因果逆保留快极点。有限初片正弦强迫的 UV 渐近排除原 C-infinity
  平坦过去合同，不能把短窗卷积界升级成完整准备历史或长时稳定性。
- 全局 NOON 状态在任意空间开区均可区别。有限 cap 的无选择局域准备
  若还没有因果覆盖该区，就不能产生这对全局输出；现已给出准备时间
  必要界与有界局域观测见证。先前的“全局门”缺口因此有了具体资源门槛。
