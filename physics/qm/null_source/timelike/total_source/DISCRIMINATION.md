# Exact source discrimination and limits on a downstream readout

The shell difference has eigenvalues +2c,-2c, so its trace distance is 2c.
At the main endpoint c=w the complete memory output also has trace distance
2w. Any common linear quantum channel with the same independent environment,
followed by a reader, has record total variation <=2w. A gravity reader
inherits this bound only if gravity belongs to that specified common quantum
channel. It is not a bound proved for a nonlinear mean-SCE law or an
unspecified hybrid dynamics.

The three-outcome measurement P_+, P_-, I-P_W has probabilities
(w+c,w-c,1-2w) and (w-c,w+c,1-2w). At c=w, any non-outside flag identifies
the preparation perfectly, but it is rare. With equal prior probabilities
the one-shot optimal error is 1/2-w. For n independent preparations,
\[
 P_{\rm error}^{(n)}=\tfrac12(1-2w)^n.
\]
Outside flags have identical conditional states and contain no information;
the non-outside supports are disjoint. This also proves optimality, not only
an achievable test. The checker computes the first n with error <0.05 in
the entire frozen parameter interval.

The universal thermal-block maximum is
w<=4^8/5^10=65536/9765625, at q=1/5.
The inherited n fixes a much smaller w. Repeated preparations consume fresh
purity/resources from PREPARATION.md; the count does not certify feasibility.

This optimal source measurement is not a constructed local gravitational
instrument. A nonzero influence amplitude on prescribed histories supplies
neither a record-TV lower bound nor a calibrated gravitational signal.
