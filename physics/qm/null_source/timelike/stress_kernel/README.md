## 3. 完整 \(C_0\)：怎样避免把截断和均值尾冒充噪声

取原已固定的测试
\[
F(\eta,\chi)=b(32(\eta-3/32))\,b(8\chi),\qquad
b(x)=e^{-1/(1-x^2)}\mathbf1_{\{|x|<1\}}.
\]
其支撑为 \(\eta\in(1/16,1/8),\chi<1/8\)；
\(D=\int F\rho_f\,d{\rm vol}_g>0\)。
对应尺度归一 \(F_\lambda=\lambda^{-4}F\)。

对完整随机相干位移态，精确分解是
\[
\operatorname{Var}(A_\lambda)
=\lambda^{-8}C_0+d_\lambda^2\lambda^{-6}C_1
+\operatorname{Var}(Y^2)d_\lambda^4\lambda^{-4}D^2.
\]
新偏置符号制备保留 \(\mathbb EY=s/2,\mathbb EY^2=1\)，但
\(\operatorname{Var}(Y^2)=0\)；旧制备该值为 \(3/4\)。
混合态一般非 Gaussian；只有中心准自由参考场使用 Wick 分解。

[完整噪声证明](noise/README.md)先将中心二次方差写为
\[
C_0=\frac12\|B\|_{\rm HS}^2.
\]
使用实际准备态的全部实球谐、全部简并度与正则零模，在 \(K=256\) 分块：
\[
C_0\le\frac12\left[
N_{LL}^2+2N_{LH}^2+(N_{\rm main}+N_{\rm err})^2
\right].
\]
低块和混合块由全模能量与空间 Bessel/Parseval 控制；
高高正频主部做三次时间分部积分，利用真实紧支撑平滑窗消去边界；
实际准备相对高阶 WKB 的误差用此前已证的 \(D_5/k^5\) 控制，
并单独计入，不把均值重整化余项直接当成噪声余项。

实际块上界分别约为
\(3146.196,\ 3045.352,\ 1133.425,\ 415.434\)。
得到
\[
C_0<1.5422920\times10^7,\qquad
\boxed{C_0/D^2<5.189752\times10^{15}}.
\]
沿用已冻结的 \(C_1/D^2<1722.590\) 后，新的充分尺度通过完整噪声门。

审查还保留两个容易失真的地方：对 WKB 的对角相位修正必须保留；
独立 \(k,l\) 的区间因子用普通区间乘法，不按同一变量平方压小区间。
主审另外执行 \([-1,1]\times[-1,1]=[-1,1]\) 的负控。

在旧 \(\lambda=8192\) 上，这个保守证书给出的完整相对方差上界仍大于 1。
它无法证明该尺度低噪声，也无法证明实际方差很大。
选择 32768 是一项已验证的充分构造，没有宣称最小尺度或最优常数。

## 4. 平均源泛函相同，完整噪声核不同

[响应线](response/README.md)将旧固定背景上的二点恒等式升级为
**每一个共同合法光滑度规上的恒等式**。
固定同一光滑辅助过去、完整 Cauchy 数据、位移初值和重整化方案，
再用各度规自己的 KG 传播算子传播，则
\[
W_{\rm old,full}^g=W_{\rm new,full}^g=W_g+f_g\otimes f_g.
\]
因此
\[
\langle T_{ab}\rangle^g_{\rm old}
=\langle T_{ab}\rangle^g_{\rm new}.
\]
新旧完整平均 RSET 泛函及一切已经存在的共同度规变分相同；
同一引力方程、初边值及候选几何类下的平均 SCE 解集也相同。
“相同”本身不证明该解集非空，不证明映射可微或有某一范数界。

对任意合法实张量测试 \(H,K\)，更强的有序连接核差为
\[
\boxed{
\mathcal C_{\rm old}(H,K)-\mathcal C_{\rm new}(H,K)
=\frac34T[f_g](H)T[f_g](K).
}
\]
右端为实、对称、正半定秩一项。因此推迟应力交换子相同，
而对称噪声不同。不存在不附加热平衡等条件的通用反推，
可从共同平均值或推迟响应唯一恢复本题的完整噪声。

主审用四个正则变量、合法纯 Gaussian 协方差与共同辛演化，
独立核对有序二次协方差、交换子归一和秩一传递。
这是有限正则代数的交叉验证；无限维尾的证明仍来自噪声线。

## 5. 同一个局部测试已经接到可测的度规响应

本轮不只写抽象符号 \(\delta W\)，而是对实际空间变化的 lapse 族
\[
\delta g_{ab}=2\epsilon\alpha\,u_{\lambda a}u_{\lambda b},
\qquad
\alpha=\frac{F}{D\lambda^2}
\]
展开 KG 算子。空间度规保持固定。对背景解，
\[
\delta\Box\phi
=-a_\lambda^{-2}
\bigl[2\alpha\Delta_{S^3}\phi+\alpha'\phi'
+\nabla\alpha\cdot\nabla\phi\bigr].
\]
空间梯度项没有删掉，初值属于共同不变过去：
\[
\delta\phi=-E_{\rm ret}\delta P\,\phi,\qquad
\delta W=-(E_{\rm ret}\delta P)_xW-(E_{\rm ret}\delta P)_yW.
\]

canonical Hamiltonian 固定生成元的号与尺度：
\[
G_\lambda=-\frac{\lambda^2}{D}A_\lambda,\quad
\operatorname{Var}G_\lambda
=\frac{c_0}{\lambda^4}+\frac{d_\lambda^2c_1}{\lambda^2},
\quad c_i=C_i/D^2.
\]
对后续窗口 \([5/32,3/16]\) 的固定 Weyl 效应 \(0\le E\le1\)，
在声明的弱导数存在合同下，
\[
\boxed{
|\partial_\epsilon P_\epsilon(E)|_{\epsilon=0}
<0.06710438.
}
\]
这是同一全模式噪声界的一项实际操作后果。
该 lapse 族在 \(|\epsilon|\le1\) 上的相对 \(g_{00}\) 变化
小于 \(4.624143\times10^{-6}\)，且保持正 lapse。

数值很小还依赖扰动轮廓本身的 \(\lambda^{-2}\) 归一。
若固定相对 lapse 轮廓，生成元方差变成 \(c_0+d_\lambda^2\lambda^2c_1\)，不衰减。
代码执行了此归一化负控。

只有 \(\epsilon=0\) 的斜率被认证。
没有有限扰动概率带、统一路径估计、完整 RSET 作用素范数或自洽修正几何。
局域 Hadamard 减除、显式几何变分、Ward 恒等式和高阶引力分支
仍须在下一步的完整响应中一起承担。

## 6. 几何读出：合法测试、初值相关与时钟

[几何线](geometry/README.md)审查的是此前已解的齐性算子
\[
L=\partial_\eta^2+1-3\sec^2(2\eta).
\]
令 \(u,v\) 为其两个基本解。读出 \(q\in C^\infty_0(0,T)\) 经
推迟核拉回成噪声测试后，零延拓在初刻光滑的充要条件为
\[
\int q u=0,\qquad\int q v=0.
\]
任意非零非负 \(q\) 都不能通过这里的 \(v>0\) 矩条件。
这是当前初刻截断与分布定义域的判断，不是禁止一切正几何读出；
改变准备过去或光滑开关应另行检查。

显式构造 \(q=L\psi,\ \psi=b(32(\eta-3/32))\) 后，
伴随拉回恰好为 \(\psi\)。
它同时消去全部齐次初值贡献，连同初值与源的相关项。
若不消除初值，仅保持两态内禀初值的边缘分布相同，
仍不足以从诱导方差降低推出总方差降低；代码给出相关反例。

另外，\(q\) 是有共同绝对标尺的尺度读出。
令 \(A=\sqrt{3\cos2\eta}\)，则
\[
LA=-36/A^3,\qquad
\int qA=-4D_\psi,\qquad D_\psi=9\int\psi/A^3.
\]
自然相关经典幅度响应
\(\beta_{\rm amp}=(d_\lambda^2/4)A(Y^2-1)\)
给出非零绝对读出
\[
\int q\beta_{\rm amp}=-d_\lambda^2D_\psi(Y^2-1).
\]
但固定共形标签下，
\[
3[\beta_{\rm amp}(\eta)/A(\eta)-\beta_{\rm amp}(0)/A(0)]=0.
\]
纯经典精确族
\(a_M^2=\sqrt{M/3}\cos2\eta\) 也有
\(V_M(\eta)/V_M(0)=(\cos2\eta)^{3/2}\)，完全不含 \(M\)。

**这个盲区不能外推到共同固有钟。**
若 \(a_\epsilon=(1+\epsilon\kappa)a_0\)，固定 \(\tau\) 会改变共形取样点，
\[
\delta y|_\tau=-3\kappa h\,\tau/a_0,
\]
通常非零。原相对体积仪器也不能在缺少初片绝对尺度时直接重建绝对 \(q\) 读出。
允许每个幅度具有不同条件几何还会改变 Weyl 传播和标定；
本轮固定共同背景的分类证书不适用于那一新合同。

最后，空间 bump 平均有真实通量
\(J^i=-A^{-2}\phi'\nabla^i\phi\)。
用 \(\phi=u(\eta)\cos\chi\) 可明确显示遗漏通量的错误。
因此齐性 ODE 不自动给出局部张量引力响应。

同一个密度 \(F\) 可以进入完整线性化约束合同下的 Hamiltonian 残差组合：
其随机部分是 \(\xi(F)\)，可使用本轮方差界。
但裸度规扰动、标量响应、量子响应和规范责任不能从该组合中各自分离。
当前背景还不是已构造的全 SCE 背景，完整约束系统仍待解。

## 9. 后续责任已经改变

原来的第一阻塞是“指定测试的完整二次噪声没有数值界”，本轮已关闭。
现在最接近的三个可验收出口是：

1. **完整量子响应的定量控制。** 把已经确定的推迟态变分、
   显式几何变分与局域重整化项放入同一个张量作用素，
   给适用函数空间、规范/初值与响应范数；若要有限扰动概率或噪声，
   再给路径上一致估计及二阶余项。
2. **真正约束相容的局部几何读出。** 构造完整线性化 Einstein—标量/RSET
   系统及合法伴随读出，选择共同固有钟与可实现绝对标尺。
   接着再处理非线性 SCE 存在、稳定性及精确解距离。
3. **完整装置与外区。** 给外区量子态、光滑匹配、准备与驱动应力、
   同一背景/时钟下的真实校准和完整成本；取得数据后才升级经验轴。

Core 只读，GI 不在范围。正式书稿、Lean、经验状态和 Core 独立物理选择保留原身份。
本轮是一个有数值出口与负控的研究增量，不是完整统一物理结案。
