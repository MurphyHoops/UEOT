# 一个可代回引力方程的量子应力，以及它能区分的物质谱

## 指定态的平面源

沿用各向同性无焦平面脉冲，取零宇宙学常数、用实测牛顿常数并将平直真空能定为零。在 Rosen 图 g=p(U)²η、du=p²dU 上，仿射坐标差与共形坐标差的比值记为 S=Δu/ΔU。世界函数为 σ=Sσ_flat，Van Vleck 行列式的正平方根为 S/[p(U)p(U′)]。直接验证了 Hamilton–Jacobi 方程与混合二阶行列式。指定共形拉回态的两点函数恰是 Hadamard 主项；R=0，最小耦合无质量标量的波算符作用于仅依赖 U 的输运系数也为零。因此尾项、该态的光滑余项和局部守恒修正均为零。Ric=2K du⊗du，du 平行且为零向，故 □Ric 和曲率平方变分也消失。该结论依赖完整参考态的选择，仅凭入射区内测得零均值不足以指定它。[位分裂公式](https://arxiv.org/abs/gr-qc/0512118) · [几何与探针核验](plane_reference.py)

在此方案中，相干位移 Af(u) 的绝对应力恰为 A²f′² du⊗du。此前用于预报探针的同一态与同一度规满足半经典**平均应力**方程。开门后仪器的应力、单次测量条件态、以及无限横截面的总能量各需另计。有限球有非零标量曲率，不能直接采用此处的真空应力值。[独立应力与量子界](quantum/README.md)

## 有限球内域中的自洽平均反馈

回到有正空间曲率的均匀内域。取守恒动量 P=a³φ̇ 的最小经典标量，以及一个自由、无质量的共形量子场。后者的局部态取辅助闭 FLRW 上共形真空的限制。两模型采用相同 P=3√3、同一固有时规则与 G；令 H=ȧ/a、F=H²+1/a²、k=8πG/3。场内容通过 Euler 异常系数 κ=a_E/(16π²) 进入。四维迹与应力守恒给

    T = −κ E₄ + b □R,                     E₄=24F ä/a ,
    ρ = 6κ F² + b[H Ṙ + R F − R²/12] + C/a⁴ .

第二式逐项满足 d(a⁴ρ)/dτ=−Ha⁴T。C 是齐性无迹辐射的态常数。对无 D 型迹项的方案，静态半径 a 的三球共形真空能为 3a_E/(4a)，恰由 6κF² 给出，故 C=0。使**总** b 为零还需固定引力侧的有限 R² 耦合，仅改记号不能实现这一物理选择。[Herzog–Huang，第 32 式及其后对方案的说明](https://arxiv.org/pdf/1301.5002)

在这个给定选择下，ρ_s=P²/(2a⁶)。将量子应力代回 Friedmann 方程并选择连续通向经典解的根，得

    B=kP²/(2a⁶),    F=2B/[1+√(1−24kκB)],    H=−√(F−1/a²).

工作窗内判别式严格为正。正负源的 P 翻号保持同一解。把源标尺固定为 P，而让初始转折半径随约束调整：没有共形场时为 √3，增加一个实共形标量后为 1.73206096347。以实测曲率半径 a=0.94√3 为停止条件，预测收缩率 H 从 −0.32548175038 变为 −0.32550698618，差为 **−0.0000252358**。两条解分别从自己的转折点到达同一个物理半径；半径触发的观测不等于同一时刻的差。程序还对两种飞行时长和有限壳的因果范围作了包含积分。[正向与反演程序](anomaly.py)

在允许 C 未知时，观测 X=a⁴F² 和 D=a⁴(F/k−Π²/2)，其中 Π 是独立标定的单位法向场导数。它们满足 D=C+6κX。在三个规定的半径以 a、H、Π 各 10⁻⁸ 绝对容差生成模型读数。前两个读数给一个实共形标量当量 [0.98224895,1.01775108]，第三个读数通过留出；加入从初时即守恒的尘埃 0.01/a³，会在拟合时产生负当量，最后一次残差也排除原模型。该项计算采用有限内域的均匀演化。外部半经典约束、最小标量本身的真空应力及装置准备尚缺完整解。在保持相同无量纲经典曲率形状的尺度变换下，异常反馈相对经典曲率按 ℓ_P²/L² 缩小；上列无量纲差值不能充作宏观仪器灵敏度。

另在**原冻结经典度规上**消去未知常数、R、□R 三个迹项。令 q=a₀⁴/a⁶，则 R=−6q、Riem²−Ric²=24q²、□R=216q²−144q/a²。四个不同尺度因子给 1,x³,x⁴,x⁶ 的满秩组合，x=(a₀/a)²。因此单一可调 R² 系数无法在全窗隐藏额外实共形标量的迹。归一绝对权重和为一，本例消元后只余约 −5.50×10⁻⁹ 的应力迹差。模型误差大于它时，此测试不能给出裁决。[共形标量迹异常](https://doi.org/10.1103/PhysRevD.17.1477)

## 同一物体的内核、真空外区和热制备

自由实共形标量、两分量 Weyl 费米子、独立 Maxwell 场的数目记作 (s,w,v)。任意态的局部共形迹中，360a_E=s+11w/2+62v，120c_W=s+3w+12v。原内核共形平坦，冷态平均反馈只识别前一行；一般交互作用还会有 β 函数、质量与阈值迹项。[系数与归一化](https://cds.cern.ch/record/1288104/files/v41p2031.pdf)

原有限球的正则外区在物质到达前是 Schwarzschild 真空，μ=GM=7565/26208，C²=E₄=48μ²/R⁶，□R=0。独立比较面积半径 2 与 3 的迹，11 个实标量与 2 个 Weyl 场虽有同样的 a_E，它们的“加场应力迹”之差仍给 **1.50409×10⁻⁵** 的径向对比。这里使用同一经典背景计算量子应力的相容性；完整反馈后的外区不能继续假定 Schwarzschild。转成一阶 Ricci 信号还需相同的重整化引力参数、其他应力和受控高阶项。

两行异常量共同仍留严格整数盲方向 (48,−20,1)。例如 48 个实标量加 1 个 Maxwell 与 20 个 Weyl 均给当量 (110,60)。为获得独立第三行，给已指定的辅助三球共形态施加热/冷制备对照；共形逆温为 β，局部温度按 1/(aβ) 转移。计算 C 的热增量，实标量取频率 n、简并 n²；Weyl 取 n+1/2、简并 2n(n+1)；Maxwell 取 n、简并 2(n²−1)，这里 n 从 1 开始。每项分 Bose 或 Fermi 占据除以 2π²；以正项几何级数向外界住高模余量。这是独立自由物理极化的热谱，未施加现实非 Abelian 强作用的色单态投影。[单粒子谱](https://arxiv.org/abs/hep-th/0310285)

两个候选在 β=3 的 C 热差为 **0.10055189949**。若两异常量已被独立锁入相应的半整数及整数格，并且热增量绝对误差≤0.001，用 20 个 Weyl 的合成读数反演时只剩这一候选。β=4 的留出区间，20 个 Weyl 给 [0.0154853,0.0174854]，48 个标量加 1 个矢量给 [0.0515386,0.0535387]。热读出可以用热/冷各自几何、场速与已标定异常项重建；若仅有某个空间区的温度拟合，不能据此宣称已准备带指定谱的态。这个条件选择减少自由场候选表中的歧义；现实质量谱、相互作用、规范群和宇宙初态各需独立来源。[谱、热余项与留出复算](spectrum.py)
