## 3. 原完整静态准备史的自由装置出口关闭

在原 A=sqrt(3)lambda 上，设备必须给出

\[
N_{\rm req}=A^{-2}-M_2/A^6-E/A^4.
\]

任意上述自由 Hadamard 设备的长时空间平均 NEC 则不小于

\[
N_{\rm min}=\frac{E-1/(4\pi^2)}{A^4}.
\]

这里允许设备把自己的零模任意正规挤压；扣除的是原参考中真实有限零模应力，AE 项没有移动。新有向区间计算给

\[
A^2(N_{\rm min}-N_{\rm req})
\in[1.999997161299185,\ 2.000002838641601].
\]

因此目标不可能恒定地维持整个静态过去。[完整固定态谱证明及瞬时负 NEC 挤压负控](PREPARATION.md)说明，这个结果没有假定量子 NEC 逐点非负。新增常数真空能也不改变 NEC，不能在保持该原半径和原 M2 时解除矛盾。

## 4. 替代模型确有共同全时平均历史

取两个相同真实场，物质 Lagrangian 增加一个明确常数 -U。该常数保持 O(2) 对称性，不引入第三个漏算的量子场；其选择仍是新的物理输入，等效真空能没有从 Core 推导。

令第一场位移为 Y u_cl，第二场为 Z u_cl。旧/新第一场边缘完全保留，双方 E Y^2=1，E Z^2=b，R=Y^2+Z^2。同一个 u_cl 的固定动量对应原 M2。一次解

\[
x^2-2xE(x)=(1+b)M_2,\qquad
U=x^{-1}-[2B(x)/3-D_0]/x^2.

对于 0<=b<=d=sqrt(3)/2，左边在 x>=3 严格递增，根满足 2lambda<A<3lambda。给定任意一个原 M2 和一个预算 b，A、U、态、分支概率都只选择一次。不同 b 的模型族可有不同 A、U；比较同一 b 的旧/新制备时，它们完全相同。

直接代入得到

\[
2\rho_q+\frac{(1+b)M_2}{2A^6}+U=\frac3{2A^2},\qquad
2p_q+\frac{(1+b)M_2}{2A^6}-U=-\frac1{2A^2}.

这是一条实际的全时平均解，包括全部量子参考应力。最低同律预算 b*=d/2 时，统一于全部原 M2 范围的新证书给

## 5. 预算降低与共同噪声之间的尖锐权衡

d=sqrt(3)/2。原旧 Y^2 取 1-d、1+d 各半；新 Y^2=1。

在平均非负同形相干预算 b 下，

\[
\inf {\rm TV}(\mu^R_{\rm old},\mu^R_{\rm new})
=(1-2b/d)_+.
\]

因此完全同律最小预算为 b*=d/2=sqrt(3)/4≈0.4330127019。它严格小于此前要求所有分支同一固定半径的 b=d≈0.8660254038；旧定理保持有效，本轮放宽的是分支半径条件。

同律时还存在不能忽略的最优方差界：

\[
\min\operatorname{Var}R=(d-b)_+^2,\quad b\ge d/2.
\]

| 同律预算 | 最小共同径向方差 | 物理含义 |
|---|---:|---|
| b=d/2 | 3/16 | 共同 R 必须为 1、1+d 各半；相干源相对 RMS≈30.21695% |
| d/2<b<d | (d-b)^2 | 多付相干预算可连续降低共同径向噪声 |
| b>=d | 0 | 仍有正规零模量子能量噪声，不能称总噪声为零 |

共同径向相对 RMS<=epsilon 的尖锐成本是

\[
b\ge\max\{d/2,(d-\epsilon)/(1+\epsilon)\}.
\]

例如要求该项不超过 1%，b 至少为 0.8475499047370678。这里约束的是相干径向部分，完整量子方差另计。

完整 connected 总源噪声为

\[
N_{\rm tot}=2N_0+(1+b)N_1+\operatorname{Var}R\,C\otimes C.
\]

它包括第二参考场、两个位移与量子场的交叉项、标签造成的场—储备相关。低预算显式完成的旧/新差是 d(d-2b) C tensor C；b=d/2 时不仅此核相等，所有有界 O(2) 不变记录都精确同律。
