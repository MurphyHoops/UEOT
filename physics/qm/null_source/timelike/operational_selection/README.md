本轮直接接续冻结提交 577d0ba1df5b70ebfe3b14aee361223dd0ab46b8。
前轮已构造同一实际量子态与几何的精确 nonlinear mean-SCE 历史；
这次继续检验它能否唯一选解、承接完整源涨落并被实际制备读出。

**最强新增结果：**在固定 incoming A、原两场、M2/U0、完整 S0 律及 AE 处方下，
允许非平稳、挤压、跨模和零高纠缠，

这是完整源约束必要界，不否定前轮平均解，不是几何 RMS或所有量子几何的排除。

## 闭合后继续推进的优先级

1. **先建立尚未被排除的完整几何—态联合初值。**保留原全部源谱、失败与停止记录，明确是否放宽 fixed incoming A／正频 E4 域，或真正增加总源／非交换几何。任何放宽均给实际物理输入及对应方程，不能只把快幅随机化。
2. **在该同一模型中证明约束传播和误差。**态与几何同步运输，保持合法量子态与 Hadamard 结构，禁止逐时选根、重置 canonical shear 或冻结态单修 jets。
3. **接局域、有限支撑的探针和控制器。**完整记录包括其联合初态、切换、总应力、交叉噪声和校准。本轮全局源 instrument 是可计算基准，没有完成这一设备门。
4. **最后检验同资源下原降噪的可辨认引力后果。**完整共同 O(2) CP 合同仍有效；额外参考、对称破缺和选择规则须明示，不把人为不同快幅当制备信号。
5. **统一目标以减少独立物理输入及经验区分验收。**当前结果没有从 Core 导出场内容、U0、物理选解、量子几何或实验确认。

这些任务的顺序由本轮新定理决定，不把已完成的平均存在证明再次当作联合物理闭环。
