# 本轮审查、证据等级与闭合后的任务取舍

## 1. 反思改变了什么

此前平均共同历史已经成立，但“平均方程精确”本身不会决定剩余快幅，
也不会把完整源谱的量子涨落变成满足约束的几何随机律。
继续只提高慢模 jet 阶数会绕开这两项物理输入。
本轮因此同时检查选解、全源约束与可读资源，而没有把任一项提前宣布为统一完成。

审查过程中得到三项实质修正：

- 时间平移必须同步处理 eta_ref 或 canonical Q/P shear；几何自治性的高阶正则性结论不能偷换成完整态协变结论。
- 原制备是 x0/4 动量方差的 Gaussian CQ 混合。巨大经典径向方差不能算作可读相干时间资源；参考标记与相干净化必须分开。
- 任意非平稳高态不具有非负正常序能量。必须先求动态 QEI，再做联合源正部谱界；低／高频组合使候选域扩展到 E4半径1/5000。

## 3. 六项新检查各自承担什么

| 检查 | 可机器复核的内容 | 仍由证明正文承担 |
|---|---|---|
| selector | 全时标协变恒等式、解析反例、指数区间 | 一般函数分类与Hölder正则性 |
| geometry | 加权系数界、Jacobian矩阵箱、有限差常数 | 无限系数控制、积分交换与全域单射证明 |
| clock | 实际相关参数、重叠阈值、45次必要门、极小相位稳定计算 | CQ直和、任意最终读取合同 |
| instrument | 连续密度归一、噪声、pointer优化、数值信息界 | CP谱演算、MMSE全方差和资源适用范围 |
| fluctuations | KG恒等式、beta采样、频段和、全r区间下界 | 无限闭型、Hadamard/态域、强交换正部谱不等式 |
| review | 不使用超越函数数值的Fraction主门、整数余量、负控、范围标志 | 整体物理模型的有效性与实验检验 |

主门使用精确冻结浮点端点对应的有理数，不把显示小数当成新测量值。
负控保留 y=−1、h=1：若去掉正部，(y+h)²≥y²立即失败。
矩阵局部行列式非零本身也不被误称全局单射；证明使用输入凸域上平均 Jacobian 仍留在同一区间箱。
