# 本轮反思与验收范围

本轮先完成约化候选的正向构造，再用它检验自己没有自动满足的物理条件。
结果不是简单的“量子约束成功”：固定离散族的三个区间已区分；
临界点有正规联合态、固定演化和有限总正源方差；同态二次参照差、
裸源代价及对称 work-law 交换子又说明它不能直接承接原 AE/RSET 历史。

## 1. 可以签收的增量

- MODEL：canonical 归一化、自伴 Jacobi 族、真实连续排序及文献来源。
- PHASE_DIAGRAM：完整曲率下，亚临界负谱态没有任何正阶体积矩；
  超临界有有限动量上限，不能精确保留原完整高斯律。
- CRITICAL_STATE：固定光滑负谱筛选、统一范数下界、正规等距编码与一条共同历史。
- VOLUME_MOMENTS：离散 IMS 与图范数归纳给多项式传播，证明筛选后体积二阶及高阶矩。
- POSITIVE_SOURCE：完整正能量的闭形式与二阶矩；正 dust 密度排序及方差界。
- SOURCE_OBSERVABLES：真实 Q 法向导数、物理 POVM、Hadamard 范围及非零 work-law 交换子。
- DISPERSION_GAP：任意相关态的保守二次参照诊断，明确权重和适用范围。
- FINITE_CLOCK：同一 dust 的正常正能提升、完整残差、非零读时窗口及无条件总源。
- ROBUSTNESS：有限误差下临界唯一性失效；新的完整裸初态近似有明确体积与能源成本。

这些是有文档证明支持的符号／区间检查。解析证明没有因此变成形式化定理，
原生子智能体审查也没有因此变成外部人类同行评审。

## 2. 必须纠正的研究优先级

强量子零约束、正尘埃时钟、离散体积、排序及谱倒数均是另行声明的物理输入。
它们不是此前已经成立的确定性 mean-SCE 推出的必要条件。
本轮的有限应力存在性检验关闭了这一候选分支的一个真实缺口，
但不能让它无限成为所有原任务的前置门。

原目标仍是：同一实际总制备、同一平均几何与涨落动力学、绝对初值约束、
完整应力/响应和可校准引力记录。前驱已有精确共同平均历史；
仅相同 W2 的两制备在 mean-SCE 下没有新的平均几何差。
要从噪声差推到引力记录，必须明示 beyond-mean 法则及其合法初态，
不能用新 clock 的正常性代替这些条件。

## 3. 这次没有再混合的对象

精确 physical 负谱态与近似 kinematic 正常态；bare 源与联合编码观测量；
固定背景 Hadamard 与量子几何 RSET；P 概率加权比值与真正线性均值；
有限总正源与小涨落；模型序列与一条模型内的时间历史；
自伴生成元与协变 Ward；文献结构先例与 UEOT Core 推导，均分别记账。

reproducibility 的源码、旧回执、当前证书和实际执行由 run_verification.py
绑定。旧 checker、旧模块、模式 ODE、几何 ODE 均不执行。
Core 只读、GI 排除、PR #468 保持开放草稿不合并。
整体物理统一与经验确认仍 OPEN。

## 4. 完成分支后已经继续回到原约束

新增 ORIGINAL_CTP_GATE 在原两自由场、原 AE 和同一 W2 下给出条件性空间投影定理；它没有借用本轮 dust 模型。纯非齐次线性几何不能供给缺失的密度 singlet；完整零行的时间 Ward 与定义域假设明确列出，并给出缺少 Ward 时的反例。原绝对密度方差在光滑正时间窗保留。

边界守恒积分常数、精确反相关要求和有限方差预算把下一任务缩小到真实联合边界态。经典 PSD 抵消与保留完整物质边缘的量子载体不同；后者若与零模 dilation 对易，仍有正残差下界。完整 CTP、制备过去和引力读出继续 OPEN。
