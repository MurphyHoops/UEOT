## 2. Exact Closed-Form $H^2(S^3)$ Bochner–Sobolev Banach Algebra Constant $\frac{3\sqrt{3}}{2}$

Equip $H^2(S^3)$ with $\|f\|_{H^2} := \|(1 - \Delta_{S^3})f\|_{L^2(S^3)}$. Since $1 - \Delta_{S^3} = k^2$ on the $k$-th harmonic shell ($k = \ell + 1 \ge 1$) with Unsöld density $\frac{k^2}{2\pi^2}$, Cauchy–Schwarz gives $\|f\|_{L^\infty(S^3)} \le \bigl(\sum_{k=1}^\infty \frac{1}{2\pi^2 k^2}\bigr)^{1/2}\|f\|_{H^2} = \frac{1}{\sqrt{12}}\|f\|_{H^2}$. On unit $S^3$, Ricci positivity $\mathrm{Ric}(\gamma) = +2\gamma$ gives Bochner's identity $\int_{S^3} (|\nabla^2 f|^2 + 2|\nabla f|^2)\,dV = \int_{S^3} (\Delta_{S^3} f)^2\,dV \le \|f\|_{H^2}^2$, and integration by parts gives
$$\int_{S^3} |\nabla f|^4\,dV = -\int_{S^3} f\bigl(|\nabla f|^2\Delta_{S^3} f + 2\nabla^2 f(\nabla f, \nabla f)\bigr)\,dV \le 3\|f\|_{L^\infty}\|\nabla f\|_{L^4}^2\|f\|_{H^2} \implies \|\nabla f\|_{L^4(S^3)}^2 \le \frac{3}{\sqrt{12}}\|f\|_{H^2}^2 = \frac{\sqrt{3}}{2}\|f\|_{H^2}^2.$$
Expanding $(1 - \Delta_{S^3})(f g) = f(1 - \Delta_{S^3})g + g(1 - \Delta_{S^3})f - f g - 2\nabla f\cdot\nabla g$ and applying the triangle inequality proves the **exact closed-form Banach algebra inequality**:
$$\|f g\|_{H^2(S^3)} \le \left(\frac{3}{\sqrt{12}} + \sqrt{3}\right)\|f\|_{H^2(S^3)}\|g\|_{H^2(S^3)} = \frac{3\sqrt{3}}{2}\,\|f\|_{H^2(S^3)}\|g\|_{H^2(S^3)}.$$
