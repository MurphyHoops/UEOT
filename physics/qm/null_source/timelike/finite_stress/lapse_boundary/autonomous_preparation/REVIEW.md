# Scope, source identity and research timing
This administrative check binds certificates to actual proof/source bytes,
checks immutable agent file identities and independently timed arithmetic.
It is not formal mathematics or external peer review. COMPLETE requires
all three read-only reviewers, no unresolved finding and >=10800 seconds.
The driver freezes 1023 predecessor files, verifies the 28-entry exact-head
parent CI, reuses 276 accepted entries and executes only the new explicit list.
