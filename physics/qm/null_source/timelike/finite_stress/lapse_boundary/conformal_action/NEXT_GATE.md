# 下一验收门：同一自主模型中的实际读数与局域总源

物理统一保持 OPEN。下一项从 Z 已构造的同一个 Hamiltonian、
同一个 r(x)、同一 finite c_r 和实际正常输入出发。不得把 X 的预设
r(t) 脉冲增益或高斯噪声直接放进 Z。

## 1. 已继续完成的门，以及现在最优先的具体交付

AA 已经在同一个 Z H 下构造两份 active-coupling 正常输入、
同一有限时刻和同一完整有界探针 effect，得到严格正的实际
source-sign record contrast。它改变了准备，高模和controller相关，
没有完成从共同过去自主产生这些相关的过程。两码字总H谱律相同，
没有几何／总能量荷辨识结论。

下一项选择一个具体出口：

- 在同一自主准备 Hamiltonian、共同正常初态和声明过去中实际生成
  AA 所需相关态，给完整成功/失败记录与能量代价；或
- 保持 Z5 外来 H2 波包在 [-2,-1]、探针和高模真空，低模源使用
  明确两份输入，证明同一实际 H 的后续碰撞读数严格正，给数值时间、
  源到记录误差与全部准备／读出能量。

后一条可取原外来多项式波包和±1相干源作为固定研究输入，其总均值
是56.5（不沿用源真空的56）；是否足以在目标时间产生可分读数需证明。

若用半经典控制器近似，必须在 W(x) 的 adapted frame 中处理
完整 A、A'及A²，控制波包扩散、反冲、有限 r² 真空势和全部场尾。
直接把自由controller packet乘 X 的固定脉冲场态，可能不在相邻
fiber的能量域；不能用它作未经域检查的 Duhamel trial。
Z 的 Mosco 极限保证存在，尚不提供该近似的定量收敛率。

所有方案仍需完整非选择仪器、失败结果、源态改变和可选参考系统。
若实际误差界不能给出正contrast，须如实拒收该参数组。
源符号可读也不等于总能量或几何约束荷可读；两者要各自选定编码和
校准效应并按同一总源重新验收。

## 2. 同一模型的下一层定义域

Z 的正常演化和 dressed 总能量有限，不自动推出裸自由场能量、
局域复合应力、Hadamard 条件或四维局域性。接下来需要在真实
operator-valued coupling 上构造可用的平滑局域应力与其 Ward 恒等式。
有限 c_r 同时保留在相位、controller 力和 lapse／应力接触行。

## 3. 回到完整局域与引力闭环

把全局 x 改成实际局域控制场时，必须重新证明动力学和准备的存在。
不能令所有非齐次控制模等于零后声称这是自动一致的截断；
phi psi 的非齐次分量会源动这些模式。
末端读数器也需由真实作用量和正常初态生成。

最终几何任务应回到同一有限初片、共同平滑过去上的 CTP 两支 lapse，
保留初始混合块、局域反项、全部接触和 tensor/momentum constraints，
证明完整总源的正定正常态与因果响应。
Y 的固定 ESU probe phase 和 U 的 spectral-zero lapse comparison
不能代替一般物理 lapse phase。

## 4. 统一目标的验收含义

同一完整作用量、正常制备、稳定演化、全部约束、完整仪器和可校准
经验预言须在一个物理模型中相容。改变模型可作为候选研究，但每次
改变都必须声明丢失和新增的前提，并重新验收。
本轮多项模型内闭环不相加为一个“统一完成百分比”。
