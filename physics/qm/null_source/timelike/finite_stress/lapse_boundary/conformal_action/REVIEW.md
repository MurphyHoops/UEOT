# Scope and source-binding review

The runner freezes 924 predecessor scientific files and reuses 248 accepted entries,
with the exact e5b116d06a6519da2689dbe9cad80b82e406f330 CI/log/artifact identity.
Only this new cohort and four established routing files may change.
No predecessor scientific Python module is imported or executed.

The review checker binds every accepted new result to its actual source bytes,
checks the independent new-module import boundary, records immutable native
reviewer/commit/file identities and verifies the timing record's arithmetic.
A checkpoint can be scientifically tested while its session and final audit
remain IN_PROGRESS. The final audit flag requires all three actual reviewers.
Timing is not inferred from test counts or predecessor work.

These are programmatic provenance/scope checks. The mathematical arguments
remain the stated analytic proofs and their independent source reviews.
No machine-formal proof or external human peer review is claimed.


The AST import/call rules are limited static source checks, not a general
Python execution sandbox. The non-runner allowlist excludes importlib;
the runner's separately reviewed importlib.metadata only reads versions.
Relative imports and direct eval/exec/__import__ calls are rejected.
Actual immutable source inspection complements these syntactic checks.
