本增量接续冻结的 c8c9e7fa4963ac5fdbad38a8e398dabd6b6e78ea。Core 只读，GI 不在范围。固定原 M2、U0、双场物质模型、AE 处方及 joint_history 的 unfiltered 实际制备，构造同一 incoming 态上的非静态几何，并给出**完整无限模、指定正时间窗内的实际方程残差和法向导数上界**。

同时闭合两项操作判断：

1. 完整联合输入 twirl 相同、共同因果约束相容通道及每个仪器结果 O(2) 协变时，所有动态、自适应、成功／失败／停止记录严格同律。动态演化本身不能产生该合同内的 old/new 引力辨识。
2. 同一未标记密度矩阵的两种分解，若逐纯态把平均源变成确定性可读几何，可给出 TV=1 的不同记录。这不能同时是仅依赖该密度矩阵的共同 affine 通道。真实制备 flag 改变完整输入，须显式保留并核算；本结果不否定一般 mean-SCE。
