# 同一参考态的动态应力、初始几何一致性与可识别关系

本轮从已审提交 `987dd4ccc58d0086cc1305e99b5cdb67f8127fde` 继续，目标仍是基于 UEOT 推进物理统一。研究对象是同一个有限球内核、同一个最小标量场和同一归档参考核。本文没有把一次计算通过或一个反例写成整个物理统一已经完成。

**主要结果：**在原参考态、原归一化尺度、`4πG=1`、`ħ=1`、Anderson–Eaker `μ=1` 且无额外有限曲率项的条件下，整个无限模量子场在原初片上的绝对重整化密度满足

\[
 \rho_q(0)>1.5101633543>\frac12.
\]

原给定经典内核的初始几何允许的总能量密度恰为 `1/2`，经典源本身已经使用了这个数额。因此，这个经典背景与该量子参考态的直接组合不满足半经典 Hamiltonian 约束。这个结论要求改变接续路线：先处理总源与几何的一致性，不能直接把旧背景用于有限幅度量子反馈预测。

同时，本轮推导了保留或缺少源二阶能量标定时的两种有限窗观测关系。它们能消去未知有限曲率系数，并给出具体误差放大；新增几何仪器、窗口参考应力和有限阶反馈余项仍须另行完成。

## 1. 反思后改变了哪些研究决定

上一轮的静态绝对应力、有限秩态差和不可识别性结论继续有效，但它们分别承担不同责任。辅助静态准备段的微小应力不能代替实际收缩段的共同参考应力；有限秩态差中消去的共同背景，正是总几何约束需要重新检查的部分。

本轮据此作了三项选择：

1. **先检验共同参考源是否允许沿用原几何。** 全部计算冻结实际 `instrument.state_scale`，不为得到小应力而更换插值或零模。
2. **以要裁决的物理命题分配精度。** 先取得严格传播，再通过中频正性与无限尾拼接给能量下界。无需为证明 `rho>1/2` 求出每个高频模式，也无需把所有有限模式都算到同一极小误差。
3. **保留已经拥有的信息。** 原总刚性源系数已知时，两密度窗足以消去有限曲率系数；源标定不足时才增加第三独立收缩，第四个观测作为留出检验。没有无说明增加未知参数，再用更重装置弥补它。

完整长期目标继续开放。新的结果依赖明确的 Einstein、量子场、Hadamard 和局域重整化输入；Core 没有在本轮唯一选出这些物理结构。

## 2. 冻结的实际模型

使用 [有限源初值](../../FINITE_WINDOW.md) 与 [同源合同](../continuation/SOURCE.md)。原内核为

\[
 a(\eta)=\sqrt{3\cos2\eta},\qquad d\tau=a\,d\eta,
 \qquad \chi+|\eta|<\arcsin(1/\sqrt3).
\]

量子参考核由辅助静态三球上的非零模真空和一个明确的正规高斯零模指定。辅助尺度在 `eta≤−1/8` 静态，在 `[-1/8,−1/16]` 使用原 `C∞` 插值，随后等于物理内核尺度。插值对象是 `a`，不是 `a²`。辅助过去用于定义态，尚未证明是有限球或实际装置实现的自洽准备历史。

非零模 `k≥2` 满足

\[
 u_k'=p_k/a^2,\qquad p_k'=-(k^2-1)a^2u_k,
 \qquad \omega_k=\sqrt{k^2-1}.
\]

初值为 `u=1/(a0 sqrt(2 omega))`、`p=−i a0 sqrt(omega/2)`。零模仍取 `Var q=1/6`、`Var p=3/2`，单独计入其有限应力。全部结论绑定这份核；改变准备过程、尺度或物理有限耦合，需要重新审查对应输入。

## 3. 从实际制备传播到动态应力的证据

### 3.1 有限模式：真正的误差包围

[传播实现与证明](propagation/README.md)使用 12 阶 Taylor 多项式、整单元的 13 阶余项，以及加权误差球

\[
 E^2=\omega_k a^2|\delta u|^2+
       |\delta p|^2/(\omega_k a^2).
\]

它的增长由 `integral |a'/a|` 控制，不随高频旋转出现指数放大。区间舍入、重设中心和初值舍入均入账；平端的导数通过解析 Bell 主项界控制。

- `k=2..64`：对 `eta=0,3/64,11/64,3/16` 共用 656 个单元，最大能量球半径约 `2.392e−20`。
- `k=65..256`：只补初片，使用 185 个单元；有限应力贡献的误差半径小于 `4.921e−5`，已足够裁决能量比较。

有限部分输出直接包含完整密度与压力系数的区间。两个执行回执是 [四点低频传播](propagation/result.json) 和 [初片补充传播](propagation/extra_eta0_256.json)。它们不单独声称已经处理无限尾。

### 3.2 局部补项和无限尾

[动态应力推导](stress/README.md)在原实际插值上采用静态端恰好匹配的 W2 模，使用实际残差驱动的 Bogoliubov 界，并在满足相位正性时作振荡分部积分。导数界来自同一背景的有向区间计算。

令 `c=cos(2 eta)`、`L=log(3 c μ²/4)+2 gamma_E`，独立从 Anderson–Eaker 原式得到

\[
 \rho_{an}=\frac{(168+180L)c^2-110-135L}{8640\pi^2c^6},
\qquad
 p_{an}=\frac{(160+300L)c^2-240-405L}{8640\pi^2c^6}.
\]

它们与实际动态模式减项配套，满足守恒。主审的 [独立代数检查](review_algebra.py)还核对了物理段的 Ferrers 精确基本解及其 Wronskian；这些恒等式没有代替制备区间传播或无限尾证书。

四个时刻的全应力已获得有限包围，但直接对称界非常宽。特别是压力尚不能精确确定；原两窗口的参考应力积分也尚未算出可用精度。完整数字和来源绑定见 [应力总回执](stress/result.json)。不能把“区间有限”当成所有动态预测已经可用。

### 3.3 一个足以改变物理判断的全场下界

转折点 `eta=0` 上，规范 Wronskian 与能量正性给每个真实模式

\[
 e_k=|v_k'|^2+(k^2-1)|v_k|^2\ge\omega_k.
\]

该点需要扣除的系数是 `d_k=k−1/(2k)+3/(8k³)`。含完整简并度后，未逐个传播的中频模式满足

\[
 k^2(e_k-d_k)\ge r_{stat}(k)-\frac1{2k},
\quad
 r_{stat}(k)=k^2\sqrt{k^2-1}-k^3+k/2+1/(8k).
\]

对 `K<k≤J` 使用平方根级数与调和和的严格下界，再对 `k>J` 使用同态的真实 UV 证书。这个拼接保留全部无限模式。

选 `J=3072` 后，数值分项约为：

| 已传播模式 | 有限密度下端 | 中频保守损失 | 无限远尾保守损失 | 全场密度下界 |
|---|---:|---:|---:|---:|
| `k≤64` | 0.6639334337489 | 0.0054477252076 | 0.0001714779400 | **0.6583142306013** |
| `k≤256` | 1.5138316903699 | 0.0034968580504 | 0.0001714779400 | **1.5101633543795** |

表内数字为展示用近似；回执保存精确有理端点。独立 A 审查不用 B 的组装函数，而从初片闭式 W2、独立零模和谱和重建下界，得到相同结论。C 逐项核对了完整简并度、零模扣除、局部补项和远尾系数。

结合已有直接上界，可保守写为 `1.5101633543 < rho_q(0) < 111.054`。这个双侧区间不够给精确量子密度；其下端已经足以否定当前参数下的微小密度修正假设。压力的现有包围仍约为 `[-8.390e4,8.391e4]`，不能据它判断压力符号或完成反馈。

## 4. 初始几何裁决，以及有限曲率项的边界

在原初片，`a0²=3`、`Kij=0`，因此

\[
 G_{nn}=3/a_0^2=1,\qquad
 \rho_{required}=G_{nn}/(8\pi G)=1/2.
\]

原经典源密度也是 `1/2`。在当前有限项选择下，加入已绑定参考应力后的约束残差为

\[
 G_{nn}-8\pi G(\rho_{cl}+\rho_q)
 =-2\rho_q<-3.0203267086.
\]

因此拒绝的是**这个给定背景与物质赋值的直接组合**。没有构造新半经典几何，也不能把旧背景上算出的 `rho_q` 固定不动后硬塞入平方根，称为新自洽解。原背景的加速度/Ricci 收缩也没有被另当成独立初片数据。

如果允许在应力侧加入 `alpha H1`，该点 `H1_nn=6`，则原密度残差可由 `alpha=−rho_q/6` 抵消。单点结论因而不排除所有允许的物理有限曲率耦合；改变减除尺度时，引力侧物理系数也必须相应记账。恢复 `ħ` 或改变源长尺度同样会改变相对修正大小，不能把当前归一化的比较推广到任意尺度。

## 5. 消去未知有限曲率系数的实际观测关系

[有限窗推导与区间证书](inference/README.md)将 Newton 和宇宙学耦合视为已独立标定。在四维共形平坦族及声明的局域维数四反项类内，曲率平方变分只保留一个有效系数。此处不包含额外 EFT 算子、边界或非齐性自由度。

扣除共同动态参考后，密度和聚焦组合 `E=(rho+3p)/2` 的第一阶关系是

\[
 \begin{pmatrix}D_\rho\\D_E\end{pmatrix}
 =\begin{pmatrix}
 c^{-1}-c/2&c^{-3}&(4c^2-3)c^{-6}\\
 c&2c^{-3}&3(4c^2-5)c^{-6}
 \end{pmatrix}
 \begin{pmatrix}\epsilon\\u\\v\end{pmatrix}+r,
\]

其中 `epsilon` 为九模源系数，`v=6 alpha`。`u` 归集总二阶齐性动量与零模方差的偏差；旧随机位移族使用 `M2=27 E[Y²]`，不能把 `M2` 误写成均值动量平方。只测一阶场均值不能分开未知随机位移方差与零模方差。

沿用原两个完整 `C∞` 时间窗，并按同一物理半径匹配，得到两种信息合同：

| 已有信息 | 所需新增几何数据 | 结果与误差要求 |
|---|---|---|
| 总刚性源系数 `u` 已标定 | 两窗密度 `rho1,rho2` | 可拟合 `epsilon,alpha`；误差界为 `9.352408899 delta + 2.081488946 Delta_u`。原理论精确 `u=0` 时保留此最省信息方案。 |
| `u` 未独立标定 | `E1,rho2,E2` 三个收缩 | 同时处理三参数；`epsilon` 等绝对误差放大小于 `15.748363`。 |
| 需要额外检验三参数源族 | 再保留 `rho1` | 形成不参与拟合的、消除有限曲率系数的残差，等误差放大小于 `1.999941`。 |

这些系数来自完整窗积分及区间逆矩阵，点值不替代窗口平均。原 Ramsey/指针记录测量场的特征函数，并没有自动提供这几项几何数据。实现它们仍需要几何测头、空间曲率/聚焦校准、同半径匹配和装置应力预算。

误差 `delta` 必须包括动态参考窗口积分、仪器、匹配、权重以及有限阶反馈余项。重复采样不能自行缩小未标定系统误差。当前固定尺度下已发现大的共同量子密度，不能直接假设第一阶余项足够小。

这个结果移除了一个“把未知有限曲率系数设为零”的推断前提。它与标准线性消元一致，尚未形成 UEOT 独有实验预测或资源优势。

## 7. 接续设计已经因结果改变

1. **先解决总源与初始几何的一致性。** 明确有限引力耦合及物理尺度，研究可合法准备的参考核，并构造总半经典约束的可行数据；若改准备核或尺度，必须让模式、仪器、能量和误差使用同一新合同。本轮的原核作为反例和回归对照保留。
2. **再给实际窗的受控反馈。** 对选定合法分支完成 `rho` 与 `E` 的窗口积分和有限阶余项。已有固定背景包围是输入与检查点；它们没有证明非线性解存在或稳定。
3. **按保留的信息选择几何仪器。** 已标定 `u` 时先做两密度窗；源二阶能量不足时才升级为三收缩/四数据，并实现真实校准、因果与完整成本。此前无共同尾约束的噪声认证不可能性仍有效。
4. **继续承担 Core 到物理结构的选择责任。** 本轮减少了一个推断中的任意系数选择，并否定了一个不自洽的源/几何组合；尚未从 Core 推出唯一量子复合规则、场内容或引力方程。后续成果必须继续明确它消去了什么输入、排除了什么关系或新增了什么可检验判断。
