## 1. 原局部扰动已从零点斜率推进到有限区间

保留原测试、共同准备过去、完整参考态和相干源初值，在 \(\lambda=32768\) 上取
\[
n_\epsilon=\sqrt{1-2\epsilon F/(D\lambda^2)},\quad
g_{\epsilon,00}=-a_\lambda^2n_\epsilon^2,\quad |\epsilon|\le1.
\]
整个路径的 lapse 保持正，度规 \(00\) 分量的相对改变量小于 \(4.624143\times10^{-6}\)。未来测量仍在原 \((5/32,3/16)\) 时间窗及 \(\chi<1/100\) 孔径，坐标涂抹保持不变。

| 指定完整记录的认证量 | 有向区间给出的保守读数 |
|---|---:|
| 旧候选全部启动 plus 概率变化 | \(<7.780355\times10^{-5}\) |
| 新候选全部启动 plus 概率变化 | \(<5.756185\times10^{-5}\) |
| fail/plus/minus 完整三标签统一总变差 | \(<7.780355\times10^{-5}\) |
| 扰动后的旧候选 plus 概率 | \([0.46364405,\ 0.48670672]\) |
| 扰动后的新候选 plus 概率 | \([0.00059723,\ 0.01827913]\) |

小数均向外放宽，精确有理端点保存在[有限传播回执](finite/result.json)。比较扰动前后概率时校准参数和失败率相同；最终区间对原声明的增益、相位、对比、偏置及询问前失败范围一致成立。

证明直接控制两个真实 KG 传播的差，而不是沿 \(\epsilon\) 积分一个只在零点成立的斜率界。规范变量满足
\[
q'=np/a^2,\qquad p'=a^2\operatorname{div}(n\nabla q)+j.
\]
以
\[
N^2=\|p/a\|_2^2+\|a\nabla q\|_2^2+\|aq\|_2^2
\]
作全空间能量，完整保留 \(\nabla n\)；对差分强迫使用原未来源的 \(H^1\) 范数。原正则零模与所有非零模共同给出协方差界。相干均值另由精确辛配对恒等式得到 \(<1.100525\times10^{-5}|\epsilon|\)，再直接比较完整 Weyl 特征函数。

这关闭了**指定外加有限度规路径、指定固定坐标 Weyl 测试**的有限概率缺口。若仪器改按实际经历扰动的本征钟触发，测量权会发生时移和 Jacobian 变化，需要额外证明；任意有界效应的统一范数、路径上的完整 RSET 与噪声常数也不由此自动得到。

## 2. 64次完整启动仍能区分两种候选

有限扰动后仍有
\[
p_{\rm old}>9/20,\qquad p_{\rm new}<1/40.
\]
每次保留 fail、plus、minus，以 plus 记1，另两标签记0。**固定64次，plus至少11次判旧，至多10次判新。**

令 \(q=1/6\)，主审独立有向计算
\[
P_{\rm old,err}\le e^{-64D(q\|9/20)}<9.481784\times10^{-6},
\]
\[
P_{\rm new,err}\le e^{-64D(q\|1/40)}<7.050492\times10^{-6},
\]
两者都低于 \(10^{-5}\)。这里 \(D\) 是 Bernoulli 相对熵，证明与精确端点见[独立回执](review.json)。

独立新制备是一个充分实施合同。更一般地，每次**条件于完整过去**仍满足制备、校准和失败合同，即可用条件矩母函数迭代；允许按过去预先选择下一次的 \(\epsilon\) 和合同内校准。这个条件责任不能从单次边缘概率证书直接推出。

负控保留在可执行检查中：令所有 \(X_i=Z\)。单次 \(p_{\rm new}=0.01\)、\(p_{\rm old}=0.475\) 均位于上述实际概率带，但64次误判仍分别为0.01和0.525。因而边缘概率、删除失败记录或任选停时均不足以支持重复统计结论。

128到64的改善来自更紧的统计估计。没有证明最优样本数或完整硬件成本优势。

## 3. 真实局部 TT 几何读出与完整噪声

在原内球上实际构造非零紧支撑的横向无迹张量 \(\tau\)：先对紧支撑平直种子作线性化 Cotton 操作，再用三维共形权移到 \(S^3\)。它有显式整数归一常数 \(M=7640\)，且 \(\|\tau\|_{\mathrm F}\le1\)。主审另用不同的四阶多项式符号独立检查局部 TT 构造和共形散度消去。

对于经典 Einstein—齐性标量背景，定义应变 \(h\) 与算子
\[
g_{ij}=a_\lambda^2(\gamma_{ij}+h_{ij}),\qquad
\mathcal D_T=\partial_\eta^2+2(A'/A)\partial_\eta-\Delta_\gamma+2.
\]
取 \(\Psi=\psi(\eta)\tau\)、\(Q=\mathcal D_T\Psi\)。紧支撑与自伴恒等式把局域、线性规范不变读出
\[
O=\int A^2Q:h
\]
精确接到应力
\[
O=4\int A^2\psi\,\tau^{ij}\xi_{ij}.
\]
所有齐次 TT 初值及其与源的相关在这个补偿读出中逐样本消去。对应真实四维测试和读出误差增益也明确给出。

| 本轮指定 TT 读出的噪声常数 | 上界 |
|---|---:|
| 全模式二次应力系数 \(C_T\) | \(<9.188034\times10^8\) |
| \(\lambda=32768\) 时 \(\operatorname{Var}O\le C_T/\lambda^4\) | \(<7.969349\times10^{-10}\) |
| 同一未经信号增益归一的 RMS | \(<2.823004\times10^{-5}\) |
| 点态应变误差到该读出的保守传递增益 | \(<8372.088\) |

全部简并度、低/高交叉、真实高频准备余项都保留。参考场态是 quasifree；二次应力本身不被假设为 Gaussian 变量。此表是**指定读出权的绝对噪声界**，不能当作校准后的应变分辨率。非零信号标定增益给出精确定义，但未计算它的可靠数值下界；TT 均值为零，也不能借用原密度 \(D\) 作相对噪声分母。

同时得到一个精确的适用范围限制：
\[
\partial_i f=0
\quad\Longrightarrow\quad
T_\tau[\phi+Yf]=T_\tau[\phi].
\]
因此在当前未扰动齐性背景上，旧、新幅度制备的整个 TT 应力记录子代数相同；前轮的密度降噪优势不能推广到这个通道。有限非齐性 lapse 传播通常使 \(f_\epsilon\) 具有空间梯度，这个零信号恒等式没有被搬到那条路径。

## 4. 共同固有钟：精确非线性有限门基准

本节采用额外的纯经典分支几何
\[
a_M^2=\sqrt{M/3}\cos2\eta,\qquad
M_Y=\bar M Y^2.
\]
它的旧、新初片绝对尺度分布不同；它不包含完整量子参考态，也不是原同一背景制备实验或已构造的 SCE。

令 \(\ell=(\bar M/3)^{1/4}\)、\(r=\sqrt{|Y|}\)、\(I(\eta)=\int_0^\eta\sqrt{\cos2u}\,du\)，则
\[
\eta_r=I^{-1}(\tau/(\ell r)),\qquad
y_r=\log[V_r(\tau)/V_r(0)]=\tfrac32\log\cos2\eta_r.
\]
固定共同正固有时间时，\(y_r\) 严格随 \(r\) 增大。

实际认证使用正归一有限门：名义 \(t=\tau/\ell\in[95/1024,97/1024]\)，共同钟速 \([199/200,201/200]\)、时零偏置 \(\pm10^{-4}\)、总 log-volume 误差 \(\le10^{-3}\)，包括初片分母的标定。

| 分支 | 已含有限门与全部声明误差的测量区间 |
|---|---:|
| 旧小幅度支 | \([-0.07802617,\ -0.07089417]\) |
| 新定幅度支 | \([-0.02861120,\ -0.02478175]\) |
| 旧大幅度支 | \([-0.02116358,\ -0.01782916]\) |

取读数落在 \([-0.05,-0.023]\) 判新，其余判旧，在这些误差预算内分离仍成立；最小阈值余量大于 \(0.00178175\)。这是完整有限钟门和体积标定的条件结果，不是一次瞬时量子试次或已经取得的硬件记录。

严格非线性还给出两项反控：

- 在共同正 proper time 与共同无焦域，\(y(M)\) 严格凹，故 \(\mathbb E y(M_Y)<y(\bar M)\)。旧平均初片尺度只有名义尺度的约0.886885614；不能用均值为零的一阶尺度修正替代这组幅度不小的精确分支。
- 若用同一标量作为内部钟，定义 \(u=|\phi-\phi_0|\)，则
  \[
  V/V_0=\operatorname{sech}(2u/\sqrt3)^{3/2},
  \]
  整条传递曲线独立于 \(M\)。这只涉及体积对无符号内部钟的记录；额外记录标量运动符号会改变实验记录定义。真正的固有钟辨识需要独立物理计时标准。

在模型、时零和绝对钟单位已知时，一点体积比 \(R\) 还可反演
\[
M=3\left[\frac{\tau}{I(\frac12\arccos R^{2/3})}\right]^4.
\]
有限门保留单调性，但不能直接套用此点态公式。
