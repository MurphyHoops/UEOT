# 无旋类时束的有限钟窗判据

基线 `7437bd1dec7e84d229c015009b07d698d9739af8`。以中央测地线的固有时 \(\tau\) 为钟，冻结几何权 \(w=[4x(1-x)]^4,\ x=4\eta_0(\tau)\in[0,1]\)，窗外置零。\(\eta_0\) 是按归档有限球 \(d\tau=\sqrt{3\cos2\eta}\,d\eta\) 预编程的名义钟表，同一个实时时钟程序用于所有候选。场读数取晚窗均值减早窗均值，各窗内用归一密度 \(30t^2(1-t)^2dt\)。窗端以 \(1/32\) 为单位：归档对为 \((1,2;5,6)\)，另固定留出 \((2,3;6,7)\)。两对均不参与选择 \(w\) 或拟合引力参数。

**几何弱式。** 在四维 Levi-Civita 时空，沿单位类时测地线平行运输一个三维正交空间标架。取三个正交于四速度 \(u\) 的独立 Jacobi 场作列，记 \(J\) 为其矩阵，\(V=|\det J|/|\det J_0|\)，整窗无焦点。置 \(y=\log V,\ B=\dot J J^{-1}\)，由 \(\ddot J=-{\cal R}J,\ {\cal R}_{ij}=R_{iuju}\) 得 \(\dot B=-B^2-{\cal R}\)。因此 \(\dot y=\theta={\rm tr}B\)，
\[
 H:=-\int w''y\,d\tau
 =\int w\,[R_{uu}+\theta^2/3+\sigma_{ij}\sigma^{ij}-\omega_{ij}\omega^{ij}]\,d\tau .
\]
这里 \(R_{uu}=R_{ab}u^au^b\)，\(\sigma,\omega\) 分别是 \(B\) 的对称无迹与反对称部分。\(w,w'\) 在两端为零，两次分部积分无边界贡献。无旋时 \(H\ge\int wR_{uu}\)。Weyl 潮汐可任意改变三条臂和剪切，迹恒等式依然成立。未要求初始膨胀为零；此式约束整窗记录，单个末端体积不能代入。[Raychaudhuri 原文](https://journals.aps.org/pr/abstract/10.1103/PhysRev.98.1123)

**场到体积。** 令 \(s\) 是两个归一场窗之差，\(S(\tau)=\int_{-\infty}^{\tau}s(t)dt\)。要求 \(S\) 两端消失，在 \(w=0\) 处几乎处处为零，且 \(0<C=\int_{w>0}S^2/w\,d\tau<\infty\)。于是 \(\Delta=\int s\phi=-\int S\dot\phi\)，Cauchy–Schwarz 给 \(\int w\dot\phi^2\ge\Delta^2/C\)。在最小正动能、无势、无宇宙常数的 Einstein–实标量模型中，\(R_{uu}=8\pi G\dot\phi^2\)，故 **\(H\ge 8\pi G\,\Delta^2/C\)**。多支规范标量的单位线性投影同样成立。若另有态依赖应力、改善项、正势或宇宙常数，须独立控制其**迹反转应力沿 \(u\) 的加权下界**。半经典平均源还需固定参考态与重整化；相干位移差不能自动提供绝对应力。平方令几何读数对源的正负简并。

**三种可失败的替换。** 以下沿用相同固有时程序，时间单位取原内核半径，所有反例均在首焦点前。

* 平直时空，在中央静止线邻域让测地初速为 \(\boldsymbol\Omega\times X,\ |\boldsymbol\Omega|=1\)。各粒子走惯性直线，中心 Jacobi 体积为 \(1+\tau^2\)。整窗 \(y''=2(1-\tau^2)/(1+\tau^2)^2>0\)，实算 \(H\in[-.311,-.288]\)，而 Ricci 为零。去掉无旋前提会错判。
* 真空平面波取 \(g_{uu}=x^2-y^2\)（此处 \(u\) 为零向坐标），中心类时线 \(u=\tau,v=\tau/2\)。三臂初始平行且无旋，\(J={\rm diag}(\cosh\tau,\cos\tau,1)\)。错用 \(3\log J_x\) 得 \(H\in[-.513,-.475]\)；实际三臂给 \(H\in[.016,.019]\)。单臂扩张与整束聚焦可同时发生。
* 非齐性有限区域若只存总容积，\(-(\log V_{\rm tot})''=\langle R_{uu}+\sigma^2+\theta^2/3\rangle-\mathrm{Var}(\theta)\)（无旋，按当前体积平均）。例如在 Minkowski 中取等初始权重的两个不相交的无旋惯性束，一支体积比为 \((1+\tau)^3\)，另一支为 \((1-\tau)^3\)；可分别取未来和过去锥的 Milne 法向束。和的归一值 \(1+3\tau^2\) 使 \(H<0\)。若按**固定初始权重**保存各地局部 \(\log V\) 并平均，局部不等式和 Jensen 给同一平均场的下界。冻结球的齐性恰使有限球体积比等于中心 Jacobi 体积比。

**绝对真空应力的几何交审。** 在无焦、各向同性的 pp 波片写 \(g=p(U)^2\eta_{\rm flat},\ dU=du/p(u)^2\)，有 \(R=0,\ R_{uu}=2K\)。两事件的世界函数与 Van Vleck 因子分别为 \(\sigma_g=(\Delta u/\Delta U)\sigma_{\rm flat}\)、\(\Delta_{\rm vV}^{1/2}=\Delta u/[p(u)p(\bar u)\Delta U]\)。两式相除，指定共形拉回真空的两点核恰等于 Hadamard 主项；传输系数只依赖零坐标，质量与 \(R\) 皆零，无局部尾。应先减去主项，再对平滑余量施加协变双微分。一般 \(\nabla_cR_{ab}=(2K)'\ell_c\ell_a\ell_b\ne0\)，但 \(\Box R_{ab}=R_{ac}R^c{}_b=R_{acbd}R^{cd}=0\)。固定平直真空能和实测 \(G\) 后，局域曲率平方反项消失，故该指定态和方案可给零绝对应力。有限齐性球内 \(R=-8\pi G\dot\phi^2\)；其最小耦合传播、参考态与局部重整化须另证，不能从 pp 波移植零参考应力。[原几何推导](../../geometry/README.md)
