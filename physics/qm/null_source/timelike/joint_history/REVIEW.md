## 1. 已关闭的具体任务

第一闭环：从真实正负条件能量偏差出发，同步选择合法量子态与几何，在固定 U0、M2、AE 处方下得到两个完整静态平均历史。状态不是逐时重置，全部平均方程及其法向导数全时成立。成功／失败都有明确概率，完整源能量包括八个热振子的真实涨落。

第二闭环：在该模型的所有正能量静态分支上证明全局均值上限，进而对任意完整记录分解得到条件方差下界及大于10%的加权相对约束 RMS。这个反思结果排除了继续细分静态记录来消除共同源噪声的方向。

## 3. 机器检查的实际内容

1. algebra：两个 Einstein 分量与独立迹恒等式、三次位移、后验矩、全方差、八振子累积量、真实热响应与全局单调性。
2. instrument：90位区间计算实际 t=10^-12 的两支完整概率、均值与方差；保留相位／共轭反作用合同。
3. history：相关前驱根恒等式、粗端点及导数余量、六次区间图像收紧、正热占据和完整全时状态合同。
4. response：完整总能量卷积及热方差、局部噪声分解、加入实际热修正后的增长根与全源作用域。
5. bounds：全局静态 cap、完整记录方差与相对残差、有限 N 密度上界、保均值强降噪的极小成功率。
6. review：独立粗有理根包围、热占据下界、两个径向间隙和10%终点；检查其余证书及主张边界。

精确符号恒等式承担“残差为零”证明；区间运算承担实际参数与符号余量。没有把宽区间恰含零当成方程已精确成立。JSON 十进制由外向取整给出，极小 c−1 低于 double 分辨率时，以解析 c=1+2t/ν 及90位内部证书为准。

## 4. 禁止跨越的结论

| 已成立 | 不由此推出 |
|---|---|
| 一次给定的状态—经典几何 CQ 准备 | 已有局域控制器因果地产生它 |
| 每支全时 mean-SCE | 算符 Hamiltonian 约束或量子引力已闭合 |
| 输入 M2 及 U0 固定 | 条件源均值、第一场边缘没有改变 |
| 固定背景非选择筛选保持应力记录 | 之后改变几何／热态的全部准备也保持原能量律 |
| 完整源局部噪声分解 | 新非齐性反馈核已数值求出或已传播到仪器 |
| 总源不变记录同律 | 任意非 O(2) 探针或未知引力模型均不可辨 |
| 新实际态有正线性增长根 | 已证明非线性失稳或所有物理模型不成立 |
| 全记录加权相对残差 RMS>10% | 每支普遍大于10%、几何 RMS>10%或实验已测到它 |

总体物理统一目标仍开放。常势 U0、态选择、场内容、引力涨落法则和仪器合同都是需要独立物理选择的输入。
