# 条件量子态与几何的全时平均历史，以及闭合后的涨落限制

本轮接续精确提交 a40f7333a3100978674ae33892a409bfaa9aa7ff，处理上轮留下的“约束相容的状态—几何联合初值及其传播”。**现在已给出一个明确的新 CQ 准备：两个实际筛选记录各自对应正规 Hadamard 态与唯一静态几何，固定同一物质参数，全部平均 Einstein 方程在整条历史上成立。**

继续审查后又关闭一个独立问题：这个静态热缓冲模型不能靠细分全部记录消除原共同源噪声。记录数甚至允许无限，其条件源方差仍有严格下界；按各支总平均密度归一并对完整记录取均方根，残差严格大于 **10%**。这是额外二阶矩／算符约束验收的结果，不否定平均方程，也不是几何涨落测量。

Core 只读、GI 不在范围，正式书稿、Lean 与经验状态不升级。本轮只增加研究候选证明、实际计算及审查。

## 1. 反思改变了推进方法

前轮先得到初片根，再被同一实际态的法向导数排除；随后得到后释放共同历史，但其准备驱动与真实物质完成仍另有责任。本轮不再把“初片通过”当作接续保证。曾考察的有限指数准备可调初片约束，但仍留下更高法向导数缺口，故未把它登记为共同历史。

本轮改为直接设计一族完整合法静态态与几何，使两条场方程全时同时成立。正向闭合以后立即审查完整记录、状态响应与残差，而非把存在性自动升级为稳定性或完整引力理论。

## 2. 物理合同与真正改变

保持上轮的两个最小无质量实标量场、AE 处方 μ=1、无额外有限曲率项、G=2T、原相干尺度 M2 和同一常势 U0。U0 仍是明示物理输入，未从 Core 导出。

新的准备把两个零模的中心化 Var(P) 从 x0/2 减为 x0/4，同步增加共轭 Var(Q)，并在两场的完整 k=2 壳各准备相同热占据 n，共八个实振子。高模参考态按各自新几何合法定义。零模实际条件能量为 M2 μ_i，沿每条历史固定；固定 M2 不等于所有记录保留原平均源或原第一场完整边缘。

两个 CP 结果使用
\[
K_1=2^{-1/2}e^{-tS_0/2},\qquad
K_0=(1-\tfrac12e^{-tS_0})^{1/2},\qquad
S_0=(P_1^2+P_2^2)/(2\pi^2M_2),\quad t=10^{-12}.
\]
成功和失败均保留，两支正规、光滑。加入热壳以后，S0 只是零模能量，完整总能量还包含真实热模涨落。

## 4. 为什么平均闭合后仍不能认定物理统一完成

每支完整平均方程与全时合法性已经成立；但它们构成一次指定的几何—态联合准备，不是已实现的局域筛选反馈装置。源涨落严格存在，实际线性增长根也存在。完整噪声的代数分解已经给出，各支真正的非齐性反馈核、约束相容传播及可校准的引力记录仍需计算。

旧／新两种制备在相同径向预算下仍给出相同的全部 O(2) 不变记录，包括这次的几何标签。只在第一场看见的降噪不能自动变成完整总源的引力优势。进一步主张需要一个确实破坏这种记录等价、且把额外物理成本计全的操作合同。

## 5. 下一责任已由新结果收窄

1. 在明确的动态引力模型中处理联合初态相关和约束，保留真实零模、高模、热缓冲及全部固定 AE 项。新目标是能承载完整源分布的非静态正时间历史；不能只把静态记录分得更细。
2. 明确额外二阶矩验收究竟对应何种随机／量子引力动力学。mean-SCE 不要求算符残差为零；若采用更强要求，必须同时给出几何变量与初态，不能从平均方程凭空加入。
3. 计算同一新历史上的完整推迟响应、非齐性噪声传播和实际局域探针。全局 CP 筛选及其经典几何分支标签仍需真实控制器、因果性、总源成本与校准。
4. 追踪场内容、U0、准备态与探针的独立物理输入。只有减少独立假设、排除竞争完成或得到同资源可检验差别，才进一步承担物理统一目标。
