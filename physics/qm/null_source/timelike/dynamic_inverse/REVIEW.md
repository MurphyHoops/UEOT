# 本轮反思、证据等级与下一项闭环

## 1. 本轮改变了什么判断

前轮已经认证同一实际态的二阶几何、正时间窗方程残差及法向导数。
未关闭的是：是否存在附近精确共同历史，残差能否控制到该真解的距离。

本轮一开始尝试这个出口后，完整响应谱显示慢根不是全部不稳定自由度。
新快根同时通过约束、具有非零曲率响应，并与同 incoming 态的合法运输相容。
因此“过去静态极限加慢模前两阶即可确定唯一修正”的默认推断不成立在线性层面。
这不是对前轮小残差证书的否定；它限定了如何使用证书。

随后的推进已经形成四个相连的建设性结果：

1. 完整开右半平面根分类：恰有两条简单正实增长根。
2. 保留两根的因果线性逆及短窗增益，同时把它接到光滑的几何—态响应。
3. 全部纯／混合频率非共振，以及保留两幅度的双变量 graph 系数逆。
4. 有限势能范数及零常数项下，双变量精确 incoming Jost 态的阶乘收敛构造、Wronskian 与同 Q/P、eta_ref 运输；不要求小势能。它关闭实际态构造门，完整重整化非线性映射仍开放。

另一个关闭的误用入口是冻结片上态后只修改几何 jerk。
本模型中全阶 UV 合法性要求相应 jets 匹配；有限片上 stress 值不足以替代 Hadamard。

## 3. 为什么不在这里直接宣布“精确演化”或“统一”

因果逆证明使用静态背景和有限初片零过去域；旧非静态 seed 的完整过去不属于这个域。
解析系数逆保留两个幅度，但完整 AE 和无限模式非线性映射仍需证明落在同一空间。
这两处都是明确的分析缺口，不能用一个泛称“标准存在定理”越过。

文献核对也没有提供可直接套用的现成定理：

- [Meda–Pinamonti–Siemssen, 2007.14665](https://arxiv.org/abs/2007.14665)
  的存在结果针对平直 FLRW、massive 场及其明确数据／正则性；不能自动覆盖当前 closed S3、minimal massless 模型及无限过去合同。
- [Juárez-Aubry–Kay–Miramontes–Sudarsky, 2205.11671](https://arxiv.org/abs/2205.11671)
  对一般 surface-Hadamard 初值适定性提出的是猜想。
- [Parker–Simon, gr-qc/9211002](https://arxiv.org/abs/gr-qc/9211002)
  的降阶有其 hbar 阶次与物理解选择，不是本完整固定 AE 方程自动删根。
- [Hu–Roura–Verdaguer, gr-qc/0402029](https://arxiv.org/abs/gr-qc/0402029)
  区分 intrinsic／induced metric fluctuations 与处理 runaway 的方案。
  本轮均值线性响应没有替代完整涨落理论。
- [Gérard–Wrochna, 1209.2604](https://arxiv.org/abs/1209.2604)
  提供 Hadamard Cauchy covariance／parametrix 框架；
  本轮受限模型的 jets iff 是自己的推导。

研究仍明确使用选定的两场物质、U0、源制备、AE 方案和平均引力法则。
即使该模型的非线性共同历史完成，也只关闭统一目标的一项必要自洽关，
不会自动从 Core 推出所有物理输入、完整量子引力或经验正确性。
Core 本轮只读，GI 不在范围。

## 4. 闭合后已经改定的主任务

下一主路线保留慢／快两个幅度，研究双变量共同历史族；
不把单变量解析性、future boundedness 或 order reduction 默认为已获物理依据的选择。

优先验收依次为：

1. **完整非线性映射。** 在明确 graph／更强可控空间中建立
   \(\mathcal S[u]=\mathcal Lu+\mathcal N[u]\) 的 AE 局部项、精确 incoming Jost 高模、
   canonical zero modes 及 thermal 壳的共同正则性和余项。
   若 graph 域不够，明确加权或改用解析半径尺度，并给相应逆的损失；
   不把前轮慢窗 UV 常数借给快频率。
2. **真正的局部精确共同历史族。** 固定两个幅度一次后，给存在及可量化误差，
   或证明所选函数空间／过去合同不允许该构造。
   通过完整 Ward 与实际初值检验 Hamiltonian 约束；不得用逐时换根或冻结态 jerk 修补。
3. **物理选解。** 区分数学上可构造的共同历史族与物理制备能选出的幅度。
   额外几何数据、设备、边界或有效理论近似都要有独立责任，
   且相同完整联合输入必须采用共同规则。
4. **涨落与仪器。** 之后才接承接完整输入谱的明确引力涨落法则、
   联合约束数据、局域控制和 probe/clock，总应力、交叉相关、全部 CP 结果与校准一起核算。
   当前 old/new 若 full joint twirl 相同且选择／仪器协变，完整记录仍同律；
   给两者不同 fast 幅度是在改变几何输入，不能记为原降噪带来的引力信号。
5. **统一目标的最终尺度。** 用减少独立物理假设和同资源下可区分的经验检验评价，
   而不是用已完成证书的数目评价。
