## 6. 原降噪的引力目标需要怎样修正

### 6.1 均值几何不可辨识定理

旧／新制备对每个共同合法几何具有相同的完整平均 RSET 泛函。若同时使用相同初边值、同一个均值解选择规则，以及只依赖所得几何和共同辅助态的记录核，则全部几何记录联合分布相同：
\[
d_{\rm TV}(\mathsf P_{\rm old},\mathsf P_{\rm new})=0.
\]
预定的适应控制也可逐次条件化得到此结论。等先验最优误判为 \(1/2\)。

因此，即使新的共同平均历史构造成功，也不能仅从平均几何得到原降噪的判别。后续要判定的是：在明确的几何涨落动力学和总源控制下，是否存在可辨认且可校准的引力统计后果。

### 6.2 真实混合态的可执行统计出口

对同一合法实应力测试，写
\[
X_Y=Q+YL+(Y^2-1)S,\qquad
V_0=\langle Q^2\rangle,\quad V_1=\langle L^2\rangle.
\]
参考态反演对称给交叉二阶矩为零。对每个条件分支，
\[
\mathbb E(X_Y|Y)=(Y^2-1)S,\qquad
\operatorname{Var}(X_Y|Y)=V_0+Y^2V_1.
\]

原旧态的 \(Y^2-1=\pm\sqrt3/2\)，新态则为零。若一个自伴谱读出实现该统计，以
\[
|X|\ge\frac{\sqrt3}{4}|S|
\]
判旧，Chebyshev 不等式和原混合权重直接给
\[
e_{\rm old},e_{\rm new}
\le\frac{16(V_0+V_1)}{3S^2}.
\]
消费原归档背景的完整场界，得到两候选各自 \(<0.024016\)。它不需要 Gaussian 随机应力，也不需要第四矩界；实际装置仍须实现该读出并计入校准、失败与反作用。

非交换算子展开还给出
\[
\Delta\langle X^3\rangle=\frac94 S V_1.
\]
在原正密度测试上 \(S,V_1>0\)。因此，给新噪声独立添加一个中心对称秩一随机源，只复制协方差，不能复制原真实三阶应力统计。

### 6.3 同源准备装置不能遗漏

若额外采用逐分支平均引力规则，当前同一初片几何对原旧制备的约束残差约为 \(86.6\%\)；即使在整个旧参数族内变更合法参考态，严格下界仍 \(>0.86602\)。这个结果不否定 ensemble 初片平均方程，而是排除把同一 ensemble 几何直接赋给每个旧幅度分支。

真实实验要使用总源
\[
N_{\rm total}=N_{\rm field}+N_{\rm device}
+2C_{\rm field,device}^{\rm sym}.
\]
相同仪器校准不能代替装置应力及交叉相关的控制。

### 6.4 后继闭环：相关装置可以精确抵消协方差差异

将实际制备标签 \(Y\) 保留为经典寄存器，记 \(\delta=Y^2-1\)。在一个应力测试分量上，取与标签相关的中心化补偿
\[
D=-\delta S.
\]
它与原场变量 \(X=Q+YL+\delta S\) 同时存在时，
\[
\Delta\operatorname{Var}X=\frac34S^2,\quad
\Delta\operatorname{Var}D=\frac34S^2,\quad
\Delta\operatorname{Cov}(X,D)=-\frac34S^2.
\]
联合协方差增量
\[
\frac34S^2
\begin{pmatrix}1&-1\\-1&1\end{pmatrix}\succeq0
\]
满足正性，却使 \(\Delta\operatorname{Var}(X+D)=0\)；张量核版本将 \(S^2\) 替换为 \(S\otimes S\)。装置也恰好补偿这个分量的逐标签条件均值。这给出了单独场秩一降噪不能决定总引力噪声的具体代数机制。

抵消仅针对协方差。非交换展开保留所有字序，给出总源 \(Q+YL\) 的二、三阶矩差为零，而四阶矩差为
\[
\Delta\langle(Q+YL)^4\rangle=\frac34\langle L^4\rangle
=\frac94V_1^2
\]
，最后一个等号使用本参考态为 quasifree 且 \(L\) 为中心线性场变量。不能据此断言完整分布相同。

这是与原制备标签和联合协方差正性相容的反例；它没有建成具有所需应力的物理装置，没有免费修改固定源模型，也没有实现引力测量。新背景上的总源、实际传递算子及仪器误差须一起认证。

   中减去已处理的普适奇异部分，认证完整剩余算子范数。优先考察 \(T=2^{-21}\)，因为其低阶预算留有余量。
3. **同时满足释放与 Hamiltonian 条件。** 若研究准备驱动，守恒要求
   \[
   (a^4\rho_D)'=a^4h\tau_D.
   \]
   完整撤除还要求
   \[
   a_i^4\rho_D(\eta_i)+
   \int_{\eta_i}^{\eta_f}a^4h\tau_D\,d\eta=0.
   \]
   单独关闭 trace 可能留下 \(C/a^4\) 辐射项。形式残差的命名或平坦开关本身不能证明驱动装置可实现。
4. **在新共同历史上检验引力统计。** 明确几何涨落动力学、约束相容初值及其相关项，再计算实际 scalar／固有钟读出的应力 pullback，认证同背景的 \(S,V_0,V_1\) 和总装置误差。
