# 允许零模—高模相关后，完整静态记录仍有宏观残差

本轮直接接续 74a5fea8d853809671cac2e170dc0b656c80fee7 的[全时联合平均历史](../joint_history/README.md)。完成该闭环后，继续检查上一条大于10%残差界的乘积态假设：**能否用高模与零模的反相关、乃至纠缠，把总能量涨落抵消？**

现在给出更广类别的严格结论：允许这类相关、允许任意非负平稳高模激发而不限于热态或 k=2 壳，完整记录加权的相对源／约束残差 RMS 仍严格大于
\[
\boxed{\frac{d/2-1/\nu_0}{3\sqrt2\,L}>7\%.}
\]
它不延续乘积态的10%数值，也未证明7%为尖锐最优下界；7%—10%之间的相关态改进仍可能。它排除的是在这个固定静态物质模型中，靠相关性和更多平稳高模把剩余残差消除。

## 1. 先说明适用合同

每个记录 i 对应一个闭 S3 静态半径 \(A_i=\sqrt{x_i}\)，使用同一个 M2、U0、AE 处方和两个自由最小无质量实场。要求候选联合量子态正规、Hadamard，并已经满足完整静态平均 Einstein 方程。这里推导必要限制，没有构造新的任意纠缠态解。

高模边缘在自身静态背景上平稳，具有有限平均激发能量。高模与零模允许任意经典或量子相关；整个联合态不必平稳，因为正规自由零模的 Q 方差通常随时间增长。高模可以占据任意壳，也不必 Gaussian、热态或具有逐简并度相等的占据数。

全部记录必须保留，非选择性输入 S0 谱保持前驱新准备的共同律：
\[
\nu_{\rm prep}=2\nu_0,\quad
\nu_0=4\pi^2M_2/x_0,\quad
\nu_{\rm prep}S_0|R\sim\chi^2_2(\nu_{\rm prep}R),
\]
\[
R=1,\ 1+d\text{ 各 }1/2,\quad d=\sqrt3/2,\quad L=1+d/2.
\]
不限制记录数；若丢弃失败记录或另行改变输入 S0 律，必须重新分析。

这是全空间平均能量的定理。它不把闭 S3 的整体假设搬到原有限内球的未知外区，也不把局部重整化能量假定为正。

## 2. 任意相关态仍有同一个正能量算符分解

在各个静态背景的正规模式表示中，
\[
H_i=E_{c,i}+E_{s,i}S_0+H_{{\rm high,exc},i},
\quad E_{s,i}=\frac{\pi^2M_2}{A_i^3},
\]
\[
H_{{\rm high,exc},i}
=\sum_{j=1}^2\sum_{k\ge2,\ell}
\frac{\sqrt{k^2-1}}{A_i}\,N_{jk\ell}\ge0.
\]
这里全部 Casimir／AE 参考常数以及 U0 保留在
\[
E_{c,i}=V_i[U_0+r(x_i)/x_i^2],
\quad V_i=2\pi^2A_i^3,\quad r(x)=2B(x)-1/(4\pi^2).
\]
正性只针对相对静态高模真空的激发 Hamiltonian，不是假定完整重整化真空能量或局部能量密度非负。

S0 与高模 Hamiltonian 位于不同模式因子，强交换。联合态纠缠并不改变算符的这种性质。整片积分的零模—高模应力交叉项也恒等消失：零模空间常数，而所有 k≥2 谐波及其时间导数的空间积分为零。这不是把局部交叉噪声删除。

平稳高模振子的 virial 关系与空间正交给
\[
\overline p_{\rm high,exc}
=\overline\rho_{\rm high,exc}/3,\qquad
\overline\rho_{\rm high,exc}\ge0.
\]
该空间平均关系不需要各向同性占据或乘积态。完整静态 mean-SCE 是前提，因此其整片积分必须满足下面的两条必要方程。反过来，仅满足这两条积分方程并不证明各点的 Einstein 方程成立。

## 3. 从平均方程得到全局能量阈值上限

沿用前驱
\[
G(x)=4U_0x^3-3x^2-\kappa x,\quad
N(x)=3x-3U_0x^2-2B(x)+3D_0,
\]
\[
\kappa=1/(16\pi^2),\qquad D_0=3/(32\pi^2).
\]
前一节给出的空间平均必要方程仍是
\[
G(x)=M_2\mu>0,\qquad
N(x)=x^2\overline\rho_{\rm high,exc}\ge0.
\]
所以前驱单调性证明仍适用：G>0 的正区间上
\[
G'=3G/x+3x+2\kappa>0,\qquad
N'<-3/2-\kappa/x<0.
\]
结合 \(N(x_0)=0\)，所有允许分支均有 \(x\le x_0\)。

现在定义真正用于总能量补偿的阈值
\[
\tau(x)=\frac{\langle H\rangle-E_c}{E_s}
=\frac{3x^2-2U_0x^3-2r(x)x}{M_2}.
\]
注意 \(\tau=\mu+\langle H_{\rm high,exc}\rangle/E_s\)，一般不等于零模均值 μ。独立求导得到关键恒等式
\[
\boxed{M_2\tau'(x)=2N(x),\qquad M_2\tau(x)=G(x)+2xN(x).}
\]
从任意允许 x 到 x0 的整个区间都满足 N≥0，因此
\[
\boxed{\tau(x)\le\tau(x_0)=\mu_{\rm old}=L+2/\nu_0.}
\]
这一步不需要热占据数，也不限定高模的个数。

## 4. 正部谱不等式直接控制相关抵消

在第 i 支的联合谱表示中，
\[
H_i-\langle H_i\rangle
=E_{s,i}(S_0-\tau_i)+H_{{\rm high,exc},i}.
\]
令 \(y=E_s(s-\tau)\)、\(h\ge0\)。逐点有
\[
(y+h)^2\ge y_+^2.
\]
若 y≥0，这是 \(2yh+h^2\ge0\)；若 y<0，右端为零。强交换因此给严格的二次型／期望值不等式
\[
\boxed{\operatorname{Var}H_i
\ge E_{s,i}^2\left\langle(S_0-\tau_i)_+^2\right\rangle_i.}
\]
量子纠缠与负协方差都不能推翻它。正部不可省略：未经截取的平方不等式是假的，独立审查明确设置了这项负控。若二阶矩无穷，则按扩展非负实数解释，下界仍成立。

以每支 \(\langle\rho_i\rangle=3/(2x_i)\) 归一，并利用 x_i≤x0、τ_i≤μold，
\[
\mathbb E_i\frac{\operatorname{Var}(H_i/V_i)}
{[3/(2x_i)]^2}
\ge\frac{M_2^2}{9x_0^4}
\mathbb E_{\rm in}(S_0-\mu_{\rm old})_+^2.
\]
最后一步用到了完整记录保留原输入 S0 谱。不同几何上的全局标量记录可以这样条件组合；这不是把不同背景的局部噪声 bitensor 直接相加。

## 5. 实际输入的高半径支迫使残差保留

输入高半径 R=1+d 分支的概率为1/2，实际零模平均值是
\[
\mathbb E(S_0|R=1+d)=1+d+1/\nu_0.
\]
它超过允许总阈值的量为 \(d/2-1/\nu_0>0\)。对凸函数 \((s-\mu_{\rm old})_+^2\) 用 Jensen 得
\[
\mathbb E_{\rm in}(S_0-\mu_{\rm old})_+^2
\ge\frac12(d/2-1/\nu_0)^2.
\]
故完整记录加权相对方差至少为
\[
\frac{M_2^2}{18x_0^4}(d/2-1/\nu_0)^2.
\]
前驱精确根恒等式与 E(x0)<0 给 \(M_2/x_0^2>1/L\)。因此
\[
\boxed{
\left[
\mathbb E_i\frac{\operatorname{Var}(H_i/V_i)}
{\langle H_i/V_i\rangle^2}
\right]^{1/2}
>
\frac{d/2-1/\nu_0}{3\sqrt2 L}>0.07.
}
\]

90位区间输出见 [correlations.json](correlations.json)。严格7%终点还有完全独立的粗有理证明：只需 \(\nu_0>1000,d>43/50,\sqrt2<17/12,L<23/16\)，已经留有正余量。

| 类别 | 已证下界 | 必要条件 |

| 前驱具体零模／热壳条件乘积准备 | 完整记录加权相对 RMS >10% | 前驱固定物质、全部记录、共同 S0 律 |

这不是任意单个分支的普遍下界，不是几何 RMS，也不否定 mean-SCE。它排除了“仍保持相同静态物质合同，只加入高模反相关或更多平稳壳，就把强约束残差消除”的方案。没有证明相关性不能把10%改善到7%—10%之间，也没有证明本界尖锐。

下一任务因此继续集中于**动态联合初态、明确的引力涨落法则和正时间窗约束传播**。若改用非平稳高模、相互作用或不同输入谱，必须说明所改物理假设并计算其完整后果；仅增加静态源相关性的自由参数已不足以解决当前缺口。完整局域探针、真实控制器、经验分离和 Core 物理选择仍开放。
