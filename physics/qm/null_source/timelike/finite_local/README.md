## 4. 关闭旧角向出口，再检验真正不同的径向源

完整 O(2) twirl 相同、共同线性 CP 动力学及不变读出下，原 old/new 的全部引力源均值、噪声、响应输入和记录同律。继续增加精度不会解除该等价。任意非线性协变规则也不能直接冒充这种操作合同。

因此另行定义新准备：原高斯块协方差、高态、M2、U0 不变，比较等权 R=1 与 R=1+sqrt(3)/2 的双环，及 R=L=1+sqrt(3)/4 的单环。它们是正常量子态，完整二点函数相同，但
\[
 \operatorname{Var}_{two}S_0-\operatorname{Var}_{mid}S_0=3/16,\qquad
 N_{two}-N_{mid}=(3/16)J\otimes J.
\]
单环仍有量子块内方差 <1.56e-11；移除的是额外经典径向混合方差。完整源的生成函数和三、四阶累积量差也已给出。

在同一精确静态平均几何及同一正窗：
\[
 {\cal R}_{mid}<1.4\,10^{-6},\quad {\cal R}_{two}>0.14,\qquad
 {\cal R}_{two}^2-{\cal R}_{mid}^2={3\over8}
       \left({M^2\over3A^4}\right)^2.
\]
全部高模压力尾与有限热壳保留。这是源侧残差矩，不是度规 RMS 或稳定性。

一个新的完整 mid/out 环带读出给源记录 TV>0.999743，等先验误判 <1.3e-4。但其相对指针动能增量上界是0.86；它合并原双环的两个半径，**不能继承旧 low/high 后验风险或反馈几何**。单环低噪声在读出前已存在；源分类也不是引力测量。

## 5. 闭合后反思：精度、时钟和引力法则

单环只在固定高斯块的径向混合族内最优。相邻奇数 Gamma 径向 Schwartz 态的正常混合可保持与均匀角向参考态相同的完整二点函数，进一步把源方差约减半；其 dilation 时钟方差约增至两倍。该数学候选未被实际制备。

对有限二阶矩正常态，适当弱算符域上的不等式为
\[
 V_DV_S-\operatorname{Cov}_{sym}(D,S_0)^2\ge\mu^2.
\]
原单环在额外固定原 D 资源后，距全正常态下界只有 4r^2L/(L+4r)<4r^2。保留协方差后，这个界对已知自由剪切 D->D+cS_0 不变。现有 shift-symmetric 源读出对零模自由时间编码严格盲；D 钟需要另一个真实参考和仪器。[完整资源证明](CLOCK_RESOURCE.md)

更关键的是，两新准备在任何共同线性背景族上的二点函数都相同，所以完整平均响应（包括共同 contacts）相同。在相同初始几何和选解规则下，确定性 mean-SCE 本身不产生不同几何。要让新的噪声差成为引力后果，必须明示 beyond-mean 动力学、约束相容初值、总源及观测。零初值的齐性 retarded inverse 也不能不经约束检查就作用到恒定源噪声。
