# 有限初片、实际局域仪器与同态正窗：本轮闭环

本轮把同一实际制备、两个完整测量结果、合法态运输和未来方程残差接成一条可验算的链。**实际短时局域测后态的两个空间平均方程，联合归一化 RMS 上界小于 \(7.6\times10^{-6}\)**；区间计算给出的保守上端约为 \(7.500867\times10^{-6}\)。同一 \(M^2,U_0\)、原源谱、热壳和 AE 约定保留。没有重置高模，没有把零模—高模的条件相关设为零，没有逐时换根，也没有丢弃结果。

这仍不是完整局域物理历史或物理统一。准备几何目前是明确指定的光滑背景，其控制器总源尚未实现；局域探针实际产生的非齐性应力已被算出，不能用两个齐次投影代替全部 Einstein 方程。PR 保持开放草稿。

## 1. 由反思改变设计，再完成真实态预算

先构造有限初片的全未来膨胀族和一个平滑辅助 Hadamard 高态，证明完整重整化均值及两条正时间窗涨落界。随后发现，当前固定源只有两个相距很远的径向分量，连续高精度读源并非必要。

新的方案采用 \(w_{\rm ptr}=C/2500\) 的弱局域 Gaussian 耦合，加一个只有两个结果的平滑径向读出。全部结果保留，内部 \(O(2)\) 对称性保留；没有先读连续方向再删除记录。源后验风险小于 \(1.56\times10^{-11}\)，平滑读出本身也有有限指针能量。

实际测后态通过同一个 CCR 演化映射运输。高模激发及所有条件相关性由正算符支配和 Minkowski 矩界处理。两个结果的制备都有统一有限时长，通过显式等待对齐共同 proper-time 起点；等待相位和 \(Q/P\) 剪切均保留。

## 2. 完整局域张量现在给出具体下一关

短时耦合后的实际非选择态具有
\(\Delta\langle T_{\mu\nu}\rangle=2sT_{\mu\nu}[u]\)，其中 \(u=Ef\) 是同一局域测试的传播解。其支撑仍在一个真球帽内，而零模积分不为零。Poincaré 与 Cauchy 不等式给出严格非零的各向异性应力下界：
\[
\int|\Delta\pi|^2dV>{1\over12\pi^2A w_{\rm ptr}^2}>1.7\times10^{-42}.
\]
该数很小，只排除“完全无各向异性”的精确说法，不说明已达到可探测量级。完整二结果平均保留它，所以至少一个真实分支需要非齐次几何或明确的装置补偿。

同一核还给真实注入目标场能量的上下界 \(A/(4w_{\rm ptr})<\Delta E<1.88\times10^{-11}\)，以及局域新增噪声
\[
\Delta N=s\sum_i\langle\{L_i,L_i'\}/2\rangle+4s^2T[u]T[u'].
\]
它对所有实光滑时空应力测试都是正半定增量；原 CQ 混合和跨场相关均保留。条件源精度提高，不等于完整非选择应力噪声降低。

## 3. 装置合同已具体化，但总引力源未闭合

有限局域 kinetic field-probe 在 \(|g_c\chi|<1\) 时有精确双 Green 核、正常双曲演化、in/out 平移荷守恒和非零有限耦合读源增益。具体探针及读出有正零模能量责任。它是一个明示新增的装置模型，不是从 Core 推出的唯一仪器，也未被证明在有限耦合精确等于前述理想指针协议。

热核计算显示，新相互作用引入 \((\Box\chi)^2\) 及曲率混合项；旧自由场 AE 规范不固定其有限系数。相应控制器应力和四阶力项必须一起进入 Ward 恒等式。

若高源强结果后仍固定原静态几何，即便允许高态变化，所需额外平均能量仍严格为负，幅度超过原正密度归一化的 10%。这排除该合同下单独使用非负能量控制器；理想不改高态的特例还有 NEC 障碍。它不是所有量子装置或其它共同几何的排除定理。
