## 1. 同一最小场的绝对应力起点

参考态绑定原 `instrument.state_scale`：辅助静态三球 a0²=3，在 eta∈[−1/8,−1/16] 平滑插接到实际内核 a=√(3cos2eta)。这段辅助历史定义 Hadamard Cauchy 数据，并未被声明为原有限球源的自洽制备历史。

零空间模没有正频振子真空；代码选择的纯高斯具有 Var q=1/6、Var p=3/2。它的有限贡献是 rho0=p0=3/(8 pi² a⁶)，不能删除。

采用 Anderson–Eaker 的正曲率重整化处方、mu=1、不额外加入有限曲率项。在该**辅助静态段**，1024个模式加上解析二项级数尾给

\[
 \rho\in[-0.000052130755106095,-0.000052130754942430],
 \qquad
 p\in[0.00103805207790565,0.00103805207796021].
\]

尾界来自逐项正系数与积分比较，未用两个浮点截断值接近代替证明。重整化补项经原始论文公式、零模以及共形归一化独立交叉检查。该结果依赖所选有限耦合方案；重整化尺度变化须与引力侧耦合一起变换。

在原收缩内核，保持同一最小量子场，在 k=3 的九维壳叠加强度 epsilon 的正光滑协方差，得到

\[
 \Delta\rho=\epsilon(\sec2\eta-\tfrac12\cos2\eta),\qquad
 \Delta p=\epsilon(\tfrac56\cos2\eta-\tfrac13\sec2\eta).
\]

它严格守恒，未改高频模和反项在态差中精确抵消。独立 Hamilton 初值积分在三个半径上复算应力，最大浮点差小于9×10⁻¹⁶。

在固定均值动量、相同物理半径、存在正规半经典扰动分支的前提下，得到差响应系数 delta H/(hbar epsilon)=(delta rho/epsilon)/(3 Hcl)。在 a/a0=.94 时为 −0.70657706144。该数是**第一阶系数**，不是有限hbar下带高阶余项的非线性反馈解。辅助静态段的应力也不能放到物理转折面上；两处即使半径相同，曲率和态历史仍不同。

## 2. 装置相容初值与转移反例

在原初片加入面积半径[.65,.67]、峰值密度.1的正球壳，约束解给

\[
 \delta(GM)=0.000216206977036444\ldots,\qquad
 \sup_R 2\mu/R<0.750666<1.
\]

R<.65的初值保持完全相同，中心在eta=3/8收齐原几何记录，其共同内域因果余量为[.00969632613517,.00969632613521]。这是标准经典Einstein–物质Cauchy框架下的内域保护；完整量子初值、装置运行寿命与非球对称设备不由此自动认证。

同一个密度壳可由初始静止尘埃或第二最小标量实现。两者rho、j、gamma、K相同；压强不同。在测头位置，原源场的三阶固有时导数分别为2.1和2.4，中心两者仍为2。进一步把壳变薄，可以让总质量趋零而该局部导数差无界。这严格否定仅凭总质量给当地三阶转移导数统一上界；它不证明有限窗场幅误差或概率误差无界。后两者仍需完整动力学估计。

## 3. 有限资源下不能从数据自行认证任意尾

取对称X、E X²=3/4，基准在0及±3/2上分配概率。把少量概率移到±M，精确保持二阶矩；单次分布总变差可任意小，而四阶矩随M²增加。制备到量子态的混合、保留辅助系统、集体或自适应仪器，都不能放大输入迹距离。至多N次独立制备的全部输出总变差至多为N倍单次总变差。

因此，对这个无共同尾界的完整候选类，若统计上限U满足统一覆盖率至少1−alpha，则在基准态上必有P(U=+infinity)≥1−alpha。此处是有限样本统计障碍，不是声称两个候选对所有无限资源实验都完全等价。它也是一个标准统计不可估计现象在同源量子场制备类中的明确构造，不宣称整个现象为新的统计学定理。

精确有理算例中，100万次制备的全部输出总变差仍≤.001，四阶矩却可从1.6875变为约2.25×10⁹。每个候选有限能量不足以排除这一族；如果现实逐次高能分支会被其他动力学或准备机制排除，必须把那一排除机制写入候选合同。

若另有独立的E|X|^(4+epsilon)≤K，0<epsilon≤2，则两个已校准的特征函数给

\[
 D_t=\frac{6-8\operatorname{Re}\chi(t)+2\operatorname{Re}\chi(2t)}{t^4},\qquad
 D_t\le E X^4\le D_t+(t^2/6)^{\epsilon/2}K.
\]

校准与抽样误差要再按t⁻⁴放大。K必须来自独立物理约束或准备合同；同一份有限记录不能无假设地认证它。

## 4. 已执行的合成研究没有被写成成功实验

新增单孔径连续指针方案显式计入有限指针宽度、时序产生的P²剪切及其校准、全启动记录、溢出旗和量化。它避免把整壳同时作用默认为免费单探针，但仍是一个有条件的设计。

在原参考态的小孔径噪声下，实际生成A/B各20万次，共40万次合成记录；两者四阶矩区间均退回先验[.5625,1.6875]，**未能区分**。同记录、同预算的普通四阶去卷积与该估计逐项一致，没有发现UEOT方法增益。

在硬支撑、精确二阶矩、指针剪切补偿和规定方差校准条件下，对预先固定的中点分类规则，保守Chebyshev设计需每候选105,510,961,574次启动。此数是指定估计方案的前瞻充分预算，未实际执行，不是最优下界，也未含独立校准启动及完整装置成本。它用于裁决这条小孔径设计在当前参数下成本极高。更好的测量与估计仍可研究；无尾合同的普遍统计障碍不会因此消失。
