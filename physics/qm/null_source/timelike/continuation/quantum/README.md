## 2. 同一准备态的绝对应力：一个有严格尾界的起点

本节所在时空是**辅助静态三球**，不是有限源的物理历史。固定 a₀²=3、ℏ=c=1、最小无质量场、ζ=1、平直真空能归零和已定 G。重整化采用 Anderson–Eaker 的 K=1 处方，μ=1（所用长度单位的倒数），不额外添加有限曲率张量项。这是明确的物理/方案输入，不是 Core 推出的选择。

正曲率空间的模式和与局部绝热减项之间有有限补项。只做逐模扣除不能得到完整绝对应力。处方来源是 [Anderson–Eaker, 1999, Eq. (9)–(12)](https://arxiv.org/pdf/gr-qc/9906055)；此处只使用其确定的重整化补项，下面的谱和、零模与余项从本模型直接推导。

设

```math
r_k=k^2\sqrt{k^2-1}-k^3+k/2+1/(8k),\quad k\ge2,
\qquad
S=1/8+\sum_{k=2}^{\infty}r_k,
\qquad L=\log(\mu^2a_0^2/4)+2\gamma_E.
```

1/8 正是零模原始能量系数 1/2 减去 k=1 的高频扣除 3/8。静态下处方化简为

```math
\rho_{\rm ren}=\frac{S}{4\pi^2a_0^4}
 +\frac{-3/160-L/64}{\pi^2a_0^4},
\qquad
p_{\rm ren}=\frac{\rho_{\rm ren}}3
 +\frac1{12\pi^2a_0^4}+\frac1{96\pi^2a_0^4}.
```

最后两项分别来自零模的刚性压力和解析补项的迹。改变 μ 时
∂ρ/∂logμ=−1/(32π²a₀⁴)，对应有限曲率耦合的重新记账；若要求同一物理理论，必须同时变换引力侧耦合，不能把方案变化称为新的实验差异。

### 严格余项

由
√(1−x)=1−x/2−x²/8−Σ_{j≥3}c_jx^j，
c₃=1/16 且 c_{j+1}/c_j=(2j−1)/(2j+2)<1，可得

```math
-\frac1{16k^3(1-k^{-2})}\le r_k\le-\frac1{16k^3}.
```

再以递减正函数的积分比较界住 Σ_{k>N}k⁻³，得到

```math
-\frac1{32N^2[1-(N+1)^{-2}]}
\le\sum_{k>N}r_k
\le-\frac1{32(N+1)^2}.
```

程序采用 70 位向外区间算术完成前 1024 项，最后再向外转为双精度端点。这是解析余项证书，不是比较两个截断值。

| 量 | 保守区间 |
|---|---|
| ρ | [−0.000052130755106095, −0.000052130754942430] |
| p | [0.00103805207790565, 0.00103805207796021] |
| (ρ+3p)/2 | [0.00153101273930543, 0.00153101273946910] |

应力单位是所选长度单位的四次倒数。负的重整化能量密度与正压力并不矛盾。作为不同场的**归一化交叉检查**，同一静态三球的共形真空处方返回 1/(480π²a₀⁴)，也等于离散零点谱的 ζ(−3)=1/120 结果；此检查未替换原最小场。

## 3. 内球的动态高频结构已经可明确核对

对任意尺度因子设 h=a'/a，v_k=a u_k，q=−1−a''/a。原最小场满足

```math
v_k''+(k^2+q)v_k=0.
```

原物理内核上 q=sec²2η，故 v_k''+[k²+sec²2η]v_k=0。这是该内核的精确化简。

原始密度和压力分别由

```math
e_k=|v_k'-hv_k|^2+(k^2-1)|v_k|^2,
\qquad
s_k=|v_k'-hv_k|^2-\tfrac13(k^2-1)|v_k|^2
```

乘 k²/(4π²a⁴) 后求和。令 v=(2W)⁻¹ᐟ² exp(−i∫W)，则 W²=k²+q−W″/(2W)+3W′²/(4W²)。依次比较 k 的幂得到 W=k+q/(2k)−(q²+q″)/(8k³)+O(k⁻⁵)。代回原始密度与压力，给需要扣除的项
e_k^d=k+E₁/k+E₃/k³，
s_k^d=k/3+P₁/k+P₃/k³，其中

```math
E_1=(h^2-1)/2,\qquad P_1=q/3+h^2/2+1/6,
\qquad E_3=[q^2-2(h^2-1)q+2hq']/8,
\qquad P_3=-q^2/8-q''/12-(3h^2+1)q/12+hq'/4.
```

把 q=−1−h'−h² 代回后，两个阶次都严格满足
E_j'+h(−E_j+3P_j)=0，等价于密度除以 a⁴ 后的应力守恒。这同时检验了压力和密度必须配套扣除。内球上

```math
E_3=\tfrac38\sec^2(2\eta)[1-3\tan^2(2\eta)],\qquad
P_3=-\tfrac18\sec^2(2\eta)[7+27\tan^2(2\eta)].
```

在辅助静态段 E₃=−1/8，在物理转折点却是 +3/8。**两处都取 a=√3，仍不能共享同一个绝对应力数值。**

动态绝对计算的待完成式是：在实际插值上演化原始模，求 Σ k²(e_k−e_k^d)，加入同一 μ、有限耦合的完整解析补项，并对这个实际演化后的频率尾给上界。局部扣除系数、Hadamard 性质和有限截断的稳定性，单独任何一项都不是该数值余界。本轮不提交未经此证书支持的球内绝对应力。

这一结果扩展了旧文仅给的有效应力项，给出了可直接代入约束和演化方程的完整齐性应力。守恒

```math
H_{\rm cl}=-\sqrt{9/a^6-1/a^2},\qquad
\frac{\partial H}{\partial(\hbar\epsilon)}\Big|_0

```
