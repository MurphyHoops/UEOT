# A 对 B、C 的独立交叉审查

日期 2026-11-19。审查文件与逐文件 SHA 见 [review_bc.json](review_bc.json)。[独立复算程序](review_bc.py) 使用另一种求和顺序和积分表达式，未导入 B 或 C 的计算函数。审查结论为所声明范围内通过。

## B：原最小场的静态种子及有限秩响应

1. **制备身份与零模。** 实际 instrument.state_scale 是 −1/8 至 −1/16 的过渡。k=1 的 Laplacian 本征值为零，原高斯 Vq=1/6、Vp=3/2 满足 VqVp=1/4；物理导数归一给 ρ0=p0=3/(8π²a⁶)。这部分不能当普通非零频振子真空删除。
2. **另一求和方向。** B 对模 k≤1024 求和并界住 k 尾。A 改为对二项系数阶 j 求和，使用
   S=1/8−Σj≥3 cj[ζ(2j−3)−1]。正项双重和可交换。j≤80 后余项不超过 (4/3)c81[ζ(159)−1]，所得 S 及静态 ρ 落在 B 的区间内。
3. **有限解析补项。** 直接核对 Anderson–Eaker 原式 (12)。静态 K=1 给 H1⁰₀=−18/a⁴、H3⁰₀=3/a⁴。ξ=0、m=0 后，三个贡献分别为 1/480、1/96、−(2+L)/64，合为 −3/160−L/64，再除 π²a⁴。论文 (+−−−) 的迹与本项目 (−+++) 的迹转换后，几何迹补项为 +1/(32π²a⁴)。原高斯零模贡献另一 +1/(4π²a⁴)，与回执吻合。[原式 (9)–(14)](https://arxiv.org/pdf/gr-qc/9906055)
4. **有限秩壳。** 从 F=√3 sin(2η)/2 的动能与梯度能独立构造 ρ、p，符号结果与 B 一致。固定物理半径时，从 H²=2ρ/3−1/a² 得 δH=δρ/(3H)，但必须保留其可微扰动分支、共同经典动量和 O(ℏ) 耦合前提。
5. **范围。** 静态辅助背景与物理转折面的 q 和曲率不同。B 已明确动态绝对应力、实际插值后的 UV 尾和有限扰动余项仍开放，本审查不扩展这些结果的适用范围。

## C：装置壳约束与局域转移

1. **初始约束与质量。** 用精确有限多项式积分重新求 I0、I2 及 δGM，得到完全相同的有理数 7707885568/35650494140625。面积半径的 μ′=R²ρ 与固有体积能量不同，C 的定义一致。
2. **初片几何及因果余量。** 独立计算外缘径向度规比、asin(.65/√3) 及中心固有时积分，均落 C 区间。再用另一径向原函数作高精度积分，壳固有厚度变化也落原区间。
3. **压力反例。** 初始 φ=0、Kij=0 给 φ̈=0；KG 与 Raychaudhuri 给 φ'''=ΔΠ+RnnΠ。尘埃与刚性标量的初始能量和动量相同，空间应力不同，故壳中心的三阶导数差是 3h，场差首项是 hτ³/2。无需把外部初始几何保持为原三球。
4. **范围。** 正密度薄壳总质量趋零而当地三阶导数差无界，只否定质量对该局域导数的统一控制。C 已明确不据此推断固定有限窗的 C0 误差无界，也不声称装置具有共同长寿命。中心保护依赖相同初始内域的经典因果唯一性，半经典量子约束仍待处理。

## B、C 对 A 的回审及修正

C 指出有限时窗连续指针的 P² Magnus 剪切是物理可见项，已经进入 A 的补偿合同和失败负控。B 与 C 独立发现原零中心量化网格在端点半格处可能超出 R，A 已改为含端点的有限网格、再次截幅并计入解码舍入裕量。B 核对了不确定高斯方差的 Hermite 二阶矩上界与 Gaussian 尾矩界，要求先对未量化截幅变量使用方差界，再加入量化的确定误差。文档已明确依此顺序计算。

前瞻启动预算只保证指定 A/B 中点阈值分类的错误概率，不保证两条独立置信区间必不相交。40 万条实际合成记录没有产生区分，仍保留该失败结果。
