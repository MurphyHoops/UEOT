# 两道量子门能否识别同一时段的应力？

**结果。** 在有限球的同一固定度规上，同一个自由、最小耦合无质量实标量有两种 Hadamard 制备，全部径向场读出相同，而整个时段的中心重整化能量密度不同。若严格要求内区齐性，原来的两道定强度门也有精确反例。两个例子都保持带符号的制备、可见度及两只探针的整个联合密度矩阵。[基线有限球](../../FINITE_WINDOW.md) · [仪器合同](../instrument/CONTRACT.md) · [运行回执](observed.json)

## 仪器与完全等价的判据

取初始内核半径为长度单位，\(4\pi G=1,\ a=\sqrt{3\cos2\eta},\ d\tau=a\,d\eta\)，经典均值为 \(s f,\ s=\pm1,\ f=\sqrt3\,\mathrm{atanh}(\sin2\eta)/2\)。沿用两窗 \([1/32,1/16],[5/32,3/16]\)、仪器组紧支 \(C^\infty\) 开关、\(\chi<1/10\) 的归一径向空间涂抹及 \(g=1/20\)。记 \(F_j\) 为涂抹场算符，\(L_j\) 为同样作用于经典解的线性泛函。单门 \(z_j=\langle e^{2igF_j}\rangle\) 给 \(p_X(\pm)=(1\pm\Re z_j)/2,\ p_Y(\pm)=(1\pm\Im z_j)/2\)。

先按 \(sf\) 位移同一个中心准自由 Hadamard 态，得制备 A；再按独立随机光滑实解 \(h\) 位移得 B。给定两比特的 \(Z\) 历史 \(r=(r_1,r_2)\in\{\pm1\}^2\)，\(U_r=e^{-igr_2F_2}e^{-igr_1F_1}\)。约化矩阵元为 \(\langle U_t^\dagger U_r\rangle/4\)。B 仅多乘 \(\mathbb E e^{ig(t-r)\cdot L(h)}\)，两态的场交换子相同。下列两种构造都使这个因子逐元等于一。因此联合测量、输入反转、不再接触场的辅助比特及正概率记录的条件统计均相同。

## 任意径向时间窗的空间盲方向

在单位三球极坐标令 \(h_i=F(\chi)n_i,\ i=1,2,3\)，其中 \(\mathbf n\) 为角单位向量，\(F=3(\chi-\sin\chi\cos\chi)/(2\sin^2\chi)\)。\(F=\chi+O(\chi^3)\)，且 \(F'+2\cot\chi F=3\)。求导得 \(F''+2\cot\chi F'-2F/\sin^2\chi=0\)，所以这三个时间无关解均满足 \(\Box_g h_i=0\)。取 \(h=\sum_i b_i h_i\)，三个 \(b_i\) 独立服从 \(N(0,\sigma^2),\ \sigma=1/4\)。B 的均值与 A 相同，协方差多出光滑正核 \(\sigma^2\sum_i h_i(x)h_i(y)\)。它仍为 Hadamard 准自由态，在旋转不变的参考上也保留球对称。角积分逐个为零，故所有径向涂抹都给 \(L_j(h)=0\)，包括加窗、重复门和改变耦合强度。

同一局域协变点分裂处方给 \(\Delta\langle T_{\mu\nu}\rangle=\sigma^2\sum_i T_{\mu\nu}[h_i]\)；几何反项相消，KG 方程保证守恒。中心正交标架中 \(\Delta\rho=3\sigma^2/(2a^2),\ \Delta p=-\Delta\rho/3,\ \Delta T_{\hat0\hat i}=0\)。在 \(\eta=0,1/8,1/4\) 的额外密度分别为 **0.03125000、0.03225266、0.03560919**。中心还恰有 \(\Delta(\rho+3p)=0\)，单独读取瞬时聚焦也会漏掉这项密度。这组态在内区具有中心球对称，完整应力可随半径变化。[点分裂应力的原始论证](https://arxiv.org/abs/gr-qc/0109048)

**新增操作。** 在 \(1/8<\chi<3/16\) 的光滑归一球壳上，将角权改为 \(1+\cos\theta\)。沿极轴的模式平均为 \(\bar F/3=0.052912508\)，其余两个为零。两态单窗可见度之比精确为 \(\exp[-(2g\sigma\bar F/3)^2/2]=0.999999125084\)。保持原弱耦合时，需要优于约 \(8.75\times10^{-7}\) 的相对可见度精度及相应漂移标定。两态的一阶相位相同。

## 严格齐性的反例与能量代价

从同一 A 改为等权加减齐性解 \(h=q+pf\)，得混合态 B′。用正源 \(\mu_j=L_j(f)\)，选 \(p=\pi/[g(\mu_2-\mu_1)],\ q=-p\mu_1\)。于是 \(2gL_1(h)=0,\ 2gL_2(h)=2\pi\)：每个分支只多一个与比特历史无关的相位。随机符号保留相同一阶均值，二点函数多出光滑的 \(h(x)h(y)\)。在内核 \(\Delta\rho=\Delta p=p^2(a_0/a)^6/2\)，满足 \(\dot{\Delta\rho}+6H\Delta\rho=0\)。内核两制备都可选为齐性、各向同性。

实算 \(q=-22.968001,\ p=282.455766\)，初始额外密度约 **39890.63**。一个独立逐制备振幅或能量上限可排除这对候选。第二门单独运行且把 \(g\) 减半，B′ 的复对比度反号，下表参考态下 \(p_X(+)\) 从 **0.997772942** 变为 **0.002227058**。若仅以概率 \(\epsilon\) 混入 B′，原菜单仍完全相同，额外平均应力与新读出差都乘 \(\epsilon\)。

两种构造均可取光滑紧支初始数据。在 \(\chi\le1/2\) 保留上述数据，到 \(9/16<\arcsin(1/\sqrt3)\) 平滑截为零。所有旧门、新球壳和所报中心读数均在未改初片的因果发展域。空间模式取零初速度，齐性额外解取初值 \(q\)、单位法向导数 \(p\)。程序积分完整初片含过渡区的 \(\tfrac12\int[(n\cdot\nabla h)^2+|Dh|^2]dV\)，平均额外固有能量分别为 **1.3968443、157832.0551**。每个样本的制备能量有限，高斯分布容许无统一振幅上限。球内点分裂在光滑背景上计算；任选光滑全局双曲延拓再限制到该域亦可，未在原外圈有限阶光滑接缝上作 Hadamard 展开。

## 两只实际合同探针的完整概率

## 主审四阶矩与条件反馈

主审使用原多项式窗和相位标尺 \(2g=1\)，本节按其四个频率 \(a,b,b-a,a+b\) 复算。对固定制备符号 \(Y=\pm1/2+X\)，对称的 \(X\) 及 \(\mathbb EX^2=3/4\) 固定了 \(Y\) 的前三阶矩。给定实光滑紧支时空张量测试 \(F\)，记 \(A=T_{\rm ren}(F), C=T[f](F)\)。按 \(Yf\) 位移有 \(A\mapsto A+Y L+Y^2 C\)，其中 \(L\) 线性于场。共同参考、相同前三阶矩使方差展开中所有三次及以下项相消，故 \(\Delta{\rm Var}(A)=C^2\Delta\mathbb EX^4\)。须有 \(C\ne0\) 且涂抹应力的二阶矩存在。点上的应力平方无此资格。

**独立攻击。** 在对称节点 \(X=\pm6j,\ j=0,\ldots,5\) 上，以归一化、\(j^2\) 和四个余弦值作六行矩阵 \(M\)。其可逆性来自五个不同的余弦节点（含 1）及在 1 的一阶导数，共六个 Hermite 条件。独立求得 \(\|M^{-1}\|_\infty=49.152204\)。加质量 \(\gamma/N^2\) 于远端，补偿原权的幅度逐项至多 \(\gamma\|M^{-1}\|_\infty\)，所以可同时保持正权且使四阶矩按 \(N^2\) 增长。实算两组分布的四个特征函数值都匹配到 \(10^{-65}\)，四阶矩分别增加 \(2.497\times10^5,\,2.497\times10^9\)。若给候选共同支撑界 \(|X|\le M_*\)，则 \(\mathbb EX^4\le3M_*^2/4\)。单独第一门筛 \(X+\) 时，后验位移功率还含 \(\mathbb E[Y^2\cos(aY)]\)，两例此项分别改变 \(9.42\times10^{-5},\,2.18\times10^{-4}\)，尽管分支概率相等。这是对条件制备标签的具体反例；推算条件量子场应力另需包括仪器更新。[主审原构造](../noise.py) · [独立正权与实算](replay.py)

对原输出作条件统计，或依首门结果选第二门的分析轴、停机，只要各门最多使用一次且未开放其他场操作，共同的有限频率仍充分。按结果向场追加不同强度的门、再测应力或改变未来度规，须重算条件场态与实际访问的频率。平均应力相同的两态只有在参考绝对应力、有限曲率反项、其他源和初值已使所选度规成为解时，才共享该平均场解。前两节的平均应力不同，固定同一引力方程和其他源时，二者不能都以该标量为唯一源生成同一度规。应力方差到实测几何噪声还需要传播、器件响应及其他噪声的证书。
