# 精确平均闭合后的反思：剩余快幅度与源—几何责任

## 1. 现在能证明真正的非唯一性

前轮仅有线性快核，不能据此断言非线性精确解不唯一。[本轮存在定理](EXISTENCE.md) 已构造归一化 U(z,w)=z+w+O((z,w)²)。固定同一原 M2、U0、A、incoming Q/P、eta_ref、完整 S0 谱、热占据及一个非零慢幅 epsilon，改变足够小的快幅 delta，现在得到实际存在的不同精确 mean-SCE 历史。

设两快幅为 delta1、delta2，沿同一共形时标，

\[
u_2(\eta)-u_1(\eta)
=(\delta_2-\delta_1)e^{\sigma_F\eta}
[1+O(e^{s_*\eta})],\qquad\eta\to-\infty.
\]

因为 sigma_F>2s_*，两条历史共享静态过去、同一慢线性幅度和同一慢二次系数 beta≈−1/3。更强地，冻结比值 q=sigma_F/s_*∈(468087.119,468087.342)，故对 N=468087，

\[
u_2-u_1=o(e^{Ns_*\eta}).
\]

它们共享慢过去的前 N 个整数增长阶。这里是过去指数渐近的阶数，不是某一有限初片的时间 Taylor jets 相同；后者通常不同，必须同步运输态。

这证明**当前给定的 incoming 制备和慢过去渐近不足以唯一选择精确历史**，而不是仅“唯一性尚未证明”。结论限于本轮构造族，没有穷尽所有 smooth／Hadamard 历史。

## 2. 不能把剩余幅度解释成坐标伪影

闭 FLRW 的标量曲率为

\[
R=\frac6{x}e^{-2u}(1+\Theta^2u+h^2).
\]

在静态背景上，频率 lambda 的一次曲率变化为

\[
\delta R=\frac6x(\lambda^2-2)\delta u.
\]

快根处系数非零。[selection.json](selection.json) 包围实际快曲率切向。

共形时间平移 c 使 epsilon→epsilon e^(s_*c)、delta→delta e^(sigma_F c)。当 epsilon>0，

\[
I=\delta/\epsilon^{\sigma_F/s_*}
\]

在时间平移下不变。固定非零 epsilon 后，改变 delta 不能由同一纯时移消去。原 eta_ref 和完整 Q/P incoming 规范也保持，不允许悄悄平移规范数据。

这只说明本构造中的剩余参数需要真实选择责任，不宣称已建立两个独立实验可观测量、仪器或完整 gauge 分类。

## 3. 一条方便数学支仍然是额外选择

令 delta=0 得到纯慢解析支，它仍是一条合法的精确 mean-SCE 历史。但“单变量解析”“未来不增长”“阶数约简”“选择某个 delta”都不是原 Hadamard 条件或 incoming 量子态自动推出的条件。

后续任何选解须回答：它来自何种物理制备、边界条件或动力学？作用于 old/new 的规则是否共同且协变？代价与额外输入是什么？本轮保留全部实际方程，没有采纳删除快模的额外定律。

## 4. 继续检验：随机化两增长幅度不能承接完整源谱

精确平均历史成立后，直接测试最接近的涨落补法：保持同一 A、U0、高模 incoming 制备，只让 epsilon、delta 依赖实际零模能量样本，以希望吸收完整 S0 的非零方差。

这一方案失败于过去常数约束。若样本改变零模源量 delta_M=delta(M2 S0)，任意上述增长幅度都在过去趋零，所有这些几何仍趋同一静态 A。额外源密度及压力均为 delta_M/(2a^6)，故在过去

\[
\Delta E=-\frac{\delta_M}{3A^4},\qquad
\Delta C=A^2\Delta E=-\frac{\delta_M}{3A^2},
\qquad
\Delta S=\frac{\delta_M}{2A^4}.
\]

除 delta_M=0 外，增长幅度不能消去这些常数。原 unfiltered S0 方差严格正，约 0.1875000000156；简单随机化该 mean-history 族并不能成为承接完整源谱的约束解族。

这是对明确“经典样本源 + 同一静态过去 + 仅改变两个衰退过去幅度”方案的排除。不把量子谱自动当作某个已建立的经典随机引力法则，也不据此否定所有联合量子几何模型。改变 A／高模条件态／物质内容／过去准备需要新的联合约束构造，不能在本定理中免费加入。

本结论承接冻结的常数源障碍，现在明确覆盖刚构造的整个精确非线性族；无需重复旧科学执行。

## 5. 闭环后继续推进的实际验收顺序

当前首要缺口已从“是否有真解”移到**哪一个共同物理历史，以及如何承接完整总源**：

1. 指定可独立辩护的物理选解／制备机制，给同一规范下的几何自由度及初态数据；仅数学方便选 delta=0 不算完成物理选解。
2. 在一个明确的涨落引力模型中，建立承接原完整源谱、正负能量偏差的状态—几何联合约束初值及传播。刚被排除的固定 A、仅随机增长幅度方案不再作为默认路线。
3. 把高模、正规零模、实际控制器、probe／clock 的总应力和交叉噪声全部纳入，再给所有成功／失败／停止 CP 记录、校准和误差。
4. 检验原制备降噪是否在相同资源与共同选择规则下产生可辨认的引力记录。相同完整联合 O(2) twirl 与共同协变选择／仪器仍给全部记录同律；人为给 old/new 不同 delta 是改变几何输入。
5. 以减少独立物理输入或得到同资源可检验分离承担统一责任。当前模型的场内容、U0、态和仪器合同仍是独立物理输入，未从只读 Core 推出。

本轮完成了平均历史和误差闭环，并继续关闭两个紧接的判断：现有条件确实不唯一选解；单纯随机化增长幅度确实不足以承接非退化源谱。完整涨落、真实仪器与物理统一仍开放，下一任务不能再退回增加慢 Taylor 阶数来代替这些责任。
