## 二、反相关补偿究竟能做多少

对正源能 A 和正装置能 B，固定完整源边缘态 rho 及总均值 E。
选 C 使 E=<max(A,C)>，令 b=(C-A)+、h=(A-C)+，则
\[
 {\rm Var}(A+B)-{\rm Var}[\max(A,C)]
 =\langle(B-b)^2\rangle+2\langle hB\rangle\ge0.
\]
在允许设计装置谱的条件下，正规态精确达到该谱下界当且仅当
[rho,b]=0。非对易时还有
\[
 {\rm Var}(A+B)\ge {\rm Var}[\max(A,C)]
                    +\tfrac14\|[\rho,b]\|_1^2.
\]
热壳中可以保留同能量 NOON 相干并实现有限级补偿；完整非平稳源态
不能只按经典能量分布选择补偿。无界源尾在有限平均资源下也不能完全消失。

## 五、继续一轮验收：引力载体建立后被有限应力条件拒收

另行声明 leading GR、两齐次零模、正尘埃、x=a^(3/2) 的平坦排序，

\[
 H_P={3\over8V_0}\partial_x^2+V_0U_0x^2
       -{3V_0\over2}x^{2/3}+{|P|^2\over2x^2}.
\]
零端点自伴边界、无穷端点、可测直积分及 H<=0 的正尘埃物理子空间
均有明确构造。这是一项新的约化模型，不是原 AE/NOON 模型。

随后继续检验正物质能 K0=|P|²/(2x²)。完整证明表明：

> 在该固定模型和分离自伴定义域内，若正规物理态满足
> Tr(rho H²)<∞，且 K0 的期望在一个开放时间窗内始终有限，
> 它必须完全支撑在 |P|²<3/(16V0)。

证明结合逆平方端点展开、标量谱表示、单侧谱的解析唯一性及
正常混态直积分。原高斯混合落在这个小盘内的概率最多
3/(32V0v)<2.85e-12，故任何通过验收的源边缘与原态的迹距离
都大于 1-2.85e-12。保持 P 谱律的应力等价族也受同一排除。

自伴性与数学幺正演化结论保留；被拒收的是把该模型用作原源态的
有限正应力共同历史。不把排除外推到所有量子化、时钟或量子引力。
有限总 H² 允许带符号奇异项相消，不能替代正物质能的形式有限。
