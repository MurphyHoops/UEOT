# 新增输入与下一项物理验收

## 已有事实与本轮新增假设

| 分支 | 保持的输入／已证明内容 | 新增条件与限制 |
|---|---|---|
| 静态相关态 | 原 M2、U0、AE、两场及输入 S0 谱；允许纠缠 | 逐记录静态、平稳高模和旧总能阈值仍必需 |

| 有限正能时钟 | 全源尾、条件初态和短窗迹距离界 | 光滑封顶新生成元；有限时钟成本；未给完整 KG/RSET |

已知 QFI 最小总能方差、关系物理内积、尘埃去参数化和
Sturm--Liouville 扩张理论明确引用一手文献；不登记为 UEOT 原创推导，
也不把这些独立量子化假设称为 Core 的结果。本轮新结合的推论及
项目特定数值由相应证明和证书给出。

## 本轮拒收的具体路线

固定半线平坦排序、可测逐 P 分离自伴扩张和正尘埃分支时：
有限 Tr(rho H²) 加开放时间窗有限正物质能，迫使 P 支持临界小盘。
原动量分布在此盘的概率不到 2.85e-12；改变 theta 或 ell
不会消去这个超临界纤维排除。

因此以下操作不能作为完成：
增加非零场壳后直接沿用此域；把有限总 H² 当有限物质能；
把应力等价源族或正能时钟码无证明地粘到该物理空间；
只验证另一形式 Hamiltonian 自伴便宣称获得有限应力历史。

## 下一轮可执行的第一任务

为一个具有独立物理理由的候选几何约束写出完整输入清单，至少包括：

1. 从同一作用量或有效理论得到约束、时钟总源及半经典 AE 极限；
   若改变排序、逆体积或端点结构，给出理由及受控恢复极限。
2. 给出物理 Hilbert 内积、自伴演化域、正物质能形式域，
   明确有限总二阶矩与正源矩的交集。
3. 证明该交集能承载保持原 P 律或明确替代源合同的正常态，
   并在一个非零时间窗保持有限正应力；给出真实初片法向导数与方程残差。
4. 通过后才扩展实际非零场、处理非齐次约束、控制器及载体；
   用同一联合态传播完整源—几何交叉项和局域仪器记录。
5. 校准判别能力时分别报告制备成本、背景变化、量子涨落与
   仪器误差；原 prescribed-history 幅度差不直接等于测量灵敏度。

选择候选的依据是能否减少并检验独立物理输入，而不是是否容易
写出一个额外自由参数或通过有限维计算。当前没有自动批准某个
硬墙、任意反弹函数或新的时钟种类作为正确物理。

## 与统一目标的关系

本轮排除了两个可量化的偷渡：把源能反相关等同完整态补偿，
以及把自伴总演化等同有限正物质应力。新应力等价族则保留了
比固定裸态更宽的合法候选空间。下一步必须在这个更准确的空间中
建立同一物理历史，随后才可能得到可辨认、可校准的引力后果。

整体统一仍需解释独立的量子态／测量规则、完整引力动态、
已知理论极限及经验预测。当前未证明这些全部由 Core 推出。
