## New second-moment argument

For strongly commuting positive A and B,
\((A+B)^2-A^2=2AB+B^2\ge0\).
Apply this to A=Es S0. If a second moment is infinite the inequalities hold
in the extended nonnegative reals. Therefore
\[
 {\rm Var}H_i\ge E_{s,i}^2
       \max\{\langle S_0^2\rangle_i-\tau_i^2,0\}.
\]
The positive part must be taken BEFORE replacing the radius coefficient;
otherwise a negative conditional lower bound could reverse that step.

Using \(\langle\rho_i\rangle=3/(2x_i)\), \(V_i=2\pi^2A_i^3\),
\[
 { {\rm Var}(H_i/V_i)\over\langle\rho_i\rangle^2}
 \ge{M_2^2\over9x_0^4}
       \max\{\langle S_0^2\rangle_i-\mu_{\rm old}^2,0\}.
\]
All records retain the input S0 spectral law. Convexity of the positive part
then gives
\[
 {\cal R}^2:=\mathbb E_i
 { {\rm Var}(H_i/V_i)\over\langle\rho_i\rangle^2}
 \ge {M_2^2\over9x_0^4}
       [\mathbb E_{\rm in}S_0^2-\mu_{\rm old}^2]_+ .
\]
This is not a separate >10% statement for every individual record.

For the actual input,
\[
 \mu_{\rm prep}=L+1/\nu_0,\qquad
 v_{\rm prep}=3/16+2L/\nu_0+1/\nu_0^2,
 \qquad L=1+\sqrt3/4 .
\]
There is an exact cancellation:
\[
 v_{\rm prep}+\mu_{\rm prep}^2-\mu_{\rm old}^2
                    =3/16-2/\nu_0^2 .
\]
The accepted root relation has \(M_2/x_0^2>1/L\), so
\[
 \boxed{{\cal R}>
 { \sqrt{3/16-2/\nu_0^2}\over3L}>0.10.}
\]
The saved interval is approximately 0.10072315975. A separate rational proof
uses \(\nu_0>1000\), \(L<287/200\), and
\(\sqrt{3/16-2/\nu_0^2}>433/1000\); the resulting lower bound
\(433/4305\) already exceeds 0.10.

## Consequence and limits

The formerly unexcluded 7%–10% improvement interval is now excluded within
this same correlated static contract. Correlations need not be absent.
We do not assert the bound is sharp or reachable, nor that the former
specific product-state numerical lower endpoint applies unchanged.

This is an integrated source/strong-constraint residual bound. It is not
a measured metric fluctuation or detector sensitivity and does not disprove
the exact deterministic mean-SCE history. Nonstatic states, nonstationary
high-mode marginals, new matter interactions, changed source law or a
different physical constraint require new analysis.
