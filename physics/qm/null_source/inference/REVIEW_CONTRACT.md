# 双轴点探针和弱透镜的复核划分

原短窗留出保留，单独审查点探针资格。额外独立合成采用实际宽窗 χ(t)=(1−t²)³，|t|<1，2g 的标称值 1，外部标尺限制为 [0.998,1.002]。中心世界线 u=τ，由之前两次同步测量把控制器 t 映到同一个仿射 u。演示真源 ξ=0，W=0（有界自由 Weyl 的一个成员），κ=1；几何允许整个原任意 W 界。实际探针准备 +X，在各自独立重复上各读 X 或 Y，以 atan2 消去同一态、同一门的未知正可见度。每个训练命令 ±1/4 共 131072 个开始，每轴一半；新命令 −3/8 留出 65536 个开始，每轴一半，几何 8192 次。标尺、时钟的公用证据和原测量规模相同。轴间转移的每个概率误差至多 0.001，绝对轴方向及相位零点独立定标。新种子 33469811、33469812；评分不得改旧窗口、阈值、数据及判定，训练不使用留出。12 个同时双侧 Hoeffding 界包括杆、两个钟、四个训练概率、两个留出概率和几何。相位支固定 |θ|<π/2，若 X 象限不可判、源标定箱为空，停止物理解释。

弱透镜复核采用主审发布的前两个权 w₀,w₂ 与未拟合 w₄。对独立计算的连续轨道用直接 K det J 加权积分核对弱式，检验共同空间矩阵增益及速度/位置相对增益被错用的影响。两种算例都是公开设计；量子噪声参考态、已校准的轴、开关面积和仿射时钟是实验前提。
