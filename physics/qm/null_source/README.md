## 独立量子选择的新增裁决

上轮 E1 网络允许两处用经典变量协调制备，并限制共享量子参考。一个物理上的充分条件是复位后两端包括辅助参考在内的完整系统各有已知、非简并的基态和能隙 Δᵢ，且后续制备在两端局域进行。若测得的平均超基态能上界为 eᵢ，落在乘积基态外的联合概率最多为 Σ eᵢ/Δᵢ；与最近的基态乘积、含外部参考的记录模型，半迹距离至多为该和的平方根。共同经典随机数可逐条件处理后取平均。用上轮记录的排除半径 10⁻⁷ 作数值检查，两个 eᵢ/Δᵢ 各为 8×10⁻¹⁶ 给复位半径 4×10⁻⁸，再加其他记录误差 5×10⁻⁸ 即可进入门槛。这是要求的精度；尚无设备读数达到它。

反例在每个装置的零能空间保留一个实二态参考，两端关联但各自的平均能量均为零。实际复算中它以总分 8.485248356179 重现 288 个指定概率格，最大差小于 7×10⁻¹⁷。因此局部低能测量本身不能保证 E1；独立识别能量简并、端口完整性和制备期间的隔离，会真正改变理论筛选的结论。[能量复位判据与失效例](probe/reset_selection.py) · [操作假设和推导](probe/PROBE.md)

主审又比较了两个实验上不同的复位程序。若能在选择测量设置**之前**，对每端全部可访问载体做「唯一基态／补空间」的局域 Lüders 测量并把两旗写入完整记录，成功块已是乘积；其余块的总质量记作 p。把旗不可逆地写为设置无关的经典记录，以共享经典变量复制联合旗分布，在坏块也用独立源替换，则含旗全部记录的总变差至多 p。未经旗测的相干复位只给平方根界。双三能级例的坏块保留一对纠缠激发；任意实可分、带经典旗的复位态在坏旗上的 Bell 见证给半迹距离下界 p/2。这是**复位态的界**，能否读出该见证取决于另外的操作权限。

## 主审增加的两轨迹反演

取平行正交横向标架，J 的两列为独立试束初始分离的演化，V 为按同一仿射时间测得的速度。记 z=det J，d=det V。当 J''=−(KI+W)J、tr W=0，按列两次微分行列式给 **z''=−2Kz+2d**。这对时变剪切成立，甚至允许 z=0；反演所需的是两个积分方程线性无关。单列的位置/速度不能给这条恒等式所需的记录。已校准的共同定常线性屏幕变换给 z,d 同乘一个非零常数，消于比值；速度增益、转动标架、时钟漂移须另行处理。

令 F=f²，h=4πGA²，b=hξ，作用量给 (1−2bF)K=h(f′)²−bF″，工作域要求分母远离零。对边界 w=w′=0 的权，直接积分或按分部公式可算

    L = ∫ [−w″z/2 + wd]                         M = ∫ wz(f′)²
    B = ∫ { [−(wF)″−wF″] z + 2wFd }           L = hM + bB .

只用 w₀ 和 w₂ 定参；未拟合的 w₄ 检验方程形状，再用 A=3/8 的新轨迹检验幅度转移。冻结的非最小合成真源为 A=1/4、ξ=1/6，包含非对角自由剪切。两个校准矩的行列式落在 [−0.063251, −0.063139]；反演给 h∈[0.05452,0.07067]、ξ∈[0.13602,0.20560]。零耦合对照包含 ξ=0。对新振幅叠加各向同性曲率 0.045(1+u/2)，第一个留出残差下界为 0.016099，足以拒绝该冻结转移。相同形状、随振幅同比变化的隐蔽物质仍可能通过；给 h 赋绝对牛顿常数还需要独立的场幅标尺。此组真值与宽窗实验不同，两组结果并列演示不同真值下的识别能力。[主审复算](weak_lens.py) · [向外区间](lens_result.json)

每条轨迹 2049 个等距节点；读出合同对 z,d 各给 10⁻⁸ 绝对误差（含量化）。每个节点的权重误差小于 10⁻¹⁰，复化梯形误差不超过区间长乘步长平方乘二阶导上界除以 12。程序对具体模型用区间算术先核对 ∥KI+W∥<2 和其导数范数 <5，再用每小段常正系数比较方程界住 ∥J∥,∥V∥<2。按列求导得 |z|,|d|≤4，|z′|≤8，|z″|≤24，|d′|≤16，|d″|≤96。两次 DOP853 积分检查合成读数收敛；传感器半径是外部读数条件。几何组另有针对其各向同性传递矩阵的区间演化。有限数据的覆盖需要实际校验采样间正则性与仪器误差；形式恒等式本身允许任意光滑自由剪切。

## 有限孔径的同源性障碍与对照

上述平面波在横向无界。直接把同一标量脉冲剪成有限光斑会改变应力和场方程。对 ds²=−2du dv+dx²+dy²−Hdu²，冻结最小正动能的实标量与 ∂ᵥφ=0，由应力定义得 Tᵤᵥ=|∇⊥φ|²/2，波算符为 Δ⊥φ。因此精确纯 uu 应力要求标量横向常值；非零的无限平面脉冲具有无限横向总通量。a、b 为光斑内外半径，若在两圆边界分别取 Af(u) 和零，沿每条半径用 Cauchy–Schwarz，再绕圆积分，得到

    ∫环带 Tᵤᵥ d²x ≥ π A² f(u)² / log(b/a) .

界对有角向变化的剖面仍成立。环带上的对数函数在给定边值的能量空间取到该界，平滑接常数时可逼近。它是给定坐标、动量方向与物质作用量下的应力分量界；从它推出仪器可分辨的曲率差还需演化和读出权限。

对照可选平行零尘 Tᵤᵤ=ρ(u)η(r)，其余分量为零，沿 ∂ᵥ 输运即守恒。圆对称 Einstein 方程给 Δ⊥H=16πGρη。以 η 在 r<a 为一、在 r>b 为零，取正则中心；那么 H′=16πGρ∫₀ʳsη(s)ds/r。在内圈精确恢复最小标量基准 K=4πGρ，外圈 H 为对数型。对照的横向通量有限，内圈轨迹与平面源完全相同；相位敏感的标量探针需要独立的标量耦合才有辨识力。该建设没有给孤立渐近平直系统的 ADM 质量。标准平行束几何已有解析研究。[符号复算](aperture.py) · [Bonnor 原文](https://projecteuclid.org/journals/communications-in-mathematical-physics/volume-13/issue-3/The-gravitational-field-of-light/cmp/1103841572.pdf)
