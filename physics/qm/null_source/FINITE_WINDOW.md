# 有限总质量的同源脉冲：从两个相位窗预报引力聚焦

在上一例的非均匀球心，已知的时间导数只约束初片。这里保留正动能无质量实标量、球对称、Einstein 方程及渐近平直外区，只调整可控的初始制备，让中间有限球内的演化有闭式解。一次测量固定初始尺度与标量单位，在相同制备的独立重复上比较带符号的量子探针、试验球半径和中心雷达钟。以下为模型计算，传感器精度是合同输入。

## 初片与因果边界

在初片令外曲率 Kᵢⱼ=0，φ=0，以球面面积 4πR² 定义 R，以 Π 表示标量的单位法向导数。选 4πG=1，R≤1 取 Π=±1，1<R<3/2 取 Π=±[1−10x³+15x⁴−6x⁵]、x=2(R−1)，更远处为零。函数及其两阶导数在接缝处连续。动量约束自动满足。写 μ=Gm，Hamiltonian 约束与度规给

    μ′(R) = R²Π²/2,     γ = dR²/(1−2μ/R) + R² dΩ²,     μ(0)=0.

中心为正则原点，外区为标准渐近平直真空初片。精确积分给 GM_ADM=7565/26208。因 |Π|≤1，在支撑内 2μ/R≤R²/3≤3/4，支撑外此比值继续降低。这排除了初片上的球形边缘陷获面；后续大尺度塌缩仍是另外的问题。

在齐性内球写 R=a₀sinχ，a₀=√3。初值恰是正空间曲率 Friedmann 模型的最大膨胀切片。Einstein–标量 Cauchy 演化的局部唯一性与有限传播使这份解在内球的因果发展域中成立。以初片为 η=τ=0，正向收缩，dτ=a dη，取相同实时时钟。则有

    a(η)=a₀√cos(2η),    dφ/dτ=±(a₀/a)³,
    φ(η)=±(a₀/2) log[(1+sin(2η))/cos(2η)].

窗口在 χ+|η|<arcsin(1/√3) 且 |η|<π/4 以内。选反射球 χ=1/8，中心在 η=0 发射试探光，η=1/8 反射，η=1/4 收回。整条光路、球壳和两个场读数窗均在该域中。无需假定无限宇宙也齐性。雷达测得的**完整往返固有时**为 [0.42390510, 0.42395859]；在 η=1/4 由同步共动球面的面积得到的**末/初面积半径比**为 [0.93679375, 0.93679378]。反射发生在 η=1/8，此时半径比为 0.984333491。为取得末时半径比，壳上的同步仪器在 η=1/4 另行记录面积，向内发送可在中心 η=3/8 收齐，仍处于因果域。空间测量的有限尺寸在此齐性内区可精确计算。

## 两个场窗口如何给出独立的几何预测

在 η∈[1/32,1/16] 和 [5/32,3/16] 上分别测量归一、非负的时间加权场均值。在每个窗令 x 从零线性增到一，权为 30x²(1−x)²dx；由上面的名义钟映射预先编制固有时间开关，换候选时沿用相同实验室程序。紧支的空间涂抹按各切片固有体积归一且完全在内核，故对齐性经典均值无尺寸修正。正制备的两个模型均值分别在 [0.08047,0.08217]、[0.30075,0.30680] 内，负制备则翻号。数字由分段包含积分向外取整取得。[符号方程与区间回放](finite_window.py) · [数值回执](finite_window_result.json)

量子操作可用同背景、同一中心参考态的相反 Weyl 位移。取 z=⟨X⟩+i⟨Y⟩，对相反制备有 arg(z₊ z₋*)/2=2g∫χφ dτ（模 π）。这依赖各窗共同的中心 Weyl 特征函数、非零可见度、相位定向、访问两个轴及对加性读出偏置的校正。自由场的传播可以有尾；交换子为 c 数，时间序产生的共同相位在此消去。未知非高斯态仅有同样的协方差不能保证所需特征函数相同。该关系用于提取带符号的试探场均值，支持有限空间涂抹；完整量子概率还依赖状态和噪声。把理想试探态本身作为绝对引力源还需求重整化参考应力、涨落以及开关反作用。无需求取整片闭宇宙的共形真空来报告此相对相位。[双反转与失效例](probe/PROBE.md)

在更一般的球对称光滑中心，取初始共动、无涡的测地试束，J 为长度比。球心各向同性、Einstein–最小无质量标量给 J″=−cφ̇²J，c=8πG/3；J(0)=1，J′(0)=0。在 0≤t≤T 的整窗未过焦点时，J(t)≥J(T)>0。两次积分后，在互不重叠的早期格 [aⱼ,bⱼ]，bⱼ<T，用加权 Cauchy–Schwarz 得到

    1/J(T) − 1 ≥ c Σⱼ (φ(bⱼ)−φ(aⱼ))² / log[(T−aⱼ)/(T−bⱼ)].

只用两个非负归一化的场窗时，连续场在每窗某一时刻取到各自均值。用两窗最早开始、最晚结束以及仪表误差给对数分母的上界，用两个均值区间的最短距离给分子的下界。这样可以直接检验有限窗，不需要测量加速度或假设三阶、四阶时间导数的上界。相比上一球例的中心导数外推，这一步消去了一项实验前提。一般非齐性系统仍需审计有限试束到中心线的转换，在本例中 J 正好等于有限球的面积半径比。

每个场窗给 0.001 的独立绝对读出容差，各钟端点给 0.0001，半径比给 0.001。在这些同时成立的条件下，用上面的场均值预报 **J(T)≤0.97616201**。同源的几何留出约为 **0.936794**，相容；取相同场记录和同样容差、末/初比为一的平直几何对照会被拒绝。只要测得的 J(T) 下界超过预报上界，即表现为给定场变化下聚焦过弱。这一单侧检验不排除额外吸引性物质。独立的标量能标和 G 仍须限定，否则数据只能约束其组合。原始点探针噪声不能直接套用这两个场窗的 0.001；实测要由两轴统计和仪器转移证明该容差。

## 由什么资料才能进一步筛选物质

在齐性内区梯度类时，无旋刚性流体 p=ρ 与最小实标量可给同一个 T、几何和雷达读数。例如换成两支规范化实标量 (φ₁,φ₂)=(3φ/5,4φ/5)，总应力逐点相同。若仪器耦合 (3φ₁+4φ₂)/5，即连整段带符号的读数也完全相同；想识别另一分量，要能独立激发或读取正交方向。若参考源已确认只读 φ₁，并独立测得总密度，用 2ρ−φ̇₁² 区分两候选，单场给零，指定混合给 16φ̇²/25。该判别适用于齐性、正动能、无势场。把流体的速度势也作为可耦合的被测场时，相应物质统计可以继续相同。该等价在类时梯度的局部域内有原始文献讨论。[Brady 等的局部对应](https://arxiv.org/abs/gr-qc/0207096)

下一次实验性验收需要在同一合同内取得双符号、双轴、全启动的场记录和独立的几何记录；若只能实现模拟器，则检验相应的有效传递。理论上先量化偏离球对称的潮汐、窗口误差及半经典应力。把标准 Einstein 方程、正动能作用量和复量子探针的选择从独立前提移入 Core 推论，仍是单独的基础责任。

四组对本例分别复核了渐近质量与末时记录的因果回传、任意中心参考态下的 Weyl 相位关系、有限窗单侧误差，以及双标量与刚性流体的等价域。独立数值积分给两个正源均值 0.081314780、0.303761406，往返时延 0.423931861，均落入上述向外区间。
