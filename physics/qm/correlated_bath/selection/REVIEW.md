## Normalized Choi conventions and interpolation

Both serializers use |Bell⟩=(|00⟩+|11⟩)/√2. Each 4×4 block has indices (output S, input reference). Write Jᵣ=(Φᵣ⊗id)(|Bell⟩⟨Bell|). Complete trace preservation is ΣᵣTr_out Jᵣ=I/2. For a general complex SR input the contraction is

    output_r[a,k,b,l] = 2 Σ_i,j J_r[a,i,b,j] input[i,k,j,l].

The usual transpose in the Choi trace formula is already expressed by these indices.
