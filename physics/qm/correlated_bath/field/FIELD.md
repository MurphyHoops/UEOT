# 同一个干预相位怎样进入局域场论

## 固定物理源与可比较的输出

取时空为超静态圆柱 ℝ×S¹，光速、场质量和 ℏ 取 1，空间周长 L=4π/√5。自由实 Klein–Gordon 场采用正能 Fock 表示。模式 k_j=2πj/L，ω_j=√(1+k_j²)。这些几何与量子假设均为 P。实验 A 在第一段 [0,a] 以给定 s=±1 的 Z 本征态局域耦合；实验 B 的探针独立制备为 +X，在第二段 [a,a+b] 局域 Z 耦合。两次操作保留同一场。读出 B 的 X 和 Y，或其相干项 2ρ₊₋。同地校准时这等价于保留环境的因果断开。类空实验使用两台局域探针，B 的初态与协议均独立于 A 选的 s。

偶空间剖面由四个半宽 L/160 的归一化盒函数卷积成 h，再取 f=(1−p)h+(p/2)[h(x−L/6)+h(x+L/6)]。支撑半径 R=L/6+L/40。归一化 Fourier 系数为

    f_j = sinc(πj/80)^4 [1−p+p cos(πj/3)].
    p = 2[1−(3/5)√(3/4) / sinc(π/80)^4].

0<p<1，所以 f≥0。令局域源厚度、时钟与耦合强度都进入物理合同。f 为紧支撑 C²；有限时间的矩形开关与空间导数并未用于点场乘积。严格局域代数可用支撑在原区域任意小外邻域内的光滑卷积近似：各测试函数的正频一粒子范数收敛（质量正，空间 Fourier 系数平方可和，时间积分有共同上界）；相应 Weyl 算符强收敛。有正类空间隔时邻域仍类空。所用全局真空是静态 Hadamard 态，把零模与第一余弦模换成中心、无反常矩、占据矩阵 [[n,c],[c,n]] 的 Gaussian 态，使二点函数仅相差有限个光滑模的线性组合，保留其局域奇性。

吸收共同的场归一化使零模 g₀=1。j≥1 的偶模 g_j=√(2/ω_j)f_j，奇模在原点解耦。B 置于原点或对径点时，B 相对 A 逐壳多一个 ε_j=1 或 (−1)^j；这两处也都没有奇模耦合。按上述剖面精确有 ω₁=3/2，g₁=3/5。保留零模和第一余弦模，得到第70章的两个频率、相对耦合和本轮所选低模浴态。模式匹配来自外加的圆周长与仪器剖面，其物理意义是可比较的实验实现。

## 从同一耦合导出的两个量

相干项 z_s=2ρ₊₋=exp(−Q+i s Φ)。若采用通常 Pauli Y，其期望为 −Im z_s。写 d_j=ε_j g_j[exp(iω_j a)−exp(iω_j(a+b))]/ω_j。第一段在场中留下的位移经第二段 Weyl 乘法给相位，中心协方差给衰减：

    Φ = 4λ² Σ ε_j g_j² [sin(ω_j a)+sin(ω_j b)−sin(ω_j(a+b))]/ω_j²,
    Q = 2λ² Σ |d_j|² + 4λ² n (|d₀|²+|d₁|²) + 8λ² c Re(d₀* d₁).

Φ 也是两个实际源的时序推迟对易响应的双积分。Q 是第二段两条自旋历史差在对称二点函数下的二次型。交换相位与噪声振幅由不同输入决定。类空支撑时 Pauli–Jordan 分布支撑于光锥内，严格给 Φ=0。等价地，可交换的两个局域耦合意味着 A 的任意迹保持非选择局域操作对 B 的边缘无影响（对局域 Kraus 的伴随映射用完备性），此处 A 的两种源选择是一个特例。对 A 结果的后选择及随后传播的经典消息另算。

对 M≥1，令 κ=√5/2。由 |f_j|≤(80/(πj))⁴ 和 ω_j≥κj，

    H_M = Σ(j>M) g_j²/ω_j² ≤ 2(80/π)^8/(10κ³ M^10),
    |Φ−Φ_M| ≤ 12 λ² H_M,       0 ≤ Q−Q_M ≤ 8 λ² H_M.

同一公式在全部 λ∈[.2,.4] 上取 λ=.4 即得统一尾界。原两模在真空以外的低模均已保留，高模是真空且初态与低模无相关。若改变初态，本尾界对 Q 需补高模协方差及交叉矩。正性与微因果的结论范围也不同：有限个振子给合法量子动力学，却破坏严格局域性。

## 实际计算与尺度连接

运行 probe.py（Python + mpmath.iv）。observed.json 对每个值保存带符号的二进端点，mid_approx 仅作显示。实例 λ=.3、n=.5、c=.25、理想读出。M=160 的 Φ 尾界小于 2.486×10⁻¹² rad。第一次 M=96 的更严精度断言未通过，其相位尾界为 4.11×10⁻¹⁰；提升截断后通过，未更改目标。观测结果：

| 设置 | 两模 Φ | 场 Φ | Im z（s=+） |
|---|---:|---:|---:|
| 同地 a=2/3、b=3/4 | 0.163731618 | 0.209161320 | 0.145988513 |
| 对径 a=b=1/5 | 0.001330794 | 解析为 0，区间包含 0 | 解析为 0 |

同地例包含类时因果接触，整个涂抹区域之间并非逐点类时。对径例有 L/2−2R>2/5，全部 A、B 支撑严格类空。前两模精确匹配的参数仍会漏掉同地相位约 0.04543 rad，并在第二例留下伪信号。两模没有恢复场的微因果抵消。上面的统一余项给出了包括更多模时的定量修正。这里没有移除时空圈长或改变质量带隙。

## 功与反馈的有限合同

两个开关段的场裸能量在实验前后均由同一个自由 Hamiltonian 测量。第一段是固定符号位移；第二段的 +X 探针有等权的正负力，平均时相干干涉不进入场能期望。初态各模均值为零。两段的平均场能增长为

    ΔE = 2λ² Σ g_j²[2−cos(ω_j a)−cos(ω_j b)]/ω_j.

由同一衰减得其正尾 ≤16λ²(80/π)^8/(9κ²M⁹)。实验源在首末均关闭，探针裸 Hamiltonian 为零，这个模型的净能量来自外控开关功。按相同输入，两个例子的 ΔE 分别约 0.296126、0.071709；空锥外无信号也不要求局域源做功为零。实际读出、相位基准和记录复位成本需要独立装置条件。该场例未宣称无限系统热化或由 Core 选出圆柱、场、质量或 Lorentz 签名。

局域测量的原始理论基线见 Fewster 与 Verch，https://arxiv.org/abs/1810.06512 。本文中的剖面、匹配和截模计算由本研究给出。
