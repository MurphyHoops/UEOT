## 核心追求与实际基线

核心目标是从 UEOT 建立完备、可解释、严格且可否证的 QM 物理理论。推进顺序同时由科学重要性和已经具备的数学条件决定：有限内核扩展应形成可复用证明，根本的量子选择与现实模型检验应有独立任务，不能用增加标准量子定理的数量替代这两类责任。

本轮基于已验收主线 97d033ff83125822e9926f5bd36afd08dbd153ef，实际完成三条并行任务，形成 Kernel 1.5；[执行合同](UEOT_QM_EXECUTION_v31.5.md) 记录原始材料、输入、分工、正负见证和验收顺序。[正式总著 3.1](book/UEOT_PHYSICS.md) 含 54 章、6 附录、101 编号结果和 [171 页 PDF](book/UEOT_PHYSICS.pdf)，继续作为唯一连续理论著作维护。

## 有限资源的高效使用

本环境同时可运行主智能体和三个子智能体。本轮采用三条独占证明文件并行，完成后转入互审和持久见证，主智能体集中公共导出、运行、总著与集成。仅在源冻结后进行一次统一全库构建；追加的具体见证单独运行且重新绑定源身份。不同职责共享固定官方工具链与依赖缓存，不重复下载和重建。

恢复期的独立源码审查已把 A1 收紧为 [QSEL-A1-CLASSICAL 执行合同](UEOT_QM_QUANTUM_SELECTION_EXECUTION_v31.6.md)。原 registeredSurvivalModel 的 4→2 商会把选定微观二点混合压成 Dirac，因此下一轮先构造同一核的完整读出模型，证明实际商上仍有混合态，再证明其在任意有限经典辅助空间中无纯扩展。此为待形式化任务，不进入本版334／392计数。

下一轮让三个子智能体围绕这一份证书分工：A负责有限经典状态空间与极点／纯化否定；B负责同一 Core 核、实际商、精确控制和真实路径边际；C独立检查前提并实现正例／删除见证。主智能体负责接口冻结、统一验收、正文及集成。A2和B1/B2进入后续队列，先消除量子选择的这一具体前提缺口，再按证据扩大研究范围。

统一验收要求：实际对象及全部前提 → 正例与前提删除见证 → focused 编译／交叉审查 → 一次统一证明和受影响运行门 → 正式正文／档案／PDF → 一个源码 PR 与必要 CI → 合入主线后验证与身份补录。旧代码未改变且证据身份完整的回归可保留原回执；新的源不能借用旧 PASS。
