# UEOT Domains — Legacy Parallel-Domain Research Tree

This tree is preserved from the early council/domain architecture.

The project has moved to a derivation-first structure:

- formal foundations → `core/` + `formalization/`
- physics/cosmos → `physics/`
- validation → `validation/`
- downstream domain uses → evaluate for `applications/`

Individual domain memos remain research provenance. They do not share equal
canonical authority with the generic Core merely because they are peer folders.
