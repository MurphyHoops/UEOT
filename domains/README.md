# UEOT Domains — Legacy Parallel-Domain Research Tree

This tree is preserved from the early council/domain architecture.

The project has moved to a derivation-first structure:

- formal foundations → `core/` + `formalization/`
- physics/cosmos → `physics/`
- validation → `validation/`
- downstream domain uses → evaluate for `applications/`

Individual domain memos remain research provenance. They do not share equal
canonical authority with the generic Core merely because they are peer folders.

The [2026-11-13 scope resolution](../council/resolutions/20261113-core-claim-scope-reconciliation.md)
governs current use of the protected terms inherited by this tree and its six
early council charters. `Active Questions`, `Accepted Claims`, `Open Tensions`
and `Next Experiments` inside preserved `STATE.md` files describe their historical
stage. They do not automatically reopen completed Core contracts, require every
model to have an Omega mechanism or unique GOD/GOA, or override the current
conditional admission rules. Read [Core current state](../core/status/CURRENT.md)
and the current constitution before starting a new domain task. The original
memos and state files remain unchanged as evidence of the early program.
