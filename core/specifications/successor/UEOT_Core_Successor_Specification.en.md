## 2. Common type discipline and application rules

### 2.1 Six object roles

This specification inherits the six-role distinction of book §34.1. Establishing one role does not automatically establish the other five.

| Role | Object and judgment | Required bridge |
|---|---|---|
| Predictive identity | A representation preserves responses for declared future protocols | Measurable factorization, observable fibers and the same future permissions |
| Formed provenance | A candidate comes from the specified formation process | Actual generating image/formation relation, seed and cover |
| Interaction distinction | Registered probes distinguish candidates | The same probe and a response difference or quantitative bound |
| Constitutive persistence | A source preserves constitutive conditions | Actual kernel, initial state and persistence/safety certificate |
| Recoverable realization | A program restores a disturbed object | Remaining information, physical intervention, interpreter and charges |
| Semantic identity | Instances are interpreted as the same object | An explicit identity relation and preservation bridge |

Bodies, predictive states, programs, actual individuals and genealogies have different types. Retention preserves an original identity; a newborn is a strict new individual. Equality of Markov states, observations, mean matrices or names alone does not prove equality of individual identity.

### 2.2 Minimum meaning of the same source

Before composing contracts, match the initial law, full transition/noise, observations and history, allowed actions and memory, actual records, object/parent identities, payment and inflow timing, clock and objective. An actual construction may prove these equalities; similarly named fields do not suffice.

Probability changes, additional observations, supply, objective changes, extra addresses or expanded history access must be explicit new source/contract premises. In particular, a transaction-funded regenerative model does not prove infinite maintenance in a zero-income source, and a receipt-only controller must not be given the current hidden state.

Representation transport must cover the claimed task. One-step responses need not preserve every finite joint future; terminal states need not preserve action histories; full-prefix identities differ from single-time marginal identities. Infinite-path events require appropriate measurability and the same actual path law.

### 2.3 Quantifiers, null sets and risk

Almost everywhere for each fixed parameter/time does not imply one full-measure event for uncountably many parameters/times. A common null set requires a countable generating family, a continuous version or an explicit uniform theorem. Default posteriors at null histories do not supply information about an actual conditional event.

The training event Good, selected candidate, deployment kernel and failure event must belong to the same actual joint law. Joint failure bounds differ from failure conditional on acceptance. Actual deployment occupancy cannot be replaced by a training average, and a transition absent from finite data need not have zero probability.

A policy for each finite horizon differs from one policy for all time. CSX-07 proves an interchange under a fixed source and finite actions. Existence of an all-times policy does not automatically give finite memory; numerical-kernel homogeneity and support homogeneity are separate.

### 2.4 Purpose, long-term objects and costs

GOD is always relative to a registered objective, admissible policies and comparison class. A GOA object must be identified as an invariant law, attracting structure, conditional survival law or another specified object. Finite net value, infinite discounted value, expected population rate, random selection shares, health and individual retention are not interchangeable.

Equality of objective values, rankings and optimizer sets are three different relations. Price is an algebraic identity for an actual population; Perron theory concerns conditional mean spectral structure. Neither alone establishes causal adaptation or normative value.

A source construction must identify which external obligations its output discharges. A Perron factory produces a certificate from primitivity; the compact spectral factory still requires actual killed-density matching; continuous-source factories retain predictable/regularity premises; resource producers retain registered supply. A record that assumes the desired conclusion does not close its source obligation.

### CSX-04 · Actual paths, safety and survival of the same finite-memory controller

<!-- contract-field: id -->

#### 1. Claim ID

`CSX-04`

<!-- contract-field: name -->

#### 2. Precise name

Actual paths, safety and survival of the same finite-memory controller

<!-- contract-field: definition -->

#### 3. Mathematical definition

A controller consists of initial memory i:Y→M, an action kernel σ:M→PMF(A), and an update U:M×A×Y→M. Output and update receive no separate clock or full past. The original source initializes X₀ from p₀, samples aₙ from σ(mₙ), samples Xₙ₊₁ from Pₙ(Xₙ,aₙ), and then sets mₙ₊₁=U(mₙ,aₙ,q(Xₙ₊₁)). The augmented state is (X,M); its coordinatewise state projection defines the actual infinite state law.

<!-- contract-field: domain -->

#### 4. Domain and object types

The finite-history PMF pushforward identity allows arbitrary types X,M,Y,A. The implemented infinite-law interface requires finite X and M with measurable singletons; original-history event masses, safety and killed-process consumers additionally use finite A and the corresponding measurable-singleton structures. Y need not be finite. A physical safe set K⊆X is declared separately. The homogeneous killed branch also explicitly requires nonempty A.

<!-- contract-field: assumptions -->

#### 5. Necessary assumptions

Every step uses the same p₀, q, controller and complete numerical sequence Pₙ; numerical time dependence is allowed. Physical safety additionally requires supp(p₀)⊆K, zero uncertified-row occupancy of this same policy at every time, and closure of K under every actual successor of a certified action at a safe state. A fixed killed matrix additionally requires one numerically homogeneous original Model; support homogeneity alone is insufficient. Augmentation retains that Model’s reward and discount, but these fields prove no survival optimality.

<!-- contract-field: quantifiers -->

#### 6. Exact quantifiers

For each fixed controller and original source, and every finite n, replaying the original actions gives exactly the augmented state–memory prefix law; every finite prefix of the infinite law is this pushforward. Under the separate physical premises, the same infinite law is safe at all natural-number times with probability one. The homogeneous branch gives the killed-mass identity for every p₀,K,n and its n→∞ survival limit, including empty K, initial failure and a zero limit.

<!-- contract-field: conclusion -->

#### 7. Conclusion

The augmented rows and complete state–memory prefix identities are constructed from the original execution; erasing memory recovers the full original state history. Actual zero occupancy and the two physical premises imply all-times safety. For a fixed numerical source, let η̃ be the unnormalized safe initial row and Q̃ the killed matrix on X×M. Actual finite survival is η̃Q̃ⁿ1, converging to all-times survival of that same state path.

<!-- contract-formula: CSX-04 -->

$$
\begin{aligned}\widetilde P_n((x,m),(z,m\prime))&=\sum_a\sigma(m,a)P_n(x,a,z)\mathbf1_{\{m\prime=U(m,a,q(z))\}},\\ (\operatorname{augmentHistory}_n)_*\mu_n&=\operatorname{Law}_{\widetilde p_0,\widetilde P}(0{:}n),\\ \Pr(X_0,\ldots,X_n\in K)&=\widetilde\eta\widetilde Q^n\mathbf1\ \longrightarrow\ \Pr(\forall n,\ X_n\in K)\quad\text{(numerically homogeneous source).}\end{aligned}
$$

<!-- contract-field: proof -->

#### 8. Proof and standard provenance

Prefix induction using a dependent PMF map/bind identity proves actual augmentation first. Ionescu–Tulcea uses the same numerical row sequence, and proved prefix identities bind the infinite law. Safety is propagated on actual supported histories and then transferred through a countable intersection. In the homogeneous case, closed-loop rows and the full infinite measure are identified with the existing augmented law before applying killed-power identities and continuity of decreasing events.
