## 1. 决定：出口 B，独立后继规范补充

保留冻结 Core v3.0 作为 106 个 P-ID 的语义与形式化计数基准，增加一个有独立版本的
**后继扩展规范**。本补充不替换原规格，不发布 Core v4.0，不新增 Lean 定理。
数学著作目前是已合并 PR #453 的双语 v4.1；这个出版版本号不是 Core 规格版本号。

这里的规格是一份可调用的数学合同：明确对象类型、必要假设、量词、输出、来源、
失败边界和消费者责任。它不承担数学书的全证明与教学叙事职责，也不承担哲学书的理由辩护。

### 为什么不是出口 A

现有数学并不缺一部自足著作。冻结 v3 已有完整的基础类型和大多数关键边界；现行数学书
已经给出后继证明与解释。但原 `core/specifications/` 只有冻结源身份，后继接口分散在
数学总论、第 32—39 章、Lean 来源模块和各次验收包。调用者需要自己重建：

1. 原 P-ID 与后继来源证明是继承、实例化、加强还是仅有主题关联；
2. 一个接口字段是合法外部前提，还是后来已由具体来源消去的证明义务；
3. 当前公开模块从哪个 import 可达，声明实际在哪一个文件定义；
4. 已接受的反例与公开收窄到底限制哪一个消费者；
5. 书面证明、精确计算和现有 Lean 端点之间的差别。

独立审计还发现数学来源表有 9 条声明链接仍指向拆分前的文件，而相关声明实际存在于其他
生产模块。它们是导航问题，未发现因此导致的证明缺失。后继映射使用真实定义文件，保留旧
登记链接的溯源字段；三部著作的修订由各自维护者消费采用清单。

### 为什么不是出口 C

没有证据表明必须重定义原 106 个 P-ID 才能表达成熟后继结果。后继工作的主要价值是增加
来源构造、加强已有限定的结论、接通消费者和给出不可混用的精确反例。复制原 0—31 章会产生
第二份需要同步维护的基础语义；仅将书的 v4.1 改称 Core v4.0 又不能履行新规格审查责任。

因此，本补充采用新的 `CSX-` 合同标识，原 `P-` 标识、SHA 和计数保持原身份。一个 CSX
合同可引用多个现有定理；它不是新增定理数量，也不是新的 FULL-GREEN 计数单位。

## 4. 哪些不是本轮新修正

原 v3 已拒绝从存在直接推出唯一目的、从路径律存在直接推出可实施控制、从访问删失直接
推出物理毁损、从平均人口推出随机比例、从逐环境二维推出共同二维、从不变律推出所有路径
收敛。它也已分开 QSD 与 Q-process，以及完整噪声 KL 与可观察状态 KL。

后继的同源反例在保留真实语义下使这些边界更具体；不能把重复陈述说成修复了原 v3 的错误。
对早期强叙事的公开收窄继续采用原
[CLAIM_STATUS](../../../formalization/ueot-core/docs/compression/theory_completion/unified_closure/core_theory_closure_v1/CLAIM_STATUS.md)，
不改写其历史。后继闭合审查中被拒绝或收窄的更强目标——有限永久严格出生谱系、
正故障和正费用且遵守登记资金合同下的零收入无限维持、无信息恢复全部程序、普遍非空 Ω——
在补充正文中保留精确反例。这不表示冻结 v3 的原条件定理错误；零费用、零故障及原文允许的
空 Ω 等边界继续保留。

## 5. 版本、权威与退出条件

- 冻结规格：Core v3.0；106/106 FULL-GREEN，106 unique，0 partial，0 pending。
- 数学内容：CLASSIFIED_CORE_CLOSED；经验支持：UNVERIFIED。
- 本补充：独立 1.0 后继参考规范候选，非 active_core 晋升；是否集成以真实 PR/main 状态为准。
- `manifest.yaml` 的 `active_core` 不改；未申请 Core v4.0 权威晋升。
- 三部著作的主文、LaTeX、PDF 及 Lean 源码不在本轮修改范围。

验收要求为：新旧来源匹配、106 项及后继声明定位、公共 import 静态可达、双语合同一致、
三路实质复查、真实自动检查和 GitHub 独立交付。没有运行新的 Lean 构建时，不得报告本轮
重新编译通过。此决定的最终审查记录见 [REVIEW.md](REVIEW.md)。
