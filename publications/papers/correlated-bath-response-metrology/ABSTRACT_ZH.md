# 中文摘要（供备案与导读）

**论文题目**：《在关联量子热库中分离涨落衰减与有向因果响应：可认证过程仪器与局域场微因果性》
（*Separating Fluctuation Attenuation from Signed Causal Response in Correlated Quantum Baths: Certified Process Instruments and Local-Field Microcausality*）

**拟投期刊**：*Physical Review A* (APS)

**核心内容**：
1. **自由 Ramsey 等价类与全局参数可识别性**：在双模关联高斯玻色热库纯退相干模型中（频率 $\omega=(1, 3/2)$、耦合 $g=(1, 3/5)$），证明所有无干预自由 Ramsey 退相干轨迹仅依赖涨落-关联组合 $(u, v) = (\lambda^2(2n+1), \lambda^2 c)$。尽管两时刻雅可比行列式非零（$\det M(3/4,3/2)=-1.162023$），裸耦合强度 $w=\lambda^2$ 仍沿一维物理纤维完全不可识别（并构造显式等价有理见证对 $P_1=(3/10, 1/2, 1/4)$ 与 $P_2=(1/3, 31/100, 81/400)$）。
2. **因果干预响应与全域逆 Lipschitz 稳定性**：在制备与读出之间插入符号可控的中间干预（$s=\pm 1$），激活交叉时间对易相因子 $\exp(iswF)$（$F(2/3, 3/4)=1.819240$），从而在全域紧致参数空间上恢复全部三参数并给出显式全域逆 Lipschitz 上界（$L_w \le 2.965319$ 至 $L_c \le 830.027702$）。
3. **有限步完备记录过程仪器、多面体校准与合成留出分离**：构建与被动贝尔参考比特对称耦合的三时段停时量子过程仪器，在 4 胞 18 顶点凸多面体上利用精确二阶泰勒余项上界完成 1,128,000 次合成抽样（720,000 校准 + 408,000 留出）的同时置信认证：在 $1\%$ 族显著性下清晰区分 $P_1$ 与 $P_2$（$71{,}816/120{,}000 = 0.598467 < 0.605581$）并拒绝误设定读出模型（`readout_challenge` $796/24{,}000$）。文中明确标注：全部数据为合成基准（真实硬件未认证），且与标准持久联合幺正演化在 $4.82 \times 10^{-13}$ 内完全一致。
4. **总粒子数 Galerkin 截断的精确有理 Duhamel 余项与完全输出钻石范数认证**：给出任意精度有理数计算的截断误差上界 $B_K$（$B_{16}=0.011678$，$B_{20}=0.002099$），结合有理 Choi 矩阵 CP/TP 修复（误差 $\le 10^{-8}$），在 $K=16$ 上实现全输出半钻石范数认证上界 $0.033892$（保守漂移 $0.035357$），严格包络 $8$ 胞与 $40$-bit 过程总变差距离。
5. **$\mathbb{R} \times S^1$ Klein–Gordon 局域场微因果性对比**：将该双模系统精确嵌入 $(1+1)$ 维大质量标量场中（$L=4\pi/\sqrt{5}$），揭示仅保留两模（$M=1$）会在严格类空对跖探测间产生虚假超光速相位（$0.001331\,\mathrm{rad}$），而对紧支 $C^2$ 探测剖面求和至 $M=160$ 则使类空残余相移降至 $-1.96 \times 10^{-17}\,\mathrm{rad}$（解析余项 $<2.49 \times 10^{-12}\,\mathrm{rad}$），恢复相对论微因果律。
