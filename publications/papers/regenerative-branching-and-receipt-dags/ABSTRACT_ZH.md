## 摘要

在预算不可补充且设备易损的条件下，运营者必须决定何时启动付费维修、发生未扣费故障后是否值得在剩余任务时间内继续重试、调度哪一台设备以及何时彻底停手。本文研究在初始时刻由有限先验抽取一次并在全时域持久保持的未知可靠度：仅初始化时刻（$t=0$）的成功维修能配置冷备用槽位（`child1`），每次维修请求须在观测结果前满足逐样本路径预付约束，且控制器仅观测记录“是否产出”与“是否扣费”的两比特收据。当预算恰能支付一次成功维修（$c \le B_0 < 2c$）时，本文对任意价格证明边际重试收益具有单次穿越性，给出嵌套价格阈值、单调最大重试次数停止律、四步备用窗口关闭引发的纯权限决策翻转（$53/32 \to 97/64$）、持久参数方差溢价、故障后验阈值收缩、设备状态反馈的正价值与耗尽维修预算后参数揭示的零价值（$\mathrm{EVPI}_{\mathrm{post}} = 0$）。对多次维修预算（$B_0 \ge 2c$），在原生谱系过程上过滤无信息零收据可导出五坐标充分摘要及具三次可达界 $O(1 + (\min(M,H)+1)H^3)$、多项式有理数位长与双层检查器 `accept` 四次上界 $24(H+1)^4$ 的认证决策图求解器。

## 六大核心定理结构概览

1. **原生谱系交换、初始化备用配置、逐路径预付安全与全历史实随机 Bayes 最优（第 2 节，定理 1）：** 在继承目标对齐不变式下，证明无限增长原生谱系槽位表与压缩物理位世界逐交易精确同构，阐明首步备用槽配置机制及逐路径硬钱包与期望预算 CMDP 的精确边界，支配一切支持合法的实数随机化完整历史策略。
2. **任意价格单次维修预算（$c \le B_0 < 2c$）最优重试停止律、四步窗口翻转与嵌套价格阈值（第 3 节，定理 2）：** 给出零写续程多项式 $U_1, U_2$；对任意价格 $p = \lambda c \ge 0$ 与 $c \le B_0 < 2c$，由离散 Chebyshev 协方差恒等式证明边际连续重试值 $\Delta_t$ 单次穿越（$\Delta_t \le 0 \implies \Delta_{t+1} \le 0$），从而精确最优值为 $V_{H+1}^* = \sum_{t=0}^H d^t \max\{0, \Delta_t\}$，导出全价格充要正值判准 $V_{H+1}^* > 0 \iff p < p_0^*(H)$、嵌套重试深度阈值 $p_0^* \ge p_1^* \ge \dots \ge p_H^* \ge 1$、四步无参数不确定性下备用窗口关闭导致的重试阈值下移（$53/32 \to 97/64$，差 $9/64$，在 $p = 8/5$ 翻转决策），并将高价格公式 $p \ge S_H(d)$ 包含为 $m^* \le 1$ 的特例。
3. **持久参数方差溢价、故障后验阈值收缩与状态反馈对参数学习的价值分离（第 4 节，定理 3）：** 证明持久参数方差溢价 $d\,\mathrm{Var}(r_\theta)$（$+1/160$ 对候选 $-1/40$、最优 $0$）；由 $\mu_1\mu_3 - \mu_2^2 = w(1-w)r_0 r_1(r_0-r_1)^2 > 0$ 证明故障收据使修复阈值严格收缩（$21/16 \to 5/4$）；在同一修复后续程子博弈中并列证明设备状态反馈具严格正价值 $d^3\mathbb{E}[r_\theta^3(1-r_\theta)]$（$20925/524288$），而免费揭示持久参数 $\theta$ 的价值恒为零。
4. **有信息零收据判准与全策略计数后验分解（第 5.1 节，定理 4）：** 刻画损坏槽空转与缺失槽请求的确定性 $(0,0)$ 收据（似然恒为 $1$，$\Delta f = 0$），证明在任意实随机历史策略下动作随机化因子 $\alpha_\pi(h)$ 恒等消去，精确后验化为 $\pi_0(\theta) r_\theta^s (1-r_\theta)^f / Z(s,f)$。
5. **五坐标摘要 $\sigma = (t,q,s,f,k)$ 的全动作充分性、对称先验对数赔率约简与三向锐界见证（第 5.2 节，定理 5）：** 证明 $\sigma$ 对一般有限先验保持全动作单步联合律（对互补两点先验 $r_1 = 1 - r_0$ 进一步无损压缩为净成功差 $\delta = s - f$），并以可达轨迹证明物理马氏状态 $(t,q,B)$ 不充分（$5/8 \neq 1/2$）、原生谱系尾部合法合并及槽位 2 扩权分裂（$0$ 对 $r_\theta$）。
6. **双层验证器 `accept` 全动作认证决策图、三次可达界 $O(1+(\min(M,H)+1)H^3)$ 与八步公平基线（第 6 节，定理 6）：** 严格区分通用 `certify` 与带 `boundCheck` 的 `accept`，证明任意 `accept` 接受数组的 $24(H+1)^4$ 界，并证明规范生成器的完备接受性（`accept(generate(...)) = some res`）、可达节点界 $N_{\mathrm{reach}}(H,M) = O(1 + (\min(M,H)+1)H^3)$ 及后验分母伸缩相消带来的多项式有理数位长；在八步双钱包基准上将 $23,841,395$ 条合法正概率完整历史（语法串 $28^8$）在 $0.18\text{ s}$ 内压缩并独立认证为 $1,661$ 个通用节点（$s-f$ 约简为 $1,020$ 个节点）与 $151$ 个执行节点，精确最优值 $884450457/1342177280$。
