# UEOT Publications

Papers, books, figures and release artifacts are snapshots of a particular theory state.

Target structure:

- `papers/`
- `book/`
- `figures/`
- `releases/`

Each future release should record the Core specification version, formalization commit, physics-sector version, and validation report set it represents.

Existing root manuscript artifacts, `book/`, and `source/paper/` are preserved during migration.
