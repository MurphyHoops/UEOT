# Teleological Equivalence Compression — Feasibility Audit

Status: **LOCAL LEAN PASS / EQUIVALENCE HIERARCHY VALID / NO NEW GENERATOR**

This audit tests the proposed M-TE compression between frozen Core v3
P-DDH-01 and P-TEL-01.

The result is useful but negative with respect to generator counting: there is
a clean hierarchy of teleological equivalence notions, yet the substantive
source mechanisms remain different.

## 1. The hierarchy

The local module

`UEOT/V3/Compression/TeleologicalEquivalence.lean`

distinguishes four levels for value representations `V,W : P -> ℝ`:

1. `ValueEqual V W`

   \[
   W(p)=V(p)\qquad\forall p;
   \]

2. `PositiveAffineEquivalent V W`

   \[
   W(p)=aV(p)+b,
   \qquad a>0;
   \]

3. `OrderEquivalent V W`

   \[
   W(p)\le W(q)\iff V(p)\le V(q);
   \]

4. `MaximizerEquivalent V W`

   the two value representations have exactly the same maximizers.

Lean proves the implication chain

\[
\text{ValueEqual}
\Longrightarrow
\text{PositiveAffineEquivalent}
\Longrightarrow
\text{OrderEquivalent}
\Longrightarrow
\text{MaximizerEquivalent}.
\]

Positive-affine equivalence is also closed under composition.

## 2. P-DDH-01 enters at the strongest level

P-DDH-01 proves the gauge identity

\[
(\Pi+\lambda\chi)-\lambda(\Phi+\chi)
=
\Pi-\lambda\Phi.
\]

The adapter

`dualDriveGauge_valueEqual`

places this source identity at the `ValueEqual` level, after which the generic
hierarchy can propagate it to maximizer equivalence.

However, the hierarchy does **not** prove the gauge identity.  The algebraic
cancellation is still exactly the P-DDH-01 mechanism.  Moving the one-line ring
identity into the generic module would be relocation, not compression.

Therefore P-DDH-01 is an adapter into M-TE, not a theorem generated by M-TE.

## 3. P-TEL-01 enters at the positive-affine level

For P-TEL-01 the analytic source work is:

- finite-horizon potential telescoping;
- bounded-potential tail decay;
- geometric-series convergence;
- uniqueness of the infinite-horizon limit.

These produce the specific policy-value identity

\[
V'(p)
=
aV(p)-\psi_0+c(1-\beta)^{-1},
\qquad a>0.
\]

The local theorem

`rewardShaping_positiveAffineEquivalent`

packages this as `PositiveAffineEquivalent`.

The source-facing theorem

`policy_values_affine_via_teleologicalEquivalence`

then rederives the policy-value form of P-TEL-01 by:

1. using the already frozen analytic helper `shaping_limit_value` for the
   concrete affine identity;
2. using the M-TE hierarchy only for the maximizer-preservation step.

Thus M-TE separates the analytic mechanism from the decision-invariance
consequence, but does not replace the analytic theorem family.

## 4. Why P-DDH-01 and P-TEL-01 are not one mechanism

They live at different semantic layers.

P-DDH-01 concerns **representation non-identifiability of one combined
objective**.  It gives literal numerical equality after a gauge change.

P-TEL-01 concerns **policy-value invariance under discounted reward shaping**.
Its transformed value is generally not equal to the original value; it is a
common positive-affine transform, sufficient to preserve policy ordering and
maximizers.

Moreover, the frozen source does not identify an arbitrary DDH
state/trajectory objective with the policy-level infinite discounted value used
by P-TEL-01.  Such an identification would require an explicit evaluation
bridge.  Without it, composing DDH gauge and TEL shaping as though they were
the same physical transformation would be an unsupported strengthening.

## 5. Compression audit

### P-DDH-01

The substantive proof obligation remains the gauge algebra.  M-TE only
propagates an already established equality downstream.

**Generator replacement: FAIL.**

### P-TEL-01

The substantive proof obligations remain telescoping and infinite-horizon
analysis.  M-TE replaces only the final generic fact that a common positive
affine transform preserves order/maximizers.

The original Core helper `positive_affine_maximizer` already provided this
standard mathematical fact before the compression experiment.

**Generator replacement: FAIL.**

### Cross-family reuse

Both source families can be placed in one typed equivalence hierarchy, and the
hierarchy prevents the theory from conflating numerical equality with policy
equivalence.

**Architectural bridge: PASS.**

## 6. Scientific value of the hierarchy

Although it is not a counted generator, the hierarchy sharpens the Core v3
notion of teleological equivalence.

It makes explicit that claims such as "same purpose" may mean different
things:

\[
\text{same numbers}
\Rightarrow
\text{same affine scale class}
\Rightarrow
\text{same policy order}
\Rightarrow
\text{same optimum set}.
\]

The converses are not asserted.  In particular, observing the same optimal
policy does not identify a unique reward function, a unique Π/Φ decomposition,
or even a unique policy ordering.

This is consistent with Core v3's existing gauge/non-identifiability boundary
and makes that boundary easier to reuse in later control/alignment work.

## 7. Classification

Recommended classification:

**M-TE REJECTED AS AN INDEPENDENT COMPRESSION GENERATOR; RETAIN AS A TYPED
TELEOLOGICAL-EQUIVALENCE BRIDGE CALCULUS.**

No ledger change is justified.  The canonical four-generator core remains
unchanged.

## 8. Next candidate

The next higher-value compression test is a contractive fixed-point calculus:

- Bellman contraction / unique optimal value / residual stability;
- Dobrushin contraction / unique invariant distribution / mixing and
  perturbation stability.

The test must not erase their distinct domain obligations.  A generic Banach
fixed-point theorem alone would be cosmetic; a successful candidate would need
to factor out a repeated **fixed-point + iteration + residual/perturbation
certificate** surface while leaving selector and probability-kernel adapters
explicit.
