## 1. Classification semantics

H1 uses the required route labels:

- `COUNTED_GENERATOR_DERIVED` — exact frozen P-ID mapping recorded in the
  Compression ledger and witnessed by a counted G0 theorem.
- `MERGED_BRIDGE_DERIVED` — a canonical-main post-FINAL theorem gives an
  actual source-facing rederivation/closure route. This is uncounted and does
  not change the frozen P-ID lifecycle.
- `RETAINED_ADAPTER` — the frozen source/domain machinery is not generated by
  current G0/G1/G2. A partial or stronger sufficient post-FINAL route may still
  exist and is recorded separately.
- `RETAINED_BOUNDARY` — the frozen no-go/identifiability boundary is retained
  intentionally rather than generated.
- `RESIDUAL_OPEN` — an architecture-level obligation is not reconstructed by
  existing canonical architecture. This is not automatically a primitive.

Route classification and frozen lifecycle are independent. In particular, a
frozen `retained_adapter` may have a later `MERGED_BRIDGE_DERIVED` route
without becoming counted.

## 12. H1 scientific result

H1 rejects the hypothesis that the observed hierarchy surface is evidence for
one already-known universal hierarchy generator.

The four counted generators have substantial but typed reach:

\[
\boxed{
\begin{aligned}
\mathrm{M\!-\!QD} &:\ \text{quotient / predictive descent},\\
\mathrm{M\!-\!TC} &:\ \text{cross-scale / historical transport},\\
\mathrm{M\!-\!PE} &:\ \text{positive-eigen / QSD / reproductive value},\\
\mathrm{M\!-\!OI} &:\ \text{occupation-limit persistence / invariance}.
\end{aligned}}
\]

Merged uncounted bridges close further typed interfaces, especially recursive
prediction, alignment, and contractive GOA uniqueness/perturbation.

What remains is not one homogeneous unexplained "hierarchy force":

- resolution/realization remains a coherent retained closure/Galois/blocker
  adapter family;
- value/selection/long-run families retain source-specific analytic and
  semantic adapters;
- the only current **formation** residual is concentrated in H0-COMP: the
  binding/existence interface that turns several child objects plus environment
  into a justified parent object without assuming the parent-specific
  certificates in advance.

H2 must test that residual directly.
