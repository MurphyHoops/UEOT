## 1. Final scientific architecture

P4 does not define inverse Objecthood as one classifier over candidate labels.
The final architecture separates five logical layers:

1. **candidate universe** — which finite formed candidates are currently under
   consideration;
2. **declared evidence equivalence** — which candidates cannot be distinguished
   by the selected observations/interventions;
3. **scientific target object equivalence** — the `Setoid` whose class P4 is
   actually asked to recover;
4. **validity/certification** — which candidate labels are scientifically
   admissible as operational, recoverable or semantically identified objects;
5. **downstream identity bridges** — whether a recovered object class determines
   the same control encoder and/or the same parent identity.

These layers are intentionally not definitionally identified.

## 3. Recompression and adversarial-audit decisions

### 3.1 Candidate equality is not the universal inverse target

`ObjectClassIdentifiedByEvidenceAmongValid` takes the scientific target
relation as an explicit `Setoid`. The interaction-evidence relation is another
`Setoid`, generated by the selected probe family. P4 proves literal candidate
recovery only when an additional separation condition collapses the relevant
class to one label.

This prevents a model token, an evidence class and an Objecthood identity from
being silently treated as the same mathematical object.

### 3.2 Finite separation constants are derived rather than assumed

For a finite candidate type with a strict unique true-risk minimizer,
`canonicalRiskGap` is automatically positive. For a finite interaction
candidate type, `canonicalInteractionEvidenceGap` is automatically positive
between distinct evidence classes.

Both constructions use a positive fallback on the already-equivalent/self
cases, so singleton or one-class candidate families remain nonvacuous. The
fallback can make the canonical gap conservative; it does not strengthen any
actual nontrivial separation.

### 3.3 Candidate-universe recovery reuses P3 and Track X

P4 does not create a second empirical coalition matcher. P3 already recovers
the exact finite response carrier family from one response estimator, and
Track X already maps exact carrier recovery through the child-coalition
formation construction. P4.2 is only their composition.

The no-exact-carrier ⇒ no formed-candidate boundary remains canonical and is
not weakened by P4.

### 3.4 Evidence-class recovery is primary; pairwise separation is optional

Two candidates that both fit one observed fingerprint within `eta` are in the
same evidence class once `2 eta` is below the canonical inter-class gap.
Vanishing fingerprint error therefore gives eventual exact **class** recovery.

`PairwiseInteractionSeparating` is used only for the stronger conclusion that
the recovered class contains one candidate label.

### 3.5 Operational validity is not generated by statistical fit

`FormedCandidateOperationalValidity` retains only genuinely additional
obligations: interaction delimitation and constitutive persistence. Formation
provenance is no longer stored as a redundant field because it is already
encoded by the `FormedCandidate` subtype and is exposed as a derived theorem.

Recoverability and semantic-fibre identity are separate stronger validity
layers. Current response/intervention data do not automatically manufacture
physical-repair or semantic-kernel certificates.

### 3.6 High-probability closure keeps changing sample spaces honest

`ChangingObjectClassDiscoveryContract` allows `Omega n` and its measure to vary
with sample size. It proves marginal class-failure probability tends to zero.
It does **not** infer almost-sure eventual recovery on one common sample path.

The specialized interaction theorem requires the small-error/gap relation only
eventually when the observation-error radius tends to zero; early sample sizes
may remain ambiguous.

### 3.7 Identifiability and persistence are independent

P4.6 machine-checks both directions of the separation:

- the canonical identifiable response witness can be paired with dynamics that
  cannot constitutively persist on the proposed domain;
- the self-loop dynamics are genuinely constitutively persistent while the
  collapsed response family leaves distinct candidate labels interaction-
  indistinguishable.

Therefore neither persistence nor identifiability may replace the other in an
inverse-object validity contract.

### 3.8 Finite discrimination has an irreducible statistical boundary

From P-INV-01, if two candidate data laws have total variation strictly below
one, every measurable equal-prior binary discriminator has strictly positive
average error. P4 therefore cannot promise perfect finite-sample discrimination
without enough evidence to make the candidate laws fully separable.

### 3.9 Control fibres and same-parent identity remain separate

`ObjectClassControlEncoderBridge` and `ObjectClassParentBridge` are independent
interfaces. Recovered-class membership yields encoder equality only through the
first and parent equality only through the second.

P2's explicit witness that identical history-control specifications may belong
to different parent identities is retained. P4 therefore never upgrades
control equivalence to same-object identity by implication.

### 3.10 Terminal closure was tightened after recompression

The first P4.8 draft simultaneously assumed class collapse, a control bridge
and a parent bridge. This was redundant: once candidate equality is already
known, every candidate-indexed map agrees automatically.

The final surface is split instead:

- `p4_terminal_bridged_inverse_closure`: no singleton-class assumption;
  object-class consistency plus explicit control/parent bridges yields encoder
  and parent consistency;
- `p4_terminal_literal_candidate_closure`: singleton-class/collapse alone gives
  literal candidate consistency.

This is a strictly smaller assumption architecture.

## 5. Nonclaims retained after audit

P4 does not prove:

- a unique metaphysical object from finite observations;
- that candidate labels are universally meaningful object identities;
- full Objecthood/repair/semantic certificates from interaction fingerprints;
- persistence from identifiability or identifiability from persistence;
- same-parent identity from equal control data;
- purpose, a unique teleological objective, or a unique Π/Φ decomposition from
  object evidence;
- perfect finite-sample discrimination when candidate data laws overlap;
- almost-sure common-path recovery from marginal confidence bounds alone;
- arbitrary, countable, Standard-Borel or general infinite-state inverse
  Objecthood;
- unrestricted causal discovery outside the declared finite candidate and
  intervention model.

These are later Theory Completion or domain-specific obligations, not missing
steps inside P4.
