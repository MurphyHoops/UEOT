# C7 external-domain validation — preregistration template v1

Status: **DESIGN ONLY / NO EXTERNAL DOMAIN SELECTED / NO DATA COLLECTED**.
The canonical `real_world_support = UNVERIFIED` is unchanged.

## Target to register before observation

Fill and freeze these fields in a distinct preregistration commit, **before**
any certification result or model adaptation:

- independently maintained target system, operator, deployment/version and
  reason it is not the constructed C7 majority-service worker program;
- object boundary, admissible parent completions, physical/software component
  IDs, replacement operations, timing and safety permissions;
- registered observables and semantics of the UEOT carrier, formation `F`,
  binding `B`, lower-state transport `tx`, parent transport `tp` and realized
  transport `td`; do not infer these identities from the final outcomes;
- calibration and independently held-out certification units, predeclared
  finite candidate universe and fault/control protocol assignments;
- observation completeness, failure/censoring and missingness categories,
  timestamps, provenance/authentication method and raw evidence destination;
- calibration procedures (and units) for `epsF`, `epsB`, binding `L`, and if
  using multi-step C4, transport Lipschitz `M`;
- explicit domain conditions permitting causal intervention or passive-only
  observation; unsafe or unauthorized destructive faults are prohibited.

## Predictions/falsifiers to freeze in advance

**C2:** protocol coverage, held-out decision intervals and registered gaps;
ambiguous is a legitimate outcome. Calibrate dependence/mixing externally:
C2's `(m-1)β(b)` term is only a budget adapter, not a proven concentration
bound. Do not apply iid confidence intervals to correlated/adaptive runs.

**C3:** search only the registered candidate family. Evaluate a separate
exhaustive baseline where computationally feasible; if the claimed binding
factorization is common-Markov, test it on held-out parent pairs or report
`UNIDENTIFIED`, not an invented `L=1`.

**C4:** preregister which source completions require matched targets. Measure
actual directional formation defects and binding-transport residuals, then
compare held-out realized mismatch against `L epsF + epsB`. A lost source with
no admissible successor **falsifies directed coverage**; an unmatched new target
is a possible birth and does not falsify one-way coverage. No symmetric
Hausdorff/same-object inference without an independent reverse bridge.

**C5:** reject a common-two-drive bottleneck only when the certified residual
rank test excludes rank ≤2 after perturbation budget. Compatibility never
proves unique Π/Φ coordinates. Register at least one >2-drive negative control.

**C6:** a mechanism signal is not purpose evidence without an independently
validated teleological-faithfulness bridge. Keep P2 mechanism/purpose/viability
and future-order gates separate.

**C7:** distinguish intervention-integrity failure (UNRESOLVED), domain-bridge
falsification (REJECTED_DOMAIN), preregistered statistical ambiguity
(AMBIGUOUS), and supported held-out domain prediction (SUPPORTED_DOMAIN).
Record all registered attempts and all negative controls, even failures.

## Required external validity ladder

1. **READY**: registration, ethical/safe access and independent data source
   exist; no data-based scientific claim yet.
2. **MECHANISM_TESTED**: held-out predictions and negative controls executed,
   complete raw provenance available, all estimates/uncertainties reported.
3. **DOMAIN_CONDITIONAL**: at least one independently reproducible target-domain
   result satisfies its prespecified assumptions and thresholds.
4. **GENERALITY_NOT_ESTABLISHED**: default even after a single successful
   domain experiment, unless cross-domain replication is actually performed.

Failure of a domain bridge does not automatically refute the generic Lean
conditional theorem. A proof/source mismatch must be reported as the distinct
`MATHEMATICS_OR_SOURCE_SEMANTICS_MISMATCH` class.

This template is **not** a pre-registered trial, independent reproduction, or
real-world validation result. It explicitly prohibits flipping `UNVERIFIED`
until an identified target and new evidence survive an independent audit.
