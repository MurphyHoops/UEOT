## 一、可以独立复述的七项内容

### 1. 恢复和增长属于同一个实际程序：PASS

我的理解是：这里没有先找一个会修复的程序，再另找一个增长快的程序，把两个结果拼成同一能力。第一程序始终照护；第二程序在健康时偏向新生，在损坏时付费恢复并照护。第二程序恢复后的动作仍由它自身的真实码决定，其后代忠实继承这些码。每个程序分别从自己的损坏身体继续运行；两个程序的备份码不同，不要求二者具有同一份程序内容。

多数备份和有限启动基元使恢复可以发生；三个实际存储位、活动位的故障、关闭的执行门以及三单位实际费用，使“描述了修复”与“实际完成了修复”可以区分。可信启动底座、保存的信息和环境资源仍是条件，局部修复也不保证修复后的个体免于死亡。第七章第 173—179 行及第 183—187 行已经把这些限度说明白。

这足以支撑一个有限但实在的哲学结论：组织把部分执行条件纳入了自身维持活动。它没有单凭这一点取得生命、意识或完整主体资格。

### 2. 何时哪个既有程序达到最优：PASS

为准确复述，我把两个固定程序各自的长期人口增长因子记为 G₁、G₂；这只是报告中的简写，不是新增模型。按第七章和增长分类脚注，完整允许策略的最优因子是：

**max{1, G₁, G₂}。**

因此第一程序达到，当且仅当其因子不低于第二程序且不低于一；第二程序达到，当且仅当其因子不低于第一程序且不低于一。两者因子相同且至少为一时共同达到。两者虽然平手但都小于一时，真实拒绝提供的因子一仍然优于它们。

正文以行动后果解释这种排序：第二程序的新生增益足以抵消原个体续存损失，并且其长期因子至少为一时，第二程序能够达到；相反排序且照护因子至少为一时，第一程序能够达到。照护本身平均产生少于一个后继，并不单独排除第二程序利用健康／损坏状态下的不同动作获得超临界增长。

完整达到标准以两个程序各自的因子及拒绝基准作比较；不能只凭“bloom 的名称听起来更有增长性”作判断，也不能把两个行动某一项贡献的大小当作完整程序排序。脚注明确列出了两个因子及其与一的最大值，足以约束正文的概括。这里审查的是这种分类是否读得懂，没有用未读的技术来源替它补做证明。

### 3. 真实拒绝的作用：PASS

拒绝不是讨论之外的任意退出选项。它来自同一请求菜单的实际后果：损坏体可以提出越额请求，规则拒绝该请求并保留该身体。完整比较类必须计入这个结果，因此最优因子具有一这一基准。删除合法的拒绝后果，会改变所比较的问题。

这一事实还能解释为什么两套会付费恢复的固定规则在某些参数下都失优。它没有证明停止活动是自然系统的普遍最优生活方式；身体在拒绝时被保留，是本模型公开承担的具体规则。第七章第 177—181 行已明确这一点。

### 4. 时间尺度与评价量的选择：PASS

本轮“最优”比较的是长期**期望人口**的指数增长因子。它不同时保证每个期限的期望人数最多、原个体一期续存率最高、某个有限群体不灭绝、材料消耗最少，或者行为者主观理解了目的。所谓“因子一”按脚注的指数底数理解，不是对数增长率等于一。

第十一章先用有训练费用的修复说明时间尺度：眼前付出较多，可能换取较长未来的收益；训练成本又不能因此被抹去。随后在增长例中进一步说明，即使长期因子相同，有限期限仍可能不同。读者因此有充分根据询问“在什么期限、按什么量、从哪个起点比较”，而不把一个长期指标扩张成全部目的。

### 5. 临界时指数相同、有限人数仍不同：PASS

临界例的具体复述是：第二程序从自己的损坏创始体出发，在每个正期限的期望人口为 11/12；一直真实拒绝，则在每个这样的期限保留一个个体。两个期望人口序列都是正的常数量级，因而长期增长因子同为一；有限期限却始终相差 1/12。

这里“同样达到指数最优”没有把丢失的期望人数补回来，也没有把两个策略说成所有方面等价。另一个两期例进一步指出：第二程序可以达到最高长期因子，而两期人数最优的策略会在末期对损坏体选择拒绝。长期目标与有限期限目标可以给出不同动作。

第十一章第 300—302 行已把数值、比较起点和解释作用写在正文中，不需要读者先打开数学著作才能理解这个反例的哲学意义。报告接受所列数值作为本书陈述的例子，没有声称独立核验其模型计算。

### 6. 两个固定程序失优，不等于所有真实修复失优：PASS

失优命题的量词范围是持续执行这两套固定规则。它不是“任何包含真实修复的允许策略都不能最优”。正文给出的反例方向很具体：允许的历史策略先在同一损坏创始体真实付费照护一次，之后按状态选择继续或拒绝，仍可达到因子一。

这里没有偷换成免费恢复，也没有保证每条路径都留下个体。修订后的正文明确说明，合法概率条件保证首次照护有正概率留下后继；首步死亡的可能、已经支付的成本以及以后所需供给仍在记录里。一次有限前缀造成的正倍数损失，可以保留长期指数而影响有限人数。

这种历史策略本来就不同于两种固定内部程序。以它说明“真实恢复与指数最优并不普遍冲突”，没有把它冒充成第二程序自身在所有参数下都最优。第七章第 181 行对这一区分已经清楚。

### 7. 机制事实与规范责任的关系：PASS

书稿的机制贡献是：给定身体、执行、资源、继承与评价问题，可以从实际续存和新生推出增长差异；这种方向不只是事后给成功贴上目的标签。选择长期期望人口作为评价量，仍然是一项问题选择。

原个体继续存在、增加后代、避免灾难、节省材料以及有限期限损失，都可以成为有理由的关切。增长占优不使其他关切失去理由，也不产生道德正当性。应当优先何种关切，要由相应的目的说明和规范论证承担。

前言第 35—39 行、第十一章第 296—304 行没有把数学证明当作伦理证明，也没有把这次有限自然化说成已经发现全部 UEOT 的唯一终极目的。第七章第 169 行另保留了历史责任：终点恢复不会自动消除已经发生的损伤、错过的机会或应当承担的责任。这些层次彼此有关，但没有被混为一个结论。
