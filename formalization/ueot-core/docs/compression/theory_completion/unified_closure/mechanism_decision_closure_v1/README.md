# 允许实验下的机制分辨与最坏决策损失闭环

两种组织都能产生子代，复制出来的个体却不总是同样有用。局部故障 **S** 只损坏被派发个体；共同故障 **G** 还会损坏未派发的备份。这个交付包在同一源接口、钱包和有限时限内回答两件事：允许的实验最多能区分多少，以及不知道故障结构时能以多小的最坏损失行动。结论接续 PR442 基线 `7f66c167a41c4f89c278431ae634218f7aaddda3`；原全 Core 条件合同、PR441 和 PR442 的完成范围不变。

**主结果。** 从唯一坏 root 出发，三步实验在可预付一次写费时达到最大总变差 $r^2(1-r)$。冻结 $r=1/2,H=3,B=2,c=1,\lambda=1/4,d=1,goal=true$ 后，同一份返回策略的最坏后悔恰为 **3/128**。所有确定性合法策略能达到的最小值是 **1/32**。达到 3/128 需要独立私随机；这两个后悔值都相对于遵守同一观察、动作、钱包和时限的机制已知比较者。

## 控制器究竟知道什么

两个机制都从只有一个坏 root 的 Store 开始。机制预先固定，直到终点不变，也不依控制器种子选择。每 tick 用同一公开正常率 $r$ 的原 mode 与独立公平 label。S 完全沿用原事务，G 先进行原事务，再在 fault 时把结果 Store 的每个已有个体的相关物理位置为 $!goal$。即使地址缺失或已 stop，环境故障仍生效。共同损坏保留槽序、None、其他物理位、受保护程序、身份、谱系及原事务产生的时钟。每 tick 仍追加一槽；没有出生就追加 None，后来的出生不补回空的 child1。新生个体及其真实父身份来自原事务。

控制器只读公开参数/剩余时限、自己的动作和 **(birth, paidWrite)** 双位收据，由此计算自己的实际钱包，并可使用独立私随机。它不能读取机制、mode、label、完整 Store、受保护程序或真实父身份。可请求 stop、root0/child1 的 idle 或写 false/true。stop 承诺从本 tick 起实际执行 root idle，世界照常推进。请求先以原 cap 检查能否付款，执行后才按真实收据扣费。从诊断到行动没有重置、第二笔预算或额外训练期。评价预先固定为
$$
J_m(\pi)=\mathbb E_m^\pi\sum_{t=0}^{H-1}d^t(\mathrm{birth}_t-\lambda\,\mathrm{actualFee}_t),
$$
终端值为零。

在“正确写 root 收到 11，随后 root idle 收到 00”的允许历史上，两机制的似然都是 $r(1-r)$。此时 root 都坏，S 的 child1 好，G 的 child1 坏；即使机制边缘概率没有改变，身体和机制仍相关。登记联合过滤器对正质量的历史给出条件律，联合质量恒等式也涵盖零质量历史。旧 S 观察器在该前缀不能直接迁移到 G；这并不改变它对原 S 的结论。

## 可以辨认多少

| 登记条件 | 同一合法实验在 S/G 下的允许历史 |
|---|---|
| 实际只派发 root，任意有限 $H$；或完整七动作、$H\le2$ | 两边分布相同。 |
| 唯一坏 root、$0\le B<c$，任意有限 $H$ | 每个实际收据均为 00，两个允许历史律相同。 |
| $r\in\{0,1\}$，任意有限 $H$ | 总变差为零。 |
| $H=3$、$B\ge c>0$，公开固定实数 $0\le r\le1$ | 最大总变差为 $q=r^2(1-r)$。 |

达到协议是 **正确写 root → root idle → child1 idle**，中间不能换成 stop。三步中两个源的第一次收据差别只可能出现在“正常、故障、正常”；其中允许收据序列 11/00/10 在 S 的概率为 $q$，在 G 为零。故全策略上界与原预算内的达到值相等。$r=1/2$ 时最大总变差为 $1/8$，等权二元分类错误最小为 $7/16$。对任意有限 $H$ 和 $0<r<1$，共同全故障模式仍迫使错误率至少为 $(1-r)^H/2>0$。这是二元分类界。相反，在相同冻结参数、$H=2$ 时，两个机制有共同最优策略且值为 $13/16$：机制分不清并不一定妨碍做出最优行动。

**私种子也可用于终端判别。** Lean 对任意实概率的原始历史动作核证明它有同一有限响应树分布，在每个固定机制上给出原历史律；其种子化检验在终端同时保留私种子和允许历史。这里的有限种子表示不限制随机权重，也不迫使判别器忘记自己用过的随机性。给定更一般的可测私随机输入及一个二元终端判别器，把全程私随机实现固定：它决定一棵深度 $H$ 的动作树，也决定每条长度 $H$ 的可能允许历史上的一个终端判决。动作和收据有限，因此**动作树与整张终端判决表的有序对**只取有限多值。将原独立随机律推前到这个签名，得到与世界独立、概率可取任意实数的有限种子；逐个机制，执行动作、收据和最后判决的联合律保持。对每个检验事件如此做即可应用终端持有种子的界；只按动作树合并、却丢掉终端判决表，会漏掉部分判别器。除上述有限签名归约外，Lean 的 arbitrary_private_H3_error 和 arbitrary_private_finite_error 直接在任意独立私种子的概率空间（包括连续分布）对条件判别风险积分。

## 机制未分清时的实际行动

已知 S、已知 G 和下界见证 $w=(3/4,1/4)$ 各在完整合法菜单上求值。前两次返回确定性表 $\pi_S,\pi_G$。部署只在起点使用独立均匀四点种子：0 取 $\pi_S$，1、2、3 取 $\pi_G$。之后按允许收据走完同一张表。真机制不参与选表。下界权重 $w$ 与这个部署混合的权重不同。

| 实际返回 | $J_S$ | $J_G$ | 最坏后悔 |
|---|---:|---:|---:|
| $\pi_S$ | 41/32 | 37/32 | 3/32 |
| $\pi_G$ | 40/32 | 40/32 | 1/32 |
| $\rho=\frac14\pi_S+\frac34\pi_G$ | 161/128 | 157/128 | **3/128** |

该歧义前缀在每个机制下概率都是 $1/4$，钱包余 1，时间余一步。idle child1 的条件净值在 S/G 是 $1/2$ 与 0；正确写 root 都是 $3/8$。前者选择取决于备份是否保住，后者可以消耗剩余钱包修复根。一般下界不是从这两张表的比较得出：新源上的完整历史 Bayes 上界给出 **任一** 共享合法策略的加权值至多 $5/4$。故最坏后悔至少 $\tfrac34(41/32)+\tfrac14(40/32)-5/4=3/128$，实际返回在两个机制均恰达该数。对任意确定性策略，固定参数使每个 $J_m$ 与最坏后悔都落在 $\frac1{32}\mathbb Z$，所以正下界上移为 $1/32$，并由 $\pi_G$ 达到。

## 如何判断执行和证明各自覆盖了什么

Lean driver 从同一次求得的完整返回表导出动作行并执行 packed 世界；完整 Store 解释由原生桥定理及使用原事务适配器的独立执行承接。冻结批次涵盖 **2 个机制 × 4 个私种子 × 64 条原 mode/label 带 = 512 条运行**；每个固定机制下，每个“种子、整条噪声带”组合质量为 $1/256$。独立 checker 检查 **1,536 个实际 tick/非空付款前缀**、两机制收益、账本、身份与世界投影；另用未归一化联合历史质量和精确有理数重算全部合法动作的 oracle、见证值及冻结例的最大 TV。路径枚举是对 THIS 返回的完整运行核对；覆盖其他策略的定理由全动作上界给出。两组证据不能互相替代。

通用源、过滤、原生桥、耦合及后悔证书与闭合的小规模算术应区分。冻结 H2/H3 的两个闭合求值声明使用 Lean 的 `native_decide`，包含各自计算机生成的原生归约公理（详见实际公理审计）；独立 Fraction 核对是另一份证据。此前未成功的直接内核展开尝试仍作为工程记录；不会据其推导数学不可能。

本包中的 S/G 是合成数学机制，经验状态仍为 **UNVERIFIED**。终端分离不等于同 H3 已获得学习后的控制收益。正当目的、真实机制先验、对象内部随机硬件和计算能耗均非本合同结论。数学/执行证据与发布、原 GI CAS、fresh recall 及唯一 CONTINUE 的事务状态应分别读取；不能由本文单独推断后者已经发生。
