分辨定理容许任意实正常率和同源自适应实验；可部署有理求解器与冻结数值另有限定。H=3 的正向公式要求 B≥c；小预算、仅根、H≤2、端点零界有各自前提。分类器可保留私随机性；任意独立概率空间的条件错误下界有直接积分证明。全故障共用质量只给二元总判别的误判下界，允许 UNKNOWN 的单侧证书不在此断言内。H≤2 的共同最优与非零 H2 数值是行动结论，不是世界相等。
