# UEOT Core：统一结构回顾与下一阶段任务

日期：2026-10-21。本文接续已合并的支持生存闭环与 #354 接口研究。它是当前工作计划与成熟度说明，不是尚未完成的 canonical 发布收据。最新远端读取见后续交接；在本文制定时，真实 main 为 `65db00a12d20be41cd6c8befacb9ba2e74a2a8a9`。

## 1. 研究目标及判定标准

核心目标是建立可追溯、可组合且有明确适用范围的数学统一结构。对象、观察、行动、风险、可行性、目的与长期组织之间的联系，需要由同一来源的数据构造，并证明所涉及的核、策略、初始律、记录和事件确实相同。数学闭环同时包含正面定理、必要假设、反例与无法推出的边界。

MINCORE 提供关系、缺陷和生成结构；H0 明示领域结构；冻结 P-ID 区分生成结果、适配与边界；TheoryCompletion 负责补齐具体来源联系。一个适配不会仅因使用共同术语而变成由四个生成元自动推出的结果。冻结 106 项继续保持 11 generated / 89 adapters / 6 boundaries。

以下判断持续有效：

- Lean 证明明示假设下的数学命题，不能据此证明经验世界、意识、伦理或完整自然理论。
- 零未认证占据是实际受选行的认证性质，参考风险及拟合误差仍可能非零。
- 当前有限时域认证定理不推出无限认证或物理存活；项目另有实际无限路径安全定理，须按各自条件复用。
- 正概率历史上的后验支持身份不能改成无条件身份；当前观察纤维不能替代完整历史的后验支持。
- 存在一个好策略不推出任意已认证前缀均可延拓。安全约束下最优与无约束奖励最优也不同。
- 数据依赖选择属于预注册的同一实验；不允许事后更换样本数、真实行或失败事件，再沿用原置信预算。

详细来源映射见 [Core 桥接矩阵](../audits/CORE_BRIDGE_MATRIX_2026-10-21.md)。成熟连接包括已校准缺陷的预算传递、可数 a.e. 商下降、同一有限表的控制商与可行反馈、真实无限轨迹安全，以及由同一历史响应构造 GOD/GOA 模型。近期研究要补实际空缺，避免重新命名这些已有成果。

## 3. 第一批验收：完成七模块的真实证据与发布

### 3.1 数学验收对象

七模块已覆盖原先三个具体接口范围差异：

1. **任意观察类型的风险层。** 仍要求有限微状态 X、有限行动 A，并使用 PMF 参考核。完整观察像由有限 X 得到；escape 编码保留参考的全部域外质量，不删除或归一化该质量。单侧实际源支撑足以保持相对于实际源的精确 TV。实际状态—行动占据保持同一策略身份；参考退出后返回并不与吸收参考的逐坐标推前混同。
2. **固定逐行样本量。** 有限注册行 J 上，训练前固定 `N : J → ℕ`、`0 < N j` 和校准半径。真实坐标类型是 `Σ j, Fin (N j)`。联合界使用每一行自己的 N，行内独立和真实边缘律由同一实验提供；不额外需要跨行独立。
3. **同一 Good 上的选中包络。** 拟合、实际占据、事件可测性、失败包络及检查预算都只要求在同一 Good 上对实际选中候选成立。部署律仍为同一选择器、源与策略生成。组合端点内部推出自己采用的 `viableFamilyPolicy` 的零未认证占据。

验收不把这些实现扩写为无限微状态、非原子参考核、随机停止样本量、一般历史策略的 Markov 化，或全部科学接口闭合。

## 4. 第二批研究：实际路径到同源 killed 核

### 4.1 已完成的第一段来源桥

给定有限 X/A、非空 A、控制模型 M、任意观察类型 Y、观察 q 和时间齐次行动 PMF `σ : Y → PMF A`，在每条历史上定义真实策略

\[
\pi_n(h)=\sigma(q(x_n)).
\]

其提升平稳策略与微观转移均直接由 σ、q 和 M 构造。已实际检查的两个私有定理证明：

- 风险一步核中的 `(action,nextState)` 擦除动作后，等于同一 M 和提升策略的 `policyTransitionPMF` 行。
- 对同一 p₀ 和每个 n，完整实际动作—状态路径擦除动作后，等于已有 `policyPathKernel` 生成的完整纯状态路径。

并未假定这两个核或路径相等。Y 无需有限、Markov 或 lumpable；σ 必须满足上述时间与历史范围。一般历史依赖策略和时间依赖 σₙ 需要其他状态扩充或非齐次接口。

动作擦除直接传递的是状态路径事件的逆像。任意依赖动作的失败事件，仍须保留原记录律或另证事件因子化。

### 4.2 当前要证明的精确命题

从同一个实际闭环矩阵 L 与注册安全集 K 构造子类型 S 和 killed 子矩阵：

\[
S=\{x\mid x\in K\},\qquad Q(u,v)=L(u.val,v.val),\qquad
\eta_0(v)=p_0(v.val).
\]

不假定 p₀ 完全位于 K；因此 η₀ 可以是次概率。首要目标为每个 n 和 v∈S 的真实事件等式

\[
\Pr(X_0,\ldots,X_n\in K,\ X_n=v)=(\eta_0Q^n)(v),
\]

以及对末态求和的

\[
s_n=\Pr(X_0,\ldots,X_n\in K)=\eta_0Q^n\mathbf1.
\]

证明路线是把已证状态路径身份接到有限 PMF 事件质量的逐步递推，再与既有行向量—矩阵乘法归纳对齐。不得把所要证明的路径等式或 killed 来源身份放入新结构的字段充当假设。

基本验收包括 n=0 的 `s₀=p₀(K)`、空 K、任意初始安全质量、离开后返回的路径被排除。条件终端分布仅在 sₙ>0 时定义。

### 4.3 在同一来源上接 QSD 与条件路径

完成事件身份后，再复用现有 QSD/Perron 定理：

- 若实际初始安全律就是归一化左特征行 r，且 rQ=ρr、ρ>0，则从同一事件公式推出实际生存质量 ρⁿ 与条件终端律 r。
- 全支撑左 QSD 不足以推出任意初态每个有限窗均正生存；已保留二维矩阵反例。
- 严格正右向量 h、Qh=ρh、ρ>0 才提供相应有限窗正性路线，仍须证明其与实际非零安全初始质量的配对。
- 一般有限窗条件生存核使用 `g_r=Q^r 1`：
  \[
  Q_{t,T}^{cond}(u,v)=Q(u,v)\frac{g_{T-t-1}(v)}{g_{T-t}(u)}.
  \]
  分母正性与条件初始律须明确。它不自动等于固定 Doob h 核；已有精确有理数反例。
- 条件化会改变初始律和受选行动的分布，不能悄悄沿用未条件化注册实验的策略身份。

这批目标的完成标准是同源事件定理与反例都进入受审 Lean，而非增加一份彼此独立证书的组合记录。

## 5. 第三批研究：对象、可行最优与长期组织的真实连接

已有生产结果应直接复用：

- 由同一 P-ALG 表构造组织商、精确控制模型和可行固定点。
- 原微观 PMF 的固定点反馈与真实无限轨迹概率一安全。
- 安全行动限制下的原转移、原奖励身份，以及对所有遵守同一限制的因果随机策略的最优性。
- 同一历史响应的 GOD/GOA 装配；唯一吸引性另需实际闭环的严格收缩。
- M-OI 的有限 Cesàro 子列不变律；没有收缩时，不宣称所有初值或逐时分布都收敛。

新增工作首先选定一个非空、完全明确的实际模型，证明其安全域、奖励目标与 greedy 安全条件，再把它接入现有 SameObject/GOA 接口。不可从“有一个安全控制器”跳到“任意目标的无约束贪婪控制安全”。

对机制到目的的联系，应区分数值表示、弱序、选择集合和可识别的目的类。机制 faithfulness 必须来自具体模型证明，或由同一有效性条件下的真实反例说明失败；裸载体的不可识别性不能冒充完整对象理论的反例。

## 6. 两部独立著作的反馈计划

数学书继续维护定义、假设、推导、边界、反例、源码端点和成熟度。新接口已经在本地新版中明确标为候选；通用 killed 桥未完成前，书面实例不升级为新增 Lean API。来源映射覆盖完整 Core，而非只列本批模块。

哲学书围绕独立的问题展开：多个描述何时属于同一个对象；一种组织何以能被保持；目的理由与实现条件怎样相互约束；幸存群体内部的稳定能说明什么，又不能说明什么。数学和形式化提供论证约束、概念区分及反例，哲学仍须自行论证其解释与意义。

下一次实质修订只吸收已经明确的新关系：

| 数学成熟结果 | 哲学论证责任 |
|---|---|
| 同源构造与路径身份 | 说明“同一对象”的联系需要可追溯关系，不能仅靠词语统一 |
| 缺陷校准及数值不可恢复边界 | 区分结构相同、误差可比与数值标准的选择 |
| 可行反馈与安全约束最优 | 区分持续条件、手段选择与目的理由 |
| 实际生存质量与条件组织律 | 区分原系统延续的概率与幸存者内部的稳定 |
| 目的表示等价和识别边界 | 说明同一选择语义可以有不同数值表达，并保留规范问题的独立性 |

现有新版已检查一般 Doob 与有限窗条件化、全支撑左 QSD 与任意初态生存两个风险点，未发现错误。没有实质内容变化时，不重复重建 250 页产物。
