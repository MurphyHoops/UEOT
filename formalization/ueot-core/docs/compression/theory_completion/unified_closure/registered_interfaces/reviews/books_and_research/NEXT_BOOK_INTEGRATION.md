## 3. 新桥按其实际成熟度吸收

**SourcePolicyPathBridge 已通过私有聚焦编译。** 两端点绑定同一个 M、q、σ、初始 PMF；σ 是固定的当前观察策略，动作擦除保留完整微观状态历史。当前源码与独立静态 CLEAR 的源码完全相同，两个实际公理打印均只有标准三公理。它补的是实际动作—状态路径与既有 stationary state-path 表示之间的等式。尚无生产导入、完整原生或 canonical 验收；不能让七模块的既有收据或计数代替它的新候选身份。下一轮数学 §21.7、§35.7 与 API 映射可在主流程正式接收后记录精确端点；当前不必为这个状态变化重新编译两书。

该桥不覆盖一般历史策略的 Markov 化，不证明观察过程 Markov，也不直接运输依赖动作记录的失败事件。它对每个有限 n 给路径 PMF 等式，不能被描述为已经补出一个新的无限路径对象。哲学主文只需使用“不同表述确实来自同一次过程”的论证价值，不写编译状态或公理清单。

**killed 生存桥仍是独审 CLEAR 的书面合同。** v2 要求从同一个 policyMatrix 直接限制得到 Q；实际初始安全行可为未归一化有限质量；真实生存条件律须分母为正。一般 Doob 变换是端点 h 加权，不等于普通有限窗生存条件化；全支撑左 QSD 也不能保证任意初态正存活。应先形式化实际生存质量 η₀Q^n1 与条件化桥，再给四状态参数实例专用端点。完整 θ 实例、受限 greedy 的全空间混合不变律等现有书面推导，不因第一条路径桥编译而自动成为已有 Lean API。
