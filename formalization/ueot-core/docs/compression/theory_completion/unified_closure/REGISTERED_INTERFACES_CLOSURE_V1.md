## 2. 有限表示保留哪一种概率比较

设有限类型 I 通过单射 i 进入可测空间 Y，Y 的单点可测；μ、ν 均为概率测度，S = range i，且实际源满足 μ(Sᶜ) = 0。这里的支撑条件直接表述为可测集合外的零质量，不引入额外拓扑。定义编码 e，将 i(s) 送到 `some s`，将 S 外所有点送到 `none`。不删除逃逸质量，不进行条件化或重新归一化。

对任意概率参考 ν，有

\[
\operatorname{TV}(\mu,\nu)
=\operatorname{TV}(e_*\mu,e_*\nu),\qquad
(e_*\nu)(\{\mathrm{none}\})=\nu(S^c).
\]

证明的关键是一侧源支撑条件。每个原事件在 S 上的迹可以由编码空间事件恢复；S 外的源质量为零，参考仍保留原来的全部质量。补事件处理两个差值方向。这不是编码在全部概率律之间的全局等距声明。

生产边界取 Y = ℕ、S = {0,2}：

\[
\mu=\tfrac13\delta_0+\tfrac23\delta_2,\qquad
\nu_e=\tfrac12\delta_0+\tfrac14\delta_2+\tfrac14\delta_e,
\quad e\in\{5,7\}.
\]

分别有逃逸概率 1/4、TV(μ,ν₅) = TV(μ,ν₇) = 5/12；而 TV(ν₅,ν₇) = 1/4，编码后两个参考却相同。由此同时排除“TV 只是逃逸概率”和“编码保留任意两个参考的全部区别”两种错误推广。

## 3. 由有限观察像返回原空间完整路径

保持有限微观类型 X、有限行动类型 A，允许观察类型 Y 无限。给定原初始律 p₀、观察 q、实际转移 P、参考 Q 与完整因果策略 π。证明内部取 I = range q；有限 X 保证这个完整像有限。p₀ 的非空支持提供一个解码 fallback 观察点，原完整策略提供所有行动分布，不从空行动类型凭空构造策略。

编码参考在 live 状态采用原 Q 行经 e 的推前，在 escape 状态吸收。编码策略将完整历史逐项解码后调用原 π；每一步动作记录都被保留。于是：

1. 全部实际微观历史上的控制核相等。
2. 每时刻整个实际状态—行动 PMF 相等，因而同一认证谓词的占据也相等。
3. live 初始原子及 live 一步参考原子相等，归纳得到全部完整 live 参考历史的无条件原子质量相等。
4. 对完整历史再应用有限源 TV 定理，得到原路径 TV 与有限 escape 路径 TV 精确相等。

原参考可以离开观察像后返回，吸收参考不会返回；本证明不声称两者的完整参考路径律互为逐坐标编码。所需身份是相对于同一个实际有限源的 TV，以及完整 live 历史的参考原子质量。

将有限路径定理与上述身份、原行 TV 身份结合，得到原空间的实际占据路径界。对认证行误差 εₙ 和实际未认证占据 uₙ，路径预算为

\[
\sum_{n<T}\bigl(\varepsilon_n+(1-\varepsilon_n)u_n\bigr).
\]

这里 uₙ 是原过程与原 π 的实际概率。把它进一步替换为上界 κₙ 时才需要 εₙ ≤ 1，以保持乘法方向。联合接口采用 εₙ = min(1,ρₙ+ηₙ)，内部提供这个条件。

给定原微观事件 E、原参考事件 F、`MeasurableSet F` 和 E ⊆ history(q)⁻¹(F)，最终风险仍使用原 Q、原 π、原 F 的参考事件概率。没有将 F 换成另一个有限模型中的事件，也没有删除任意 Y 所需的可测性条件。

**范围限制：**当前占据与风险端点仍要求有限 X、A，参考行仍为 PMF。它不是无限微观空间中“仅一个可达观察子集有限”的定理，也不涵盖任意非原子参考核。

## 4. 固定逐行样本量的真实注册实验

注册表 J 与响应类型 X 均有限；J、真实源行 Pⱼ、样本数 Nⱼ > 0、非负容差 ρⱼ ≥ 0 和微观失败事件在训练前固定。样本类型为 `∀ j, Fin (N j) → Ω → X`，真实实验的坐标类型为 `Σ j, Fin (N j)`；产品测度和坐标分布关系均由定义与证明给出。

校准只要求每一行内部样本在同一个训练律 μ 下独立，并且每个样本的真实边缘等于注册的 Pⱼ。不同注册行之间不需要另外假设独立。逐行预算按各自 Nⱼ 求和，不用最小或最大样本数替换：

\[
\alpha_N=\sum_{j\in J} 2\,|\mathcal P(X)|
             \exp(-2N_j\rho_j^2).
\]

有限 X 上所有事件的同时偏差控制给出真实源到经验律的 TV 条件；注册联合接口采用这些条件的 canonical 同时 Good 事件 G_N，并在同一 μ 下推出 μ(G_Nᶜ) ≤ α_N。

这不是数据依赖的停止规则或训练后决定的 Nⱼ。空注册表仅给出空校准预算，不会自动消除部署风险。采样层可用一般可测训练空间；当前选中训练—部署联合 PMF 端点仍使用有限 Ω。

## 5. 同一 Good、同一选中策略、同一次坏事件预算

选择器可以依赖全部训练数据，不要求有限候选类型。对每个 ω ∈ G_N，只要求其实际选中的候选满足以下条件：

- 同记录经验律对选中参考的拟合 `hfit`；
- 同一实际策略的未认证占据上界 `hcap`；
- 选中 F 的可测性 `hF` 和固定 E 的包络 `henvelope`；
- 同源参考事件风险加路径预算的数值检查 `hchecked`。

本接口不要求所有候选的全局包络，也不要求坏记录满足上述检查。真实注册校准先提供原源到经验律的误差；三角不等式和数据处理再提供实际原源到选中 Q 的认证行误差。原空间风险定理随后给出 Good 上的实际源风险，而不是要求调用者先假设该风险结论。

令 J 为真实训练后按所选模型部署得到的联合律。对 β ∈ [0,1]，有

\[
J(E)\le\min\bigl(1,\alpha_N+(1-\alpha_N)\beta\bigr).
\]

证明先以真实坏事件概率 p 写出 p+(1-p)β，再用 p≤α_N 和 1−β≥0。坏事件只计一次；α_N 不必预先限制为 ≤1，最外层 min 保留概率上界。

生存组合版本将实际部署策略固定为 `viableFamilyPolicy`。同一个 G_N 上，所有正概率初始观察纤维的有限时域可行性，通过此前已证定理推出这一个策略自己的零未认证占据，并在上述端点中取 κ=0。fallback 仍为显式输入；未引用另一策略的占据证书。

零未认证占据不等于零物理失败风险。参考事件风险和拟合误差仍然存在；有限时域可行性不等于无限存活；正概率历史上的真实后验支持身份也没有被扩成无条件身份。

## 6. 对统一结构与两部著作的作用

这批结果把已有真实支持生存与实际占据联系传到风险层，并把不等样本量及 Good 上的选中包络放进同一个真实训练—部署实验。新增来源等式由原核和策略构造并证明，作用超出将互不相关的证书并列。

MINCORE 的表示与可比较缺陷、H0 的实际动力学与评价条件、P-ID 适配及边界、TheoryCompletion 的具体来源接口仍各有不同责任。冻结 106 P-ID 的 11 generated / 89 adapters / 6 boundaries 分类没有因此改变；不声称全部由四个生成元自动重推导。

数学书分别记录有限表示保留何种比较、完整路径与终点的区别、固定样本数和选中 Good 的量词。哲学书从这些成熟区别发展关于对象描述、持续条件、目标理由和意义的独立论证，不把概率界当成经验世界、意识或伦理已被证明。

同一个四状态控制源的稳态、Cesàro、killed QSD、历史失败与受限最优性已有完整书面推导。独立研究分支随后实际通过了动作擦除来源桥和 K1 同源 killed 路径桥：从同一实际闭环的安全限制推出有限窗口联合存活／末态质量与总存活质量。它们仍是私有研究候选，没有加入当前七模块生产 import、native census 或本批 API 声明。一般条件律、QSD 特化与无限路径来源连接分别按其实际成熟度验收；两个独立 GOA 证书不能替代这些来源联系。
