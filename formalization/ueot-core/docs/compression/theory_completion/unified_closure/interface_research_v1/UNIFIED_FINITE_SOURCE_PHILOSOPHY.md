# 可以被保持的组织

本稿为下一版哲学书准备，尚未进入已发布的两部著作。它的有限实例来自实际 survivalMicroKernel 与 conflictRewardControl；具体命题、书面证明状态及所需附加输入见 [数学伴随稿](UNIFIED_FINITE_SOURCE_EXAMPLE.md) 和 [Lean 来源表](UNIFIED_FINITE_SOURCE_LEAN_MAP.md)。下列正文是一段独立哲学论证，代码对应关系留在伴随稿中。

## 一、论证提纲

### 1. 对象：有范围的准确性能够产生真实认识

问题是：为何某些差别可以舍去，另一些必须保留？

论证从同一个受控过程出发。若某种划分完整保存预先登记的属性及所有相关行动的响应，我们便能借助这个描述认识并干预过程。对描述范围的承诺使这种准确性可以检验。扩大任务可能要求细化划分，却不撤销前一任务中的正确认识。

本例的积极贡献是展示一个真实受约束的对象描述：四个微观状态压成两个运行状态，动作响应和奖励仍可准确追踪。进一步关于“哪个历史个体持续存在”的判断需要对象追踪和来源条件；行为等价本身不承担全部身份论证。

### 2. 持续：稳定关系可以通过活动被保持

问题是：一个有内部变化的存在者怎样维持某种秩序？

有限例中，内部位每步重新取值、允许变化，而特定动作使登记条件保持。稳定由动作、允许后继和后续可行动性共同解释。客体的持续因而可以包含内部更新；研究应找出哪些关系使它仍能实行所承诺的回应。

该贡献是一种构成性的解释路线：从条件、行动到后继支持说明“如何保持”。把它发展为生物体、制度或心灵的解释，仍须加入相应对象的真实机制和评价问题。

### 3. 目的：使可行未来形成可公开检验的排序

问题是：同一动力学为什么可以支持不同的行动目标？

在这个例子里，纯奖励评价与保持运行的约束导出不同的最优策略。由此可把目的分成已说明的评价、可接受行动域以及实现这些要求的机制。目的论有了可以事先声明、据行动后果检查的内容。

任务给定后，最优控制能提供严格结论。为何选择这一任务、为何让某些限制优先，需要进一步理由。这个区分为目的论增加了说明义务，也保护了它的实质内容。

### 4. 修复：恢复未来能力，同时保留已经发生的历史

问题是：修复究竟使什么重新成立？

同一个保全动作也可把失效状态带回运行条件。若进一步描述程序损坏和重构，还可以说明恢复能力自身依赖怎样的组织。恢复后的功能和已经发生的损失分别有真实意义；终点状态没有包含全部历史评价。

本例的积极贡献是把修复理解为重新打开某些可行动未来。程序、编码、可信执行器和故障范围则具体说明这种能力从何而来。

### 5. 意义：自然条件为承诺提供实行场所，理由决定其价值

问题是：组织、持续和目的对意义的理解提供了什么？

一个承诺要在世界中发生作用，需要对象和行动的具体实现条件。对于需要持续履行的承诺，保持与修复进一步提供实行和延续的能力。有限例可以展示这些关系的一部分；一次性的行动或不可逆的承诺也可能有意义，其价值并不以可以修复为前提。意义的规范内容还须讨论谁的关切、谁承受后果、目的是否值得追求，以及受到影响的人能否要求理由。

由此得到的是积极的自然哲学方向：使意义的实现条件更具体，同时让意义的价值理由继续接受哲学讨论。

## 二、可直接融入下一版的完整论证片段

### 可以被保持的组织

设想一个极小的装置。我们登记一项运行条件，用一个可见位表示它是否成立。装置还有一个内部位，每次动作之后，它都可能取两个不同的值。装置可以实行两种动作：一种使下一时刻满足运行条件，另一种使下一时刻失去该条件。整个模型由四个微观状态组成，动作对状态的影响已经完整说明。它足够小，可以让我们把关于客体、持续和目的的几个问题放在同一过程里考察。

首先，我们可以只记录装置是否满足运行条件。这个描述只有两个状态，却保留了每一种动作对登记条件的全部影响。内部位虽然可以变化，舍去它并不妨碍我们回答已经提出的问题。我们因此获得一种认识上的能力：用较少的区分，仍准确知道哪些行动会保持装置的运行，哪些行动会中断它。描述的简洁在这里有严格的依据，也有明确的用途。

这种依据来自描述所保留的关系。若我们后来要求同时知道内部位的当前值，原先两个状态的描述就需要细化。问题扩大了，准确回答问题所需的区分也增加了。这说明一个客体描述可以既相对于任务，又受到世界的约束。任务决定哪些问题必须得到回答，过程本身决定某种划分是否确实保存这些回答。我们不能随意合并会在相关行动下产生不同后果的状态；也无需为了知道一件事而保存与该问题无关的一切细节。

从这里可以发展一种有分寸的客体实在论。一个客体之所以值得被单独描述，是因为某些区分能够贯穿我们对它的观察与行动，使我们持续回答关于它的问题。客体的边界因而可以成为研究所得的结果：哪些条件共同支持某项能力，哪些变化会改变这项能力，哪些内部变化可以容许。这样的边界有待检验，也能够随着研究深化而变得更准确。它给予我们进入世界的具体方式，而不是一张预先完成的万物分类表。

行为描述的准确性还留下另一个问题。两台装置可能有相同的动作响应，却有各自不同的制造与使用历史。上述压缩告诉我们它们在登记问题上怎样等价；追踪“这一台装置”还需要沿实际因果历史继续辨认。这样，角色与历史可以相互支持：角色说明我们在追踪什么能力，历史说明这项能力通过哪些具体变化延续。对象理论向前推进的方向，是把这两种说明接起来，并明确每一种说明承担的部分。

再看持续。假如我们不断实行保全动作，运行条件可以一直成立，内部位则每步重新取值，既可能改变，也可能保持原值。稳定因此具有活动的形式：我们允许内部状态更新，同时保持某项能够继续实行的回应。对这个极小系统来说，持续的机制可以逐步写出：当前条件允许一个动作，该动作的所有可能后继仍满足条件，于是下一步仍有相同的可实行回应。持续不是只由当前一张状态照片表达的性质；它还包含当前状态通向未来的方式。

这一观点使“保持”获得了正面的解释内容。我们不再只给一个系统贴上稳定的标签，而是寻找使其保持的行动与关系。若某一步只能暂时满足条件，却同时耗尽下一步的全部可能，那就需要另一种持续判断。我们的极小装置恰好没有这样的死路，保全动作始终可用；这使它容易理解，也限制了它能说明的范围。更丰富的生命和社会过程需要把资源、损耗、环境改变以及新的行动能力逐项加入。每加入一项，持续的解释都应随之增加实际内容。

目的从哪里进入这个过程？现在给两种动作一个公开的评分：每次选择使运行条件失去的动作得一分，选择保全动作得零分。再把较晚的得分按固定比例折减。如果唯一任务是最大化得分，装置应不断选择前一种动作。如果任务还要求从可行状态出发始终保持运行条件，允许的行动就只剩后一种。两种结论都可以从同一转移规律准确推出。

这并不使目的变得空泛。恰恰相反，目的的内容变得可以辨认：我们提出什么评价，哪些后果可被接受，以什么机制实行相应行动，以及不同要求发生冲突时如何处理。只要这些内容在比较行动之前说清楚，评价便能接受反事实检验。一个声称重视持续的安排，若始终选择会中断持续的行动，就需要解释这一偏离；一个只追求即时得分的安排，也不能因为得分高便自动取得关于持续的赞誉。

数学能够在给定问题内判断哪些行动最好，但目的的理由仍需继续讨论。维持某个组织是否值得，取决于这个组织做什么、对谁产生影响，以及其他可能性会被怎样改变。把保持运行列为约束，本身是一项有内容的决定。统一的理论应使这种决定更容易被看见：它如何改变可接受行动、付出什么代价、保留什么能力。这样的清楚性让目的论能够进入共同讨论，也让不同目的之间的冲突有了可以分析的形状。

修复把这个问题向前推进了一步。在极小装置里，即使运行条件已经失去，实行一次保全动作仍会使它重新成立。于是同一个动作既能维持，也能恢复。我们由此看见恢复的一个积极意义：它重新打开了原本已经中断的行动未来。装置再度具备符合登记条件的回应能力，后续的保持也再次成为可能。

然而，恢复发生之后，之前的中断仍然属于这段历史。如果只看第二步结束时的装置，我们可能看见它已经运行；若问前两步是否曾经失效，就会得到另一个答案。两种问题各有价值。当前能力关乎下一步还能做什么，发生过的中断关乎已经付出的代价、错过的机会以及需要承担的责任。一个恰当的修复观应同时容纳这两者。恢复的成功使未来重新开放，忠实记录过去则使这份开放保持真实。

在人与共同体的生活中，这一分别也有启发性。重新履行一项曾经中断的承诺具有实际价值，因为新的行动再次支持了某种关系。与此同时，过去的中断可能仍需要说明、补偿或重新建立信任。我们可以承认修复所取得的进展，同时继续评价此前的经历。这里的哲学重点，是让恢复的希望与历史的责任共同存在。

若进一步询问装置凭什么能修复，我们就必须打开它的组织。假定保全指令保存在三个副本里，损坏范围只允许其中一个副本出错，还有一个能正确解释指令的执行结构。这样的组织可以先恢复正确指令，再由恢复后的指令作用于装置。第一阶段修复程序，第二阶段才改变装置的运行状态。恢复能力于是有了可以检查的来源：副本之间的关系、读取与解释的能力、允许的故障范围以及操作的先后次序。可信执行结构依然是输入；若它也可能损坏，理论还须继续说明相应条件。

这个分析有助于理解组织的脆弱性。能够修复某种损坏，意味着系统拥有应对这一损坏的具体关系。知道这些关系，才知道能力何时可以继续、何时需要外部帮助，以及进一步增强恢复能力应从哪里着手。把条件写明并不会减损修复的价值；它使价值有了可以依赖的机制，也使我们的期待有了更准确的尺度。

学习与风险要求同样的清楚性。假定无论此前出现什么历史，装置下一步选择中断运行动作的条件概率都固定为八分之一，那么两步之内曾经中断的概率是十五分之六十四。仅知道两个时刻各自的边际概率都是八分之一，还不能得到这个两步结论。这个风险来自装置自己的行动和转移过程。另一个总会保持运行的模型可以作为比较，但它与真实行动响应之间的差别必须计入判断。更精确的模型则会完整保留两种动作的后果，从而准确预测这一失败概率。

因此，一个完全准确的描述也可能告诉我们：当前行动安排会失败。准确性带来的积极成果，是使后果可以被认识、比较和修订。它给改进行动提供依据。我们若希望减少失败，就需要改变所选行动、增强装置能力，或者重新考虑所提出的任务；仅仅增加关于同一不利行为的准确知识，不会自行改变它的后果。

这些关系与意义有何关联？对于需要持续履行的承诺，辨认所关切的对象、理解哪些变化会损害它、保持可实行的回应，以及在中断后寻找恢复途径，都能具体支持承诺的延续。这类承诺关切的还包括某些关系能够继续、某些可能性仍然开放。对象、行动和持续在这里获得了共同的方向，使关切有一个可以具体实现的场所。与此同时，一次性的行动或不可逆的承诺也可能有意义；其价值不能由持续或修复能力单独判定。

但何种承诺值得承担，仍然是哲学的问题。某个安排即使善于自我维持，也可能损害他人的生活；一个目标即使可以高效实现，也可能缺乏可以向受影响者说明的理由。意义的理解因而需要把实现条件与价值理由联结起来。前者使我们知道承诺怎样进入自然与社会过程，后者要求我们讨论谁的关切应被听见、怎样分担代价、何时应当修订甚至放弃既有目的。

这是一条能够继续发展的统一道路。我们从有限过程里找出可准确描述的客体，从实际后果里找出保持与修复的条件，再把这些能力放回目的与理由的讨论。世界的组织使某些承诺能够实行，反思又使我们能够评价这些承诺，并调整自己的行动。统一的进步体现在这些关系变得更具体、更可检验，也更能承担我们对真理与共同生活的要求。

## 三、融入现行两部著作的建议

数学书最值得新增的是同一实际源上的精确风险与两个参考模型对照。可在下一次修订 §35 的有限实例时固定本稿的唯一 P，并在 §36 的实际覆盖及 §37 的正概率支持处回访它。这样能把较早的可行控制、程序安全桥与本轮支持/风险模块连接为一个可以逐步核对的论证。现有 §35.4 的另一个书面核可以保留为独立例，或在实质修订时明确替换，不能悄悄混用数值。

哲学书宜将以上论证分段融入原有思想发展，不另开一个 Lean 成果目录：

- 第四章“Ω：组织如何维持自己的条件”吸收对象划分与活动中的持续。
- 第七章“修复、生命与自创生”吸收恢复未来能力、修复历史与组织机制的分别。
- 第九章“可能性先于最优性”和第十一章“目的从哪里进入自然”吸收同一源上不同评价与行动约束的冲突。
- 第十章“学习必须回到行动所处的世界”吸收准确模型仍能预测真实失败的论证。
- 第二十四章“意义来自怎样的承诺”吸收实现条件与价值理由的联结，并由第二十五章继续讨论公共理由。

其中最值得优先纳入的是“恢复使未来重新开放，但终点不包含全部历史评价”与“准确性让行动后果可修订”这两段连续论证。它们从成熟数学得到新的正面内容，又能自然接入本书关于持续、责任和承诺的既有问题。
