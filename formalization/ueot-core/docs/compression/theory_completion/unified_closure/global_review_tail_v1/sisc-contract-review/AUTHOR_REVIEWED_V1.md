## 2. 可落地的 SISC 逐探针实验合同

### 2.1 已有内容与新接口的差别

现有 `SISCInterventionSamplingPower.lean` 明确假设独立重复单位，每个单位的记录 `Z` 提供全部探针 `outcome : Probe → Z → ℝ`。源码已经警告普通一次一个处理的实验不自动满足此条件。该定理本身正确；问题在于怎样为另一种合法实验给适配器。

现有 N3 构造候选集合，N4 先估计坐标均值再求候选风险，并证明统一校准与间隔功效。现有生产 `N_j` 注册采样已经给出固定逐行样本的真实坐标。下一接口应把这些已成熟部分接起来，而不是再假设最终的“正确识别概率”或重写 Hoeffding 证明。

### 2.2 第一版准确命题草案：固定有限实验

取有限探针集 J、有限样本值域 X、有限候选/亲本集 C。训练前固定每个 j 的真实 PMF ν_j、正整数 N_j，以及有界读数 g_j:X→[0,1]。在同一个概率实验 μ 中，行 j 的样本 X_{j,1},…,X_{j,N_j} 为 ν_j 的独立同分布样本。**行间独立不为并合界所必需**；若现有构造以乘积实验实现，则该构造的更强独立性仍如实说明。

给训练前固定 u≥0，定义

\[
m_j=E_{\nu_j}g_j,\qquad
\widehat m_j=\frac1{N_j}\sum_{k<N_j}g_j(X_{j,k}),
\]

\[
G=\{\forall j,\ |\widehat m_j-m_j|\le u\},\qquad
\alpha_N=\sum_{j\in J}2e^{-2N_ju^2}.
\]

目标先由现有逐行集中与并合界得 μ(Gᶜ)≤min(1,α_N)。每个实验单位只需其所属探针的实际输出；无须在同一单位观察其它处理的反事实输出。这里的 μ、样本边缘和估计器必须实际构造并绑定，不能仅提供一个无来源的 Good 概率假设。

对注册参考向量 R_c，令

\[
L(c)=\sum_j|m_j-R_c(j)|,\qquad
\widehat L(c)=\sum_j|\widehat m_j-R_c(j)|,\quad r=|J|u.
\]

复用 `finite_absolute_response_risk_lipschitz` 的反三角论证，在同一 G 上对所有候选同时有 |L̂(c)−L(c)|≤r。由现有 N3/N4 决策：真实候选注册且满足因果 admissibility、L(c)+2r≤τ，而所有其它注册且 admissible 候选满足 τ+2r<L(d) 时，输出唯一 c。这里“唯一输出”是注册模型族中的结论，不是现实对象的无条件唯一性。

对于 N6，先保留当前统一容差 u：真实源 c 注册、有独立认证的 `authenticatedTransfer c child`，且每行真实均值 m_j 恰与 c 的参考响应匹配；所有竞争者有某一探针的响应差大于 2u。于是同一 G 上审计候选集合为 {c}，失败概率不超过 α_N。候选集合的**构造不输入正确 c**；c 只出现在正确性与功效定理中。被识别的仍是满足独立来源合同的模型类。

逐探针不同容差 u_j 的更精细版本可随后给出；现有 N6 的统一容差接口不能在文字中直接改成已支持任意向量。固定 N_j 也不变成随机停止样本量。

### 2.3 必须先处理的四个失败点

1. **实验不匹配。** 探针名称相同不保证 ν_j 等于实际干预律；模型匹配要来自实际干预适配，而非从拟合成功反推。
2. **谱系来源不足。** 主动响应分离与转移认证缺一不可；核的完整知识甚至完整状态路径仍不能单独生成真实亲本关系。
3. **均值与损失混淆。** E|Y−R| 一般不等于 |EY−R|。先估计均值是当前成熟证明的必要步骤，不得为了复用某个 loss 接口改掉问题。
4. **后验选样或选模型。** 预先注册的共同 Good 可以支持数据选择；训练后新增未校准探针、依结果决定 N_j、或改变同一参考模型，均需要新的合法接口。若再接部署风险，仍须证明条件未来核与同一实验来源吻合。

以上为**新合同草案**，本回顾没有编写或编译该适配器。

### M1：§34.6，C2段后（当前行4119）

精确锚点：`**C2：有漂移的三值决策。**` 段落之后。

**拟加入：**

> 科学候选决策还包含比单一区间更强的正向连接。给注册候选 c 的参考响应向量 R_c，真实均值 m 与样本均值 m̂，候选风险取 L(c)=Σ_j|m_j−R_c(j)|。反三角不等式给 |L̂(c)−L(c)|≤Σ_j|m̂_j−m_j|，因此一份共同坐标 Good 事件可以同时校准所有候选，不按候选标签重复计算统计失败。注册且因果合法的未拒绝候选集合若是单点，并且该点已经认证，决策器返回 unique；无未拒绝候选返回 uncovered，其余返回 ambiguous。相对于半径 r，真实候选满足 L(c)+2r≤τ、其它注册合法候选满足 τ+2r<L(d) 时，共同 Good 进一步推出唯一识别。样本均值与实际源的匹配、独立重复单位和界限仍须明示；uncovered 只表示当前注册模型族没有受支持候选，不表示现实中没有对象。

## 4. 哲学书下次实质修订：概念澄清与论证深化

哲学第14章对稳态、条件生存、真实持续、选择偏差与最优的区分已经充分吸收数学内容。本次尾端点的 PASS 不要求向该章添加状态报告。已有第11章也明确反驳“目的必然只是观察者投射”，以下建议不是假装这个论证此前缺席。

### P1：第11章第2段的目的归属范围（当前行219）

原段以“某些差别被当作成功或失败”进入目的。后文已有功能、形成史、意向和共同承诺四层，建议在该四层段之后加一段，明确这些是不同归属根据而非程度不同的同一个标量：

> 四种根据也允许我们区分目的解释的强弱。一个被动的恢复力可以使偏离缩小，却未必建立了需要由它自身维持的成功条件。调节若参与保存一个组织继续活动的条件，功能解释便获得构成上的根据；若某种作用说明了该机制怎样被保留，形成史又给出另一种根据。行动者能够为所追求的结果提供并修订理由时，目的还包含可以归责的立场。我们不能仅凭“出现反馈”就越过这些差别，也不能因某种功能有形成史，便认定它今天仍值得维持。

这段将既有论证进一步落实为可反对、可辩护的条件，**不是**为所有生命或一切反馈系统断言一个唯一内在目的。资源与表现的条件排序可作为数学背景，正文无须插入 Lean 名称。

### P2：第24章第2段后的定义范围（当前行465）

原句：`本书把意义理解为这样一种关系：行动者能够把自己的活动理解为参与某种值得关切的事物，并使这种参与在生活历史中取得位置。`

**建议最小澄清段：**

> 这里首先讨论的是能够反思自身活动的行动者所形成的实践意义，不是把理解和叙述能力设为一切生命具有分量的门槛。一个不能讲述自己历史的人，仍可以承受痛苦、享受关系，并成为他人不可替代的关切对象。意义之于行动者的体验、一个生命对他人的意义，以及这个生命本身值得怎样对待，是相互联系却不同的问题。反思可以改变前一种联系，却不能单独决定后两者。

这是范围澄清，不是声称现书否认弱势者价值。第23、25章已有相应的尊重和规范理由；补句使第24章定义与其更直接一致。

### P3：下一阶段要正面推进的两至三个问题

1. **跨协议的客体客观性。** 第2章行59的森林例、第3章边界与第17章类型层级已经表明问题相对不等于任意。下一步可问：不同协议怎样共同约束一个对象归属？何时应承认多个都准确但不等价的对象描述，而非强求唯一“最真实”划分？这需要兼容的干预后果、形成史与域外失败条件，不是重复“模型有条件”。
2. **恢复什么，为什么值得恢复。** 第5、7、11、14章分别论身份、修复、目的和持续。下一步用一个具体冲突贯通它们：恢复功能是否恢复同一承诺？可替换的实现、不可抹去的损害、可以转交的责任各是什么？预测等价或重新稳态不能单独回答，但真实约束能排除不可能的解释。
3. **何时应结束一个有意义的承诺。** 第24–25章已有可修订性与公共理由。进一步比较修复、转交、退出三种选择：维持原计划若持续使他人受害，何以结束不等于背叛？有限性使承诺具体，但长期持续自身并不给出继续的理由。该问题需要哲学论证与具体案例，不需要把伦理选择编码成一个未经辩护的奖励函数。
