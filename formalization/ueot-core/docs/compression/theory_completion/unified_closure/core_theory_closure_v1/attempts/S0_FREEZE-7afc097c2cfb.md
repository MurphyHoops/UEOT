# 核心声明与同源合同冻结

本轮：UEOT Core 定本，2026-11-06。原作者：钱德桂（Degui Qian）。实际基线为 PR443 后 main `d67eda06bc4509ba5fd653fab73cff5713fddc2e`；不回退审查 SHA。原全 Core 条件合同、PR441—443 的完成状态保持。本文冻结新源的权限与物理语义；后续结论必须接受此源的成功与失败，不能为结论改源。

## 核心声明（S0）

UEOT 本版讨论对象、组织、允许行动、传递与演化之间的结构关系。对象是相对于能力、观察与未来试验辨认的结构；组织再生是其中一个更强分支，要求自身过程实际恢复执行条件。二者不等同。具有现实存在条件，不推出任意允许干预族内必有非空失效族 Ω。

本轮将完成的正类是有限、开放供给、带非零噪声的可再生组织。原始输入只有物理位、读写和执行规则、噪声参数、初态和账本。实际修复、行为差别、允许行、续存/新生名单、忠实传递、均值算子、增长排序和反馈由源导出。先验成功证书、fitness、条件均值、Perron 数据和最优程序均不作为来源输入。

同一组织的程序编码与主执行门可以损坏。有限可信底座是多数读取、收费写位和收费开门的规则；它不保存正确程序答案。可靠性只覆盖规定的单活动位损伤，不覆盖全信息擦除、全部启动路径毁坏或任意灾难。修复恢复的是本 tick 的执行能力，不能称为最终永久健康。

本轮增长目的来自实际下一次普查贡献的长期期望。它与存活、实际人口比例、加权谱系、给定折扣收益 J、意图和规范价值分别讨论。增长最优只是 UEOT 的一个来源分支，不是全部目的理论。有限控制存在不代替真实继承选择；有利程序仍可能先灭绝，初始支持外的程序不会因忠实复制自动出现。

一般 Perron 行优化仅在信息充分、每行可组合且继续动作算子本原时成立；本源须逐项满足。停止与拒绝保持实际语义，并扩入完整请求菜单。固定程序身体块本原不使忠实多程序总矩阵本原。统计加权谱系核不自动成为原控制器可实施的动作核。

合法表示相容须保持观察、动作、付款、身份及带标记后继的联合记录。只保留一个预测读出或一阶矩，不能据此宣称修复、选择和最优值全部不变。原二维 Π/Φ、唯一吸引子和自然普适最优等强版本按现有反例与条件定理公开修订；规范与主体问题由独立哲学论证承担。

结束条件是 S0—S6 七项真实出口、两书可独立阅读、公开源和验证、发行与原 GI 接续。经验普适支持保持 **UNVERIFIED**。未解决的核心正命题必须写 **UNRESOLVED**，不能用接口包装或撤回全部正命题完成任务。

## 单一来源合同（S1）

**身体与程序。** 身体有 H/D 两行，每行三个布尔位（活动位和两个备份），主执行门、有限可信 bootstrap 和一个不可观察的无效物理标签。每行三位同值编码动作；0=care，1=bloom。两个遗传程序为 θ0=(care,care)、θ1=(bloom,care)。损伤翻转每行活动位并关闭主门。内部程序先读取本次损伤诊断，按多数码申请资源；收费恢复后由真实活动位在原诊断行执行。外部请求端口允许同样的 care、bloom、stop，使用同一恢复与事务规则。控制器只读声明的物理诊断及允许历史，不读 θ 标签、未来噪声、审计身份或不可见标签。

**资源。** 每个普查旧体带 1 单位资本，环境显式流入 5 单位。每修正一位或开启主门收费 1；care 操作收费 1，bloom 收费 2；每个实际续存体与新生体各获 1 单位，均从同一 6 单位扣除。读噪声前预留至多两个输出资本。H/care、H/bloom、D/care、D/bloom 的请求上限分别为 3、4、6、7；故 D/bloom 被拒绝。拒绝不读取噪声，旧体和旧钱包不变，退还 5；stop 输出空人口并退还 6。余款和死亡余款均归环境。有限初始 n 体至 T 的供给不超过 5n(2^T−1)，另有 n 初始资本。无限期增长依赖开放输入，不能声称来自封闭有限钱包。

**原始噪声。** 存活类别概率为 (1−s,δ,s−δ)，分别为都不留存、只有 care 留存、二动作都留存；出生类别为 (1−b−γ,γ,b)，分别为都无新生、只有 bloom 新生、二动作都新生。每个实际输出独立以 q 损伤。三个类别及两个损伤位形成 36 个有限原子；当前噪声与允许过去及私随机独立。公开正参数区间为 0<δ<s<1、0<b、b+γ<1、δ<γ、0<q<1、s+b>1。独立 cohort 使用独立原子和各自真实环境账本；同一源条件期望上界不额外依赖同代个体独立。

**身份与时钟。** 全人口普查每个旧体仅处理一次；新生下 tick 才执行。续存保留身份、真实出生时刻及父指针；新生取得不同新身份并指向真实父体。永久身份与有限身体类型分开。L 计同体续存，B 计新身份出生，M=L+B，包含死亡和零贡献，不条件于成功。本源是明确的新人口普查时钟，不冒称旧 Register 串行 dispatch 的保守扩展。

**冻结前发现的边界。** 亚临界时拒绝保留可优于继续，故不排除拒绝来保存最优性；正类显式要求 s+b>1，并对拒绝的单位行证明同一潜势上界。原型保留 s=1/4、δ=1/8、b=1/8、γ=3/16、q=1/3 时 D 继续均值 3/8、拒绝均值 1 的反例。可信 bootstrap 被切断、资源不足、全码擦除、把局部钱包改成共享总钱包，均为已测试的失败边界。
