## 2. 分类闭合所保留的实质

本版不是撤回全部正向内容后只留下反例。声明类保留非零死亡、出生与损伤噪声、真实可损坏代码和支撑部件、付费恢复、真实资源约束、实际个体与后代身份。成功、忠实传递、条件均值和最优性由源消费者履行，不作为未证明的源输入返还。

原始参数为 `p=(s,δ,b,γ,q)`，正类公开要求 `0<δ<s<1`、`0<b`、`b+γ<1`、`δ<γ`、`0<q<1`、`s+b>1`，并有真实有理点证明非空。每个旧成员的一单位资本与五单位环境供给独立登记；长期增长不从有限封闭钱包产生。局部恢复先于后续存活／出生噪声，故恢复成功不消除灭绝事件。

同程序共同见证从受损 θ1 出发：支付三单位恢复，读取恢复后的码执行 care，以后健康时仍由同一程序执行 bloom。S4 的两健康创始体 cohort 是另行声明的同源消费者，不把其初态或资源冒充这一损坏共同见证。一般最大根选择与实际执行的已编码程序也分别说明。

谱系 Q 是生殖价值加权的统计律，不能直接取得原动作的实现权限。表示相容证明保持完整实际记录和允许历史；标签展开矩阵有忠实分块，不因商块本原而自动本原或具有唯一正射线。

主体经验、意义、理由与规范由哲学书给独立正面论证、反对与回应。增长优势不推出道德正当性；公开合成源中的形式及实现证据不确认自然普适性。这些范围是结题内容，不能改成未说明的普遍强版。

后继发布与接续回执必须同时具有以下证据，不能只证明其中一项：

- **真实发行与远端读回。** 记录实际候选／发布 commit、tree、PR 或等价正常发行身份，及所采用分支；从实际发布对象读取交付清单各文件的 SHA256 与字节数，核其与已审采用版本一致。只有本地 commit 或一次 push 不替代发行采用与远端字节核对。
- **工作区采用。** 记录实际采用后的 HEAD／tree、分支、工作区与必要进程状态；已保留的缓存、历史失败和其他未提交内容按事实说明，不将它们清除来制造“完成”。
