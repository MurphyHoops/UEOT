# UEOT Core 定本：核心主张终态与强版修订

本表对应[原始总纲](MASTER_PLAN.md)§3、S0—S6 与七项出口。总纲是保留历史状态的范围基准，当前实际验收见 [FINAL_ACCEPTANCE.md](FINAL_ACCEPTANCE.md)。它登记内容终态，不以“统一接口已存在”代替实际来源，也不由文件数量推断闭合。

**数学／内容判定为 `CLASSIFIED_CORE_CLOSED`。** 保留的正向主张在非空、参数化、含噪声且受真实约束的源类中有条件结论；部分原普遍主张经反例收窄。发行、公共构建与原 GI 的事实状态必须由实际回执另行确认，不能由此标签推断全部交付操作已完成。经验支持始终为 **`UNVERIFIED`**。

| 精确反例／不可识别 | 强断言在保留语义下失败，反例或同输入不可辨识给出失败原因。 |

## 3. 原强版的公开修订与阻止偷换的反例

| 原强表达／容易误读的推论 | 保留的准确版本与反例 |
|---|---|
| 持续存在必有该操作族中的非空 Ω | Ω 依赖声明能力及允许操作。q(x,u)=x 非恒定而 cut 只改 u 时，允许操作不破坏该能力；不是把对象恒定化得到的空例。 |
| 自创生意味着任意毁损后都能恢复 | 正类保留多数信息和可信 bootstrap，并足额支付。切断 bootstrap、修复阶段固定余额不足且不再追加供给、全码信息擦除均有不可恢复边界。 |
| 恢复成功意味着零死亡或最终永久健康 | 恢复在噪声之前完成。随后真实死亡与零输出仍发生；局部执行恢复与人口存续不是同一命题。 |
| 恢复与增长的各自证书可以随意拼接 | 新正见证须同一程序、同一损坏初态与同一六单位账本。反馈使用同源但另外登记的两健康创始体 cohort，不能把其资源或初态冒充共同见证。 |
| 增长最大化就是所有意义的生存最大化 | 同一健康体 care 的原身份一步续存率 s 严格大于 bloom 的 s−δ，而 θ1 在健康时选择 bloom 增长期望人口。未比较无限谱系生存最优。 |
| stop／拒绝可以为谱优化忽略 | stop 为零行，拒绝保留原体为单位行，均进入全请求上界。亚临界点 (1/4,1/8,1/8,3/16,1/3) 的 D/care 下一步均值 3/8，拒绝为 1；不得改拒绝为死亡挽救结论。 |
| 每行各自最优就总能组合为全局策略 | 行替换要求允许观察能区分行、请求可实施且资源约束可组合。本源各体独立钱包满足此条件；共享总钱包不是无条件可替换的同一合同。 |
| 忠实遗传的整体矩阵必为 primitive | 固定程序的 H/D 身体块严格正；多程序及无效 tag 忠实携带，扩大矩阵按遗传块可约。只对正确块调用 Perron 工厂。 |
| 最高增长程序在固定有限人口中必然胜出 | 它首期全灭且低程序仍非零的概率在固定点为 243/2048；正反馈结果是先 T 后 n 的有限概率界。没有证明低程序永久存活。 |
| E[实际比例]等于期望计数之比 | 同一两创始体首期的零扩展期望 2095/4096、非零条件期望 2095/4006、期望计数比 10/19 互不相同。 |
| 归一化均值、典型谱系与允许控制核相同 | 普通均值身体组成是 (2/3,1/3)，加权谱系为 (20/29,9/29)。Q 可实施须另过原凸包／观察纤维判别，不因定义为行随机核而自动获得动作权限。 |
| 预测等价足以保持修复、成本与最优性 | 删除 H/D 丢失 bloom 的可支付性；只保留解码内容而删除主门丢失 rawExecute 的执行能力。本源合法商只删无效 tag，保持完整联合记录。 |
| 自然动力学普遍二维、目标或吸引子唯一 | 保留 C5 的低秩／锚定条件和各 GOA 条件类；不把任意动力学归入二维或普遍唯一极限。 |
| 增长优势产生道德正当性 | 撤回该推论。痛苦、能力、理由一致性、相互承认和公共可修订性需要独立规范辩护；机制事实约束其可行性，却不能代替理由。 |

这些边界保留真实失败、资源、观察和遗传语义。新正类添加的公开条件是可检验的适用范围，不是改变失败事件、删除比较动作或免费补资源。

## 6. 采用规则与结束边界

本版选择 `CLASSIFIED_CORE_CLOSED`，因为原强版存在公开修订，而保留的组织、排序、控制、反馈和相容性正类仍有实际解释内容。不是撤回全部新正向主张之后只留下反例。

数学书可独立阅读同源定义、条件、论证与边界；哲学书独立讨论协议相对而非任意的对象、维护与一般依赖、功能与意图、增长与规范、有限可信底座及非零死亡。两书不能靠相互援引免除各自证明或理由责任。

本表登记的是数学／内容判定。若最终形式或运行验收发现仍保留的核心正命题存在实质缺口，应准确改为 `UNRESOLVED` 并说明，不允许以“待发布”掩盖研究阻塞。反过来，形式化以外明确排除的更强领域，也不自动扩大本轮退出条件。

完成七项实际出口后停止自动扩题。经验状态保持 `UNVERIFIED`；新领域、一般生态、更强无限时域选择、无限创新、通用意识理论或绝对价值公理均需独立决定。
