## 4. S4：实际反馈及其边界

分离子审确认：`treeMean_program_recurrence` 和 `treeMean_program_succ` 从真实 `programStep` 和噪声树给均值；`actual_cohort_feedback` 包含零人口失败；`exists_finite_cohort_selection` 在自身证明内部先取有限 T，再依据真实二阶矩取 n。中间的 hmean 不是最终消费者重新裸给的来源前提。

保留范围为两个忠实程序，每个 cohort 各一健康创始者，声明的局部独立噪声与跨 cohort 独立性，以及真实开放供给。n 个 cohort 是 2n 个创始体，资源上界为 `n[2+10(2^T−1)]`。当前数学总论明确该范围，不宣传任意程序族／并列最大块的新定理。

`reachable_program` 对任意 θ 成立，足以保留初始支持缺失时不能创造新程序的边界。最高增长程序先灭绝、共同零人口以及 E[比例] 与期望计数之比不同的同源反例均已存在。固定有限群体在无限时间必然选优不属于结论。无需新增 S4 Lean 模块或一般 branching 极限平台。

## 5. S5：同程序恢复与增长，及完整有限历史相容

S5 并非仅给一份繁殖程序。证明链是：

1. `programStep_uses_paid_repair`：内部程序实际输出和收费来自同一修复阶段；
2. `best_step_is_programStep`、`attaining_generation_is_internal`：达到请求的整代执行等于物理 true 程序内部执行；
3. `generation_program`、`reachable_program`：后继继续携带同一码，未把较差程序替换成优化标签；
4. `bestPolicy_positive_branch_is_internal`：最优允许历史核的正概率分支确实执行上述内部程序；
5. `same_program_regenerates_and_attains`：同一 θ1、损坏 founder 和六单位账本，恢复后执行 care，随后健康时执行 bloom，并达到期望人口增长界。

这里不需要另以 π_repair 和 π_growth 互不相关的证书拼接结论；正向共同见证在整个 Valid 参数类内成立。恢复与增长的共同见证使用一个损坏 founder，反馈定理则使用同源但另行登记的两健康 founder cohort。书稿已区分这两种初态与资源规模。

`step_joint_record_commutes` 是同一噪声原子下的完整收据交换。`generation_eraseMember`、`branchWeight_eraseState`、`next_eraseState`、`populationExpectation_eraseState` 随后给真实人口状态／分支、同一 Policy 及任意有限时域测试的推前。`attainable_test_values_eraseState` 给同一完整策略集合的可达值等价，并非只给单向策略提升。付款历史和 census 测试有直接消费者。

合法商仅删除静默、不可观察的 tag，保留真实身份和祖先标记。扩展 tag 矩阵按忠实块可约，书稿没有把它错说成本原。删除 H/D 可支付性区别或主执行门的反例限制了非法预测压缩。无需新建任意尺度、无限路径或谱稳定平台。
