# S4 独立语义审查

**结论：在准确声明的来源类内，未发现阻断 S4 结题的数学缺口。** 本意见是源码语义审查，不是新编译或内核验收回执。所读六个相关文件均与当前 fresh 副本逐字节相同；两书正文及七出口总装由父审查者继续核验。

## 已经具备的正向结果

`CoreRegenerativeSource.Valid` 给出严格不等式定义的非空概率参数类；损坏概率在 0 与 1 之间，36 个实际噪声原子权重均为正。`programStep` 读取真实程序，执行付费修复和允许行动，输出 retained/newborn 两个实际后继槽。`treeCount` 递归执行这些槽，死亡按 none 计零；新生下一 tick 才行动。

`treeMean_program_recurrence` 和 `treeMean_program_succ` 从这些执行与原始概率权重推出矩与各时域均值；未把 fitness 或条件均值作为未履行来源输入。`descendants_length` 将计数与真实身份和父指针记录列表相联。

`lower_mean_share_tendsto_zero` 是归一化期望程序数量的集中。`actual_cohort_feedback` 则对独立完整 cohort 给真实随机份额的有限时域概率界，明确把总人口为零列入坏事件。`cohort_variances_bounded` 用每个个体最多两个后继的有限界取得二阶矩。最终 `exists_finite_cohort_selection` 在证明内部先选 T，再按实际矩选 n；中间 `hmean` 被自身来源结果履行，不是重新输入成功条件。

## 边界与最小复用

- `reachable_program` 对任意 theta 和公共请求历史保持程序编码；取 theta=false 已足够说明没有 true 程序的群体不会自行发明它，不需要再建支持平台。
- 同源两创始者的实际一步计数证明：最佳增长程序灭绝而较差程序仍非空的概率为 243/2048，总人口灭绝概率为 45/2048。
- 实际比例的零延拓均值为 2095/4096；非零人口条件下为 2095/4006；期望计数之比为 10/19。三个量须分开。审查者用九个计数结果作了独立 Fraction 算术复核，未将其冒称 Lean 编译。
- `actual_sample_resource_bound` 保留 n 个 cohort 的实际资源扩张：每 cohort 两单位初始资本，再对每个实际处理个体流入五单位环境资源。

## 书稿必须保持的范围

正类是两个忠实遗传程序、每 cohort 各一健康创始者、共同物理 tick、已声明的独立局部及跨 cohort 噪声和资源供给。先固定有限时域，再扩大 cohort 数量及初始资源；结论不是固定有限群体无限期必然选择最优，也不是共用噪声、任意变异、频率依赖或环境切换的定理。归一化期望计数集中不能写成实际随机比例自动等同于期望之比。
