## Exact scope

The original model, original initial PMF, observation map, stationary
current-observation action PMFs and safe set are shared throughout. State and
action types are finite, the action type is nonempty, and the real-measure
endpoints retain measurable singleton assumptions. The observation type is
arbitrary. The killed matrix and unnormalized initial safe row are the existing
definitions from SameSourceKilledPath.

The main missing implication is obtained by summing the original causal PMF
over safe continuations of a fixed complete state prefix. No matrix-to-source
identity is supplied as an assumption. A private weighted version permits any
terminal test function; the last pmfExtend step and finite sum rearrangement
give the induction. With the constant terminal test it yields

    actualPrefixSurvivalMass(t,r,h)
      = actual_state_prefix_atom(t,h) * (Q^r 1)(last(h)).

This is valid for each safe prefix. It includes r=0 and t=0, imposes no positive
prefix or positive total survival condition, and does not condition on merely
being safe at the terminal time.

The positive-survival constructor actualConditionedPrefix filters the same
original action/state history experiment at t+r and then maps to the state
prefix. Its atom formula yields both the conditional initial law and the full
conditional safe-path mass. The conditional next-row formula is the ratio of
actual child and parent joint events; the horizons (t+1)+r and t+(r+1) are equal.
Positive parent mass, rather than positive global survival alone, supplies the
positive row denominator. finiteWindowRowPMF is a positive-row interface: it
does not assign 0/0 to a probability row or introduce an implicit null-row
fallback.

## Doob comparison

FiniteWindowDoob constructs the genuine tilted initial PMF and stationary Doob
row PMFs from the existing positive right eigenstructure. Its finite PMF path
is generated by causalLaw. The atom identity is derived by cancelling the
interior h factors:

    doobPathLaw(path)
      = killedPathWeight(path) * h(final) / (rho^T * <eta0,h>).

The initial pairing is explicit and need not equal one. The actual-source
comparison then reuses the preceding conditional safe-path identity. On each
positive killed path, equality with the natural Doob path is equivalent to
h(final) = rho^T <eta0,h> / s_T. Nothing forces h to be constant on unreachable
states.

A separate sufficient condition Q 1 = rho 1 with rho>0 gives Q^r 1 = rho^r 1
and finiteWindowRow = Q/rho. This condition is not inferred from a left QSD.

## Boundaries preserved

- The source feedback is stationary and current-observation based.
- Complete state history is retained; action-dependent events are not erased
  without proof. The conditioned action distribution is not identified with
  the original action policy.
- Zero total survival provides no filtered conditional PMF.
- Row PMFs require positive remaining survival. No all-state total kernel or
  independently generated full conditional path is claimed by that row API.
- The original K-exterior states need not be absorbing; safety concerns every
  recorded time.
- No Q-process limit, spectral convergence or nonstationary-to-homogeneous
  reduction is asserted.
- These are uncounted source-realization results. Frozen P-IDs, counted
  generators, prior source declarations and global closure state are unchanged.
