## 1. 同源性与 K1 的量词成立

合同直接从实际 `policyMatrix M (liftedStationaryPolicy o sigma)` 定义 L，再令 Q(u,v)=L(j(u),j(v))。Q 不是独立自由输入，原始动作—状态实验也没有被另一张看似相同的表取代。源的共享依赖仍是已经静态审查的平稳当前观察策略桥；其精确源码 SHA256 为 `108500fc13229b8faffc9829d886313167142075112bc3f6c023a086c074ae91`。本审查不将这个私有候选升级为已编译。

安全初始行 η₀(u)=p₀(j(u)) 是未归一化限制，事件 Sₙ 检查从 X₀ 至 Xₙ 的所有状态。因此

\[
\kappa_n=\eta_0Q^n,\qquad s_n=\eta_0Q^n\mathbf1
\]

对任意实际初始 PMF、任意安全集 K、所有 n 成立。一步递推只按安全前缀末态和下一安全状态分组；不除以任何历史概率，不把返回路径恢复为存活路径。先使用擦除动作的事件原像身份，再复用完整状态路径律身份，是正确的复用方向。

| 边界 | 正确结论 | 不允许的替换 |
|---|---|---|
| n = 0 | s₀=p₀(K)，κ₀=η₀；初始失败概率为 1−p₀(K) | 不得默认为 s₀=1 |
| p₀ 在 K 外有质量 | 外部质量在初始时即不属于 Sₙ；η₀ 保留原质量 | 不得先归一化 η₀ 然后仍称原实验存活概率 |
| p₀(K)=0 | 所有 sₙ=0，未归一化身份仍有效 | 不得构造唯一的实际条件概率律 |
| K 为空 | Sₙ 为空、sₙ=0；空类型上的矩阵和、幂身份合法 | K1 不得增加 `Nonempty K` 以绕过边界 |
| 路径先离开再返回 | 终端可在 K，但该路径已不属于 Sₙ | 不得用终端安全概率代替生存概率 |
| K 为全部 X | Q=L，sₙ=1 | 不需要额外 QSD 条件 |

直接查阅 `riskEverFailure`：零步定义是 `bad h`，后继是此前失败与新状态失败的析取，确实包含初始时刻。合同使用其否定定义 Sₙ 与现有时域约定一致。

矩阵递推的方向也正确：`rowApply_mul η₀ (Q^n) Q` 配合 `pow_succ` 给出 η₀Qⁿ⁺¹。`QSDPerron.rowApply_mul`、`leftPerron_pow` 的相关接口只有有限类型要求，没有强制安全类型非空；K1 可以保留空安全域。

## 2. K2 与真实条件分布

K2 严格要求 sₙ>0，故由非负终端质量和等于 sₙ，可构造归一化行 η₀Qⁿ/sₙ，并识别为实际事件过滤后末态分布。n=0 时，它准确给出 p₀ 条件于 X₀∈K 的律，而非无条件 p₀。

实际 mathlib `PMF.filter` 的第三个参数要求

```lean
∃ a ∈ s, a ∈ p.support
```

而 `filter_apply` 正是事件指标乘以事件质量倒数。有限历史空间上的 sₙ>0 可以推出该支持见证；合同指出要从真实 sₙ>0 构造见证，方向正确。不能另行传入与实际生存事件无关的过滤成功证书。

在 sₙ=0 时，未归一化 K1 继续成立；任意选择的零概率条件律都不由原实验唯一决定。Lean 的除法总函数约定不能改变这个概率含义。

## 3. K3、正右特征向量与实际初态

`KilledQSDGOA` 的真实定义是非负 substochastic 矩阵、非负归一化左行、正尺度和左特征关系。它不携带原控制模型或实际初始律。合同先从 L 构造 Q，再从给定左概率行 r 构造实际 p₀=j₊r，正好补齐这两个来源问题。

此时 K1 与 rQ=ρr 给出 sₙ=ρⁿ>0，条件终端律为 j₊r，且包括 n=0。对任意原先给定的 δₓ 初态，则不能套用这个重新构造初态的结果。四状态模型需要另证其初始适配；实际初始概率行 η 一步后变成 (1−θ)r，只有 n≥1 的条件终端律可据此变成 r。

左 QSD 即使对全部安全状态都严格为正，也不保证每个单点初态有下一步生存概率。§8.2 的反例完全成立。它同时说明“左概率行全支撑”不能代替严格正右特征向量。

§6 从严格正右特征关系 Qh=ρh 和非零非负 η₀ 推出有限时域正存活，推导正确：

\[
\langle\eta_0Q^n,h\rangle=\rho^n\langle\eta_0,h\rangle,
\quad
h_{\min}s_n\le\langle\eta_0Q^n,h\rangle\le h_{\max}s_n.
\]

非零 η₀ 先确保安全类型非空，有限性与 h>0 再保证正的 hmin、hmax。仅有 `RightEigenData` 在空类型上可以真空成立，不能省略这一非零初始质量条件。结论是每个有限 n 的 sₙ>0，不是存在统一正下界，更不是无限期存活概率为正。例如从安全概率初态出发，Q=(1/2)I 的 sₙ=2⁻ⁿ 对所有有限 n 正，却趋于零。

## 4. 有限窗条件路径与 Doob 路径

对真实正概率且已存活的完整微观前缀，未来存活因子只依赖当前微观状态；这是同源平稳策略桥提供的 Markov 性，未把观察过程本身 Markov 化。以 gᵣ=Qʳ1 写出的

\[
\frac{Q(u,v)g_{T-t-1}(v)}{g_{T-t}(u)},
\quad
\frac{w(j(u),a)p(j(u),a,j(v))g_{T-t-1}(v)}{g_{T-t}(u)}
\]

分别是有限窗生存条件下的下一状态、动作—状态联合行；分母正且前缀真实正概率时成立。第二个式子表明条件化会改变行动边缘，不能再称为原未条件化部署策略。

初始条件律为 η₀(u)g_T(u)/s_T。要将它称作真实条件概率，必须明确全局 s_T>0。即使这个全局条件成立，也不代表所有 u 的 g_{T−t}(u)>0；§8.2 从 QSD 初态出发便提供一个全局存活正而某行未来生存为零的例子。将分式推广成全部状态上的完整因果核时，零分母状态要另给 fallback，或者限制到正生存支持；不能把 0/0 的零行作为概率行。

如果后续接口只接收观察前缀，真实混合应保留“此前已经存活”的信息。例如先用未归一化信念

\[
b_t(u)=\Pr(S_t, X_t=j(u)\mid \text{观察前缀}),
\]

再乘未来权重 g_{T−t}(u)。单纯使用 Xₜ 的普通观察后验，可能把已经离开后返回的路径混入。若先条件于 Sₜ，则用相应存活后验即可。当前合同没有写错误的显式观察混合公式；这是后续实现必须保持的精确接口条件。

Doob 路径的乘积望远镜消去内部 h 因子，得到

\[
\prod_{t<n}Q^h(x_t,x_{t+1})
=\rho^{-n}\frac{h(x_n)}{h(x_0)}\prod_{t<n}Q(x_t,x_{t+1}).
\]

只有给 η 非负和 ⟨η,h⟩>0，ηʰ=ηh/⟨η,h⟩ 才是概率初始行。此时对应的是终点 h 加权的 killed 路径质量；一般不同于只按生存事件筛选并归一化。若 η 是未归一化的 η₀，原对象是截去初始失败质量后的有限测度，应明确这一含义。

当 Q1=ρ1 且 ρ>0 时，h=1 确实使所有有限窗条件转移成为 Q/ρ。对安全概率初始行，条件初始律保持该行；若从任意原初态开始，则应先限制并除以 p₀(K)，不能声称完整原初始律不变。合同将特殊相等限定在安全概率初态上，是正确的。
