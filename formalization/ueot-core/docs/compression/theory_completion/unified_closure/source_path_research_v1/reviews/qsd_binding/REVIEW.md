## 逐项结论

| 检查对象 | 结论及必要边界 |
|---|---|
| 真实初态 | p0 按定义是 `r.map Subtype.val`。`safeInitialRow_map_subtype` 从推前原子公式推出实际安全限制行为 r 的实值原子，没有把目标初态相等另置为假设。实数行接口使用已有 `FiniteProbabilityRow.ofRealRow`，保留逐点非负和总和为 1。 |
| 同源 Q 与实际路径 | Q 只能是同一 M、q、sigma 的 `killedMatrix M (liftedStationaryPolicy q sigma) K`；事件概率仍取自原 `causalLaw`、`riskMicroControlKernel` 和 `observationMarkovPolicy sigma`。左特征关系是这一 Q 的真实输入，没有独立 Q 或来源等式前提。 |
| 初始时刻及事件范围 | 生存事件是 `¬ riskEverFailure`，包括时刻 0 至 n。构造的 p0 已全在 K。终态质量与条件律针对实际含行动记录路径的状态事件；没有将终端在 K 当作全程安全，也没有声称一般行动路径或 Doob 路径等价。 |
| ρ=0 | 两条未归一化质量公式没有正性前提。因此 n=0 得总质量 1、联合质量 r(v)，n>0 得零生存质量。条件律接口有显式 `0<rho`，没有将实数零除约定当作条件概率。 |
| n=0 | 正 ρ 接口包含 n=0，正确返回初态 r 的推前。ρ=0、n=0 也在数学上具有合法条件律，但当前声明统一要求 `0<rho`，所以没有覆盖该边界实例；这是接口范围，不是错误结论。 |
| 空 K | `r : PMF K` 无法在空 K 上提供；实数行的总和为 1 同样排除空 K。源码没有给 K1 添加 `[Nonempty K]`。QSD 特化在此无可实例化输入，与 K1 仍处理空 K 相容。 |
| 条件 PMF 分母 | 分子和分母均属于同一个实际 nu。先证明真实生存质量为 rho^n，再由 `0<rho` 得正性，从该实际事件导出 `PMF.filter` 所需支持证据；没有外加另一实验的正概率证书。 |
| 条件 PMF 等式 | 私有 `filter_map_apply_real` 从实际 filter/map 给出同一分母的比值；K 内用联合质量公式，K 外用生存蕴含末状态安全证明零质量，最后对全体 X 原子取外延。目标是实际终端推前 PMF 等式，不只是归一化矩阵行。 |
| 特征条件与 GOA | 推出的是 0≤ρ≤1；严格正性仍为条件律和 `KilledQSDGOA` 的明确输入。未声称一般有限 Q 自动有正 QSD、唯一 QSD、吸引性，或任意初态正存活。 |
| 类型和时间 | X、A 有限，A 非空，X/A 单点可测；Y 任意。固定 M 与当前观察平稳 sigma 的范围保留，不外推一般历史依赖控制。 |
