## 1. Objective

The original Dual-Isolation theorem used three quantitative ingredients:

- binding isolation `beta_bind`;
- parent realization sensitivity `L_bind`;
- semantic isolation `kappa_sem`.

The open question was whether `L_bind` could be generated by an existing
frozen theorem rather than supplied as a free regularity constant.

P-MET-01 is exactly the relevant source when the parent dynamics is a common
post-processing of an assembly-level probability law.

## 2. Mechanism certificate

`CommonMarkovParentRealization` contains:

1. `baseLaw : A -> Measure X`;
2. probability normalization for every base law;
3. `tvDist(baseLaw a, baseLaw b) <= dist(a,b)`;
4. one Markov channel `channel x` for each finite parent state;
5. the exact row-realization identity

   `rowLaw(K p, x) = channel x ∘ₘ baseLaw(repr p)`.

Parent-Binding conclusion.

## 3. P-MET derivation

P-MET-01 gives

`TV(channel x ∘ₘ μ, channel x ∘ₘ ν) <= TV(μ,ν)`.

Using the realization identity and assembly metric domination yields

`crossRowTV(K p, K q, x) <= dist(repr p, repr q)`.

Therefore

`CommonMarkovParentRealization.toParentBinding`

constructs a genuine Parent-Binding certificate with

`L = 1`.

This is a derived theorem, not a field of the mechanism certificate.

## 6. Boundary

This result does **not** prove that every parent kernel has `L <= 1`.

The essential domain assumptions are:

- one common Markov channel for a given parent row index across compared
  completions;
- exact row factorization through the assembly-level law;
- assembly metric domination of base-law TV.

If a domain violates those assumptions, the generic
`ParentBindingLipschitz` interface remains necessary and may have `L > 1`.
