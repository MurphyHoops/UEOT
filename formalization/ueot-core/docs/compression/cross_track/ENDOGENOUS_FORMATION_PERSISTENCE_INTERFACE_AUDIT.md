## 2. Problem decomposition

The preceding Track-H / Parent-Binding / Dual-Isolation / Interaction work left
two distinct residuals:

1. **candidate formation** — the interaction theory still consumed an external
   candidate assembly type `A`;
2. **endogenous persistence** — P-PER-03 proved existence of a preserving
   stationary policy, but the controller appeared as an external object in the
   source controlled system.

These residuals are solved here only to the precise level supported by the
existing source theorems.  In particular:

`formation != identification != runtime persistence != self-repairing Omega-loop`.

## 3. Response-generated candidate formation

The new definition

`responseFormedCandidateFamily`

is

`childMinimalFamily regions (exactCarrierFamily readout p)`.

Thus a candidate parent coalition is not introduced independently.  It is
generated by the following source-certified chain:

`response laws p`

-> `zero-response-defect physical carriers`

-> `inclusion-minimal exact physical carriers`

-> `P-COMP-06 child-coalition lift`

-> `inclusion-minimal sufficient child coalitions`.

The equality

`responseFormedCandidateFamily_eq_lifted`

is exactly the P-COMP-06 two-stage construction theorem specialized to the
response-generated physical carrier family.

## 4. Formation existence from a primitive seed

The local mission initially needed nonemptiness of `exactCarrierFamily` as a
premise.  That premise has been reduced further.

`exactCarrierFamily_nonempty_of_zeroDefectSeed`

proves that one concrete finite physical carrier `S0` satisfying

`responseDefect readout p S0 = 0`

already generates an inclusion-minimal exact carrier.

The response history and response-probe axes are required to be nonempty.
This is semantically essential rather than cosmetic: if either axis were empty,
the response diameter defining the defect would have no observations and the
real supremum could collapse to zero vacuously.  The hardened theorem therefore
does not allow “response-supported formation” from an empty response domain.

Then

`responseFormedCandidateFamily_nonempty_of_zeroDefectSeed`

proves that if the declared children cover that same seed, finite
minimalization generates a nonempty parent-candidate family, again under
explicit nonempty response-history and response-probe axes.

Therefore the constructive formation premise is now a source-facing
zero-defect/coverage witness, not a pre-existing candidate family.

This is still conditional formation: the theorem does not prove that every
arbitrary physical system possesses such a seed.

The negative boundary is exact as well:

`responseFormedCandidateFamily_empty_of_no_exactCarrier`

proves that if the exact physical-carrier family is empty, the generated
parent-candidate family is empty.  The construction therefore cannot invent a
parent without any lower-level carrier witness.

## 6. Generated candidate type and metric

`FormedCandidate` is the subtype

`{S : Finset Child // S in responseFormedCandidateFamily ...}`.

It is finite whenever the child type is finite.

The candidate metric is not an arbitrary enumeration metric.  The local
instance `formedCandidateHammingMetric` embeds each coalition into its child
membership bit-vector and uses Mathlib's Hamming metric.

Hence assembly distance counts changed child-membership coordinates.

`formedCandidate_interactionIsolation_pos_iff`

then applies the already closed interaction-isolation theorem directly on the
generated candidate subtype:

`positive beta_E`

iff

`the selected probes pairwise separate the generated coalitions`.

This is the formal Formation -> Identification bridge.

## 7. Constitutive persistence state

The new reflexive state is

`ConstitutiveState X A = X × (X -> A)`.

The first coordinate is the physical state.  The second coordinate stores a
stationary controller.

The autonomous lift is

`constitutiveLift P (x, controller) ()`

which samples

`x' ~ P x (controller x)`

and returns

`(x', controller)`.

The external action type is `Unit`.

`constitutiveLift_external_action_irrelevant`

proves that the external action argument cannot influence the transition.
Runtime action selection is therefore entirely determined by internal state.

## 8. Projection correctness

Two theorems verify that the lift has not changed the intended closed-loop
dynamics:

- `constitutiveLift_state_projection` — the physical marginal is exactly
  `P x (pi x)`;
- `constitutiveLift_controller_projection` — the controller marginal is
  exactly `pure pi`.

Thus controller internalization is not merely a renaming of an external action
argument; the physical transition consumes the controller stored in the
reflexive state.

## 9. P-PER-03 -> autonomous constitutive closure

For a fixed source viability kernel `K`, P-PER-03's finite viability machinery
constructs a deterministic stationary selector `pi` satisfying

`support(P x (pi x)) subset K`

for every `x in K`.

Define

`constitutiveDomain K pi = {(x,controller) | x in K and controller = pi}`.

Lean proves:

- `constitutiveLift_staysIn`;
- `constitutiveDomain_fixed`;
- `exists_endogenous_constitutive_closure_of_fixed`;
- `exists_endogenous_constitutive_closure`.

So every finite controlled viability problem reaches a stabilized kernel and
admits a reflexive realization whose preserving controller is internal and
whose external action channel is trivial.

## 10. Path-level probability-one persistence

`exists_constitutive_all_times_safe_of_fixed`

uses the genuine Ionescu--Tulcea trajectory machinery already established in
the P-PER stack.

For `x in K`, it constructs an internal `pi` such that the trajectory of the
constitutive lift under the unique external `Unit` control remains in

`constitutiveDomain K pi`

at every discrete time with probability one.

This is stronger than one-step invariance and is the positive runtime
persistence result of this mission.

The strengthened interface also rules out vacuous empty-kernel closure.

`ConstitutivePersistenceCertificate` stores an actual seed in the stabilized
kernel together with one internal controller.  That same controller witnesses
source preservation, constitutive fixed-domain closure, and the all-times
probability-one trajectory theorem.

`exists_constitutivePersistenceCertificate_of_nonempty_winningSet`

constructs this certificate whenever the P-PER winning set is nonempty.

The helper theorem

`constitutive_all_times_safe_of_preserving`

uses a supplied preserving controller directly, so the path-level proof does
not silently re-select a different existential policy.

## 11. Exact Omega-loop boundary: no self-repair yet

The same construction intentionally exposes what it does **not** solve.

`constitutiveLift_wrong_controller_stays_wrong`

proves that if the system is initialized with a controller different from the
target preserving controller, the lift copies that wrong controller forward.

Therefore the current mechanism has:

- internal action selection;
- controller persistence;
- autonomous runtime viability;

but not:

- controller error detection;
- controller repair;
- controller reconstruction;
- constitutive replacement after controller loss.

This theorem prevents `constitutive persistence` from being silently renamed
as a full self-repairing Omega-loop.

## 12. Operational formed-persistent-parent synthesis

The final local module `EndogenousObjectSynthesis` joins the two branches in a
single certificate without renaming it as full Objecthood.

`OperationalFormedPersistentParent` contains:

- a `parent : FormedCandidate ...`, so formation provenance is carried by the
  subtype itself;
- one nonempty selected probe family;
- a family-wide `PairwiseInteractionSeparating` witness;
- one `ConstitutivePersistenceCertificate` for the selected parent.

The theorem

`exists_operationalFormedPersistentParent_of_responseSeed`

starts from one zero-defect carrier seed plus child coverage, generates at
least one formed parent, and combines that with explicit assumptions that the
chosen probes separate the generated family and that every generated parent's
P-PER winning set is nonempty.  It then constructs an operational parent
certificate.

This is nonvacuous: the response seed constructs the parent candidate before
the persistence witness is selected.  The theorem does not rely on separation
or winning-set statements over an empty formed-candidate type.

If the generated candidate type is nontrivial,

`OperationalFormedPersistentParent.interactionIsolation_pos`

recovers the quantitative positive interaction margin `beta_E` directly from
the certificate's family-wide separation witness.

The complementary theorem

`responseFormedCandidateFamily_empty_of_no_exactCarrier`

proves that the formation mechanism cannot manufacture a parent when no exact
physical carrier exists.

## 13. What the two residuals have become

Before this mission:

`candidate formation` was approximately “supply A”, and

`endogenous persistence` was approximately “supply/use an external policy”.

After this mission the residuals are narrower:

### Formation residual

Construct or empirically certify a zero-defect seed and its child-region
coverage in a concrete domain; for noisy data, discharge the already explicit
statistical recovery conditions.

### Omega-loop residual

Upgrade the internally stored preserving controller from immutable state to a
repairable/reconstructible constitutive component, ideally coupled to explicit
integrity/failure observables from the P-OMG family.
