## 4. Formation existence from a primitive seed

The local mission initially needed nonemptiness of `exactCarrierFamily` as a
premise.  That premise has been reduced further.

`exactCarrierFamily_nonempty_of_zeroDefectSeed`

proves that one concrete finite physical carrier `S0` satisfying

`responseDefect readout p S0 = 0`

`responseFormedCandidateFamily_nonempty_of_zeroDefectSeed`

This is still conditional formation: the theorem does not prove that every
arbitrary physical system possesses such a seed.

## 7. Constitutive persistence state

The new reflexive state is

`ConstitutiveState X A = X × (X -> A)`.

The first coordinate is the physical state.  The second coordinate stores a
stationary controller.

The autonomous lift is

`constitutiveLift P (x, controller) ()`

which samples

`x' ~ P x (controller x)`

and returns

`(x', controller)`.

The external action type is `Unit`.

`constitutiveLift_external_action_irrelevant`

proves that the external action argument cannot influence the transition.
Runtime action selection is therefore entirely determined by internal state.

## 11. Exact Omega-loop boundary: no self-repair yet

The same construction intentionally exposes what it does **not** solve.

`constitutiveLift_wrong_controller_stays_wrong`

proves that if the system is initialized with a controller different from the
target preserving controller, the lift copies that wrong controller forward.

Therefore the current mechanism has:

- internal action selection;
- controller persistence;
- autonomous runtime viability;

but not:

- controller error detection;
- controller repair;
- controller reconstruction;
- constitutive replacement after controller loss.

This theorem prevents `constitutive persistence` from being silently renamed
as a full self-repairing Omega-loop.

## 12. What the two residuals have become

Before this mission:

`candidate formation` was approximately “supply A”, and

`endogenous persistence` was approximately “supply/use an external policy”.

After this mission the residuals are narrower:

### Formation residual

Construct or empirically certify a zero-defect seed and its child-region
coverage in a concrete domain; for noisy data, discharge the already explicit
statistical recovery conditions.

### Omega-loop residual

Upgrade the internally stored preserving controller from immutable state to a
repairable/reconstructible constitutive component, ideally coupled to explicit
integrity/failure observables from the P-OMG family.
